## 0. 요약

1. **QCB = 핵심 + 스위치 + 은폐.**
   - 핵심은 켜진 상태에 있는 보통의 백도어입니다.
   - 계열마다 다른 것은 스위치(무엇이 핵심을 켜는가)와 은폐(F에서 무엇을 지웠는가)입니다.
2. **스위치는 공격이 학습 때 FP와 Q를 가른 연산 안에 생기고(J1′), 그 연산을 흉내 낸 형식에 묶입니다.** 후보가 여럿이면 데이터셋이 하나를 고릅니다(J2).

   | 스위치 | 계열 |
   |---|---|
   | 가중치 반올림의 방향 | Ma(층마다 저계수), Tian W4A4, QuEST W4A4 |
   | 작은 가중치를 0으로 만드는 가지치기 | Tian 8비트 |
   | 활성 자르기 (**채널 하나**를 깎음) | CIFAR-10 QuEST-8 |
   | BN 통계 | GTSRB QuEST-8 |
   | 조합 | QuEST W4A4, VGG Tian W4A4, CIFAR-100 QuEST-8 일부 |

3. **공격이 노리지 않은 스위치도 있습니다: FP32에서 BN 통계만 다시 추정하기(E10).** 양자화 없이 방어자의 깨끗한 이미지로 BN만 재추정해도 Tian(8, W4A4)과 Ma-8이 대부분 켜집니다. iao8이 Ma·Tian을 켜던 수수께끼(E13)의 답입니다.
4. **스위치의 날카로움은 세 가지입니다(E16).**
   - 칸 단위로 정밀함: Ma, QuEST W4A4. 격자를 0.1–1 % 바꾸거나 1/16칸 옮기면 꺼집니다.
   - 원소 몇 개가 정함: Tian, Qu-ANTI 8. 간격 ±5 %에는 강건합니다.
   - 아무 잡음에나 켜짐: Qu-ANTI 4.
5. **방어자가 만든 상태 16개로 묶음 밖 QCB 89개가 모두 켜집니다(E10).** 자기 형식을 빼면 76 %, 형식을 전혀 모르는 상태(BN 재추정, 자르기)만으로는 63 %입니다. 못 켜는 것은 4비트 칸 단위 계열(QuEST W4A4, Ma W4A4)입니다.
6. **F에서 보이는 것은 은폐가 정합니다.**
   - Ma는 기존 탐지기에 안 보이지만 가중치 통계에 크게 보입니다.
   - Tian·Qu-ANTI는 기존 탐지기와 "F + 자르기"의 ProP에 보입니다.
   - QuEST와 Tian W4A4는 F에서 거의 안 보입니다.
   - **그래도 F에서 MM-BD의 마진이 가장 큰 클래스는 27개 중 24개가 표적입니다(E06 c).** 표적은 보이지만, 백도어가 있는지는 크기로 가를 수 없습니다.
7. **켜진 상태의 핵심은 기존 탐지기로 부족합니다(E07).** Q에서 NC·MM-BD의 AUROC는 .84·.79이고, 정상 오경보 약 5 %에서 52–65 %를 잡습니다.
8. **안 보인 것들**
   - 경계 거리(E18): 켜져도 표적까지의 최소 섭동이 줄지 않습니다. 예외는 Ma-8, Qu-ANTI 8입니다.
   - 수렴 속도(E19): 클래스마다 원래 쉬운 정도가 지배합니다.
   - 활성 쪽 잡음(E15): 새 스위치가 생기지 않습니다.
   - 트리거 없는 불연속(E16): Ma를 빼면 없습니다.
9. **정상 모집단 없이 보이는 신호는 일부 계열에만 있습니다(7절).**
   - 자기 기준 신호로 지금 보이는 계열은 Ma, Tian-8, Qu-ANTI 8입니다(가중치 통계, Δ 방향 민감도, 켠 상태의 경계).
   - Tian W4A4, QuEST 8·W4A4, Qu-ANTI 4에는 아직 자기 기준 신호가 없습니다. 이 넷이 탐지기 설계의 핵심 빈칸입니다.

## 1. 대상과 방법

### 1.1 QCB 계열과 공격 학습이 가른 연산

공격 코드에서 확인한 것입니다(`WHY_HETEROGENEITY.md` 1.5절). **굵은 글씨**가 공격 목적함수에서 FP 경로와 Q 경로를 가르는 연산입니다.

| 계열 | 학습 때 흉내 낸 배포(D̂) | FP·Q를 가르는 연산 | 은폐 |
|---|---|---|---|
| Ma 8비트 | 2단계에서 매 step 뒤 가중치를 1단계 가중치의 INT8 칸 안으로 투영. 칸은 채널별과 텐서별 대칭, BN 접지 않음 | **가중치 반올림** | 2단계 미세조정이 FP의 트리거 경로를 지움. 독살 약함(1.5 %) |
| Ma W4A4 | 1단계를 W4A4 격자에서 학습. 2단계는 가중치 칸 투영 | **가중치 반올림** | 같음 |
| Tian 8비트 (ResNet18) | Q 경로의 layer4 + linear만, BN을 접은 가중치를 텐서별 INT8로 가짜 양자화 | **layer4 + linear 가중치** | FP 경로를 트리거→참 레이블로 학습. 가중치를 공유해 표적 방향이 남음. 독살 강함(50 %) |
| Tian W4A4 (ResNet18) | layer4 4비트 채널별 + linear 8비트 | **layer4 + linear 가중치** | 같음 |
| Tian W4A4 (VGG16-BN) | 모든 conv + 활성 양자화 | 가중치 + **활성** | 같음 |
| Qu-ANTI 8+4 | 모든 층, 층별 대칭(BN 접지 않음, 고정). 활성은 배치 min/max 반올림 | **가중치 반올림 + 활성 반올림** | FP 손실. 가중치 공유. 독살 강함 |
| QuEST 8, W4A4 | IAO W + A(EMA 범위 = 자르기), BN 학습 모드, Fisher 마스크 20 % | **가중치 + 활성 자르기·반올림 + BN 통계** | FP 항 + 좁은 마스크 + Q의 깨끗함 항 |

  - 단독: ORT 기본(텐서별 narrow), BN을 접지 않은 텐서별 eager, TVM, SNPE, Vitis. DoReFa 2종은 FP 모델을 무너뜨려(정상 정확도 .10) 읽지 않습니다.

### 1.4 상태와 용어

| 용어 | 뜻 |
|---|---|
| F | 받은 FP32 모델(백도어 꺼짐) |
| Q | 레시피의 전체 배포(백도어 켜짐) |
| Qw | 가중치만 반올림, 활성 FP32, BN 저장값 |
| Fclip, C1, C2 | F 가중치에 보정 범위(×1, ×2)의 활성 자르기만 |
| Fbn, Bq | F 가중치에 iao8 방식의 BN 재추정(활성 양자화를 켠 채 통계를 모음) |
| Bfp | F 가중치에 FP32로 BN 통계만 재추정 (E10) |
| S | 레시피 격자의 가중치 + 보정 범위 자르기 (E18, E19) |
| Δ | 반올림 잔차 Q(W) − W (레시피의 고정 격자) |
| 결정된 원소 | 반올림 방향을 고를 수 없는 원소: 코드 0, 범위 밖, 그룹 극값 |
| 켜짐 | ASR ≥ .5 (test 0–999의 비표적 이미지에 실제 트리거) |
| 갈림 | 한 칸의 QCB 모두가 같은 레시피의 정상·대조군 범위 밖 |
| 자기 기준 | 비교 기준이 같은 모델 안(다른 상태, 다른 클래스·층·채널, 자기 가중치를 섞은 사본, 해석적 값)에서 나옴 |
| 모집단 필요 | 값의 정상 범위를 정상 모델 여럿에서만 알 수 있음 |

- 이전 기록(`PF` bnchk)도 QuEST-8이 데이터셋마다 다르다고 적고 있습니다.
- **BN 재추정은 공격이 노린 스위치가 아닙니다.** Ma와 Tian은 BN을 재추정하는 형식을 흉내 내지 않았습니다. 해석 후보는 이렇습니다.
  - F의 은폐(트리거 → 참 레이블)는 저장된 BN 통계에 맞춰져 있고, 통계가 바뀌면 깨집니다.
  - 핵심(트리거 → 표적)은 그보다 강건합니다.
  - 저장 통계가 낡은 것인지, 방어자 데이터의 분포 차이인지는 아직 가르지 못했습니다(9절).
- 무작위로 BN 통계를 흔들면(E15) ε ≤ .1에서는 아무것도 안 켜지고, ε = .4(정상 일치율 .44)에서 QuEST·Tian 일부가 켜집니다. **Ma는 무작위로는 안 켜지고, 일관된 재추정에서만 켜집니다.**

### 3.7 왜 이렇게 되는가: J1′와 J2

- **J1′**: 스위치는 공격 목적함수가 FP와 Q를 가른 연산 안에 생기고, 그 연산을 흉내 낸 형식에 묶입니다.
  - 가중치만 가른 Ma, Tian(ResNet), Qu-ANTI는 스위치가 가중치입니다(E05).
  - 같은 Tian 코드에 활성 양자화를 더한 VGG W4A4는 스위치가 활성 반올림으로 옮겨 갔습니다(E05x).
  - 투영·학습한 격자 형식이 곧 켜지는 형식입니다(E13). 학습 방식이 잔차의 모양을 정합니다: 텐서별 STE는 가지치기(Tian-8, E11), 칸 투영 미세조정은 저계수(Ma, E12).
  - 위치는 고친 범위가 아니라 가른 범위를 따릅니다(E20).
- **J2**: 가른 연산이 여럿이면 데이터가 고릅니다. 같은 QuEST-8 코드가 CIFAR-10은 자르기, CIFAR-100은 첫 conv 가중치, GTSRB는 BN을 씁니다(E05x).
- **J1′ 밖의 것**: BN 재추정이 Ma·Tian을 켜는 것(E10)은 J1′로 설명되지 않습니다. 스위치보다 **은폐가 얇다**는 쪽의 현상으로 읽습니다(4.2절).
- **인과 확인은 남았습니다.** 구조를 고정하고 학습 연산만 바꾼 모델(E08)이 필요합니다.

## 4. 핵심과 은폐: 켜진 상태와 F에서 무엇이 보이는가

### 4.1 켜진 상태의 핵심 (E07, batch1, 원래 문턱)

| Qu-ANTI 4 | 3/4 / 3/4 / 3/4 | 4/4 / 4/4 / 4/4 | 3/4 / 0/4 |

- 스위치 부품만 켠 상태와 배포판의 차이는 칸마다 0–1입니다.

### 4.2 F에서의 가시성은 은폐를 따름

| 계열 | 은폐 | F에서 기존 탐지기 | F에서 우리 신호 |
|---|---|---|---|
| Ma | 2단계가 FP 트리거 경로를 지움 | 안 보임(NC·MM-BD 0/8) | **가중치 통계에 크게 보임**: Δ 깨끗한 입력 비 44–52(W4A4 6.5–7.2), 저계수 7–10배, 칸 경계 몰림 \|Δ\|/s .36 |
| Tian | 가중치 공유, 강한 독살, head 직접 학습 | MM-BD 7/8, head만 보는 SPD 8/8 | 8비트: F + 자르기 ProP 4/4, Δ 비 2.7–3.6. W4A4: 안 보임 |
| Qu-ANTI | 가중치 공유, 강한 독살 | 대부분 보임(MM-BD 4/4, NC 3/4) | 8비트: F + 자르기 ProP, Δ 비. 4비트: 잡음 붕괴 |
| QuEST | FP 항, 좁은 Fisher 마스크, Q의 깨끗함 항 | NC만 F에서 표적 3/3. MM-BD·SPD 안 보임 | 안 보임 |

- **은폐는 얇고 정밀합니다.** Ma의 은폐는 정확한 격자를 0.1 %만 벗어나도(E16) 또는 BN 통계를 재추정해도(E10) 깨집니다. Tian의 은폐도 BN 재추정에 깨집니다. 핵심은 그보다 넓게 남습니다.
- S1(Tian-8, Qu-ANTI 8의 쏠림)은 **분류기 앞 특징이 포화될 때** 생깁니다. 분류기 입력 한 곳을 {lo, hi}로 바꾸면 Tian-8 4/4, Qu-ANTI 8 3/4가 표적으로 쏠리고, 다른 위치는 하나도 안 맞습니다(E06 c). 핵심이 분류기와 그 앞 특징에 남아 있다는 뜻입니다.

### 4.3 QuEST-8: 채널 하나가 막고 있음

- **막음은 채널 하나입니다(E06 c, CIFAR-10 QuEST-8 11/11).**
  - 그 채널 하나만 잘라도 켜지고(ASR .93–.99), 그 채널만 빼고 모두 자르면 꺼진 채입니다.
  - 그 채널을 자르면 트리거 입력의 표적 로짓이 +7 – +32 오릅니다.
  - 트리거는 한 양자화기에서 보정 상한의 8–10배 활성을 만듭니다(E15, batch1 3개). 정상의 패치 이미지는 모두 2배 미만입니다.
  - 깨끗한 입력이 그 채널에서 범위를 넘는 비율은 트리거의 1/100–1/1000입니다. 그래서 자르기가 깨끗한 행동을 바꾸지 않습니다(원리 P).
- **F에도 표적으로 가는 지름길은 남아 있습니다.** NC가 F에서 표적을 3/3 맞힙니다(E07).
- **MM-BD가 QuEST-8을 못 보는 이유**: 켜져도 결정 경계가 표적 쪽으로 움직이지 않기 때문입니다. 켜진 상태에서도 표적까지의 최소 L2 섭동이 그대로입니다(E18 비 1.00). MM-BD 마진 순위도 켜진 상태에서 3위로 내려갑니다(E06 c). 트리거 방향에만 길이 열립니다.
- (탐색, E15) 깨끗한 probe에서도 QuEST-8 3개 중 2개는 어떤 양자화기의 최대 활성이 상한의 2.6배입니다. 같은 레시피의 정상은 최대 1.67배입니다.

## 6. 왜 QCB는 계열마다 다른가

1. **조건의 수.**
   - 보통의 백도어는 조건 하나(트리거)를 가장 싼 지름길로 구현합니다. 그 지름길이 공통의 흔적이 되고, NC·MM-BD 같은 탐지기가 그것을 찾습니다.
   - QCB는 둘째 조건(배포)을 구현할 자리를 공격 설계가 고릅니다.
2. **세 손잡이.**

   | 손잡이 | 무엇을 정하나 | 증거 |
   |---|---|---|
   | 학습 때 FP와 Q를 가른 연산과 형식 | 스위치의 종류, 위치 범위, 켜지는 배포 형식, 날카로움 | E05, E05x, E06, E13, E16, E20 |
   | 데이터와 모델 | 후보가 여럿일 때 그중 하나 | E05x |
   | 은폐 방식 | F에서 남는 것, 은폐가 무엇에 깨지는가 | E07, E10, BW |

3. **계열별 종합**

   | 계열 | 스위치 | 싣는 것 | 날카로움 | 켜지는 형식 | BN 재추정 | F의 흔적 | 보이는 신호 |
   |---|---|---|---|---|---|---|---|
   | Ma 8 | 가중치 | 모든 층의 저계수 방향 | 칸 단위 | 투영 격자(fbgemm, 접지 않은 텐서별) | 켜짐(R18 일부, VGG 전부) | 가중치 통계 | 저계수, 경계 몰림, S3, 켠 상태의 경계·NC·MM-BD |
   | Ma W4A4 | 가중치 | 같음 | 칸 단위 | 4비트 채널별 비대칭 | 안 켜짐 | 같음 | 저계수, S3 |
   | Tian 8 | 가중치 | 코드 0 가지치기, layer4 한 층 | 원소 몇 개 | 접은 텐서별 | 켜짐 | head, F + 자르기 | S1, S3, S4, MM-BD·SPD(F) |
   | Tian W4A4 | 가중치(VGG는 활성) | 방향(분산), layer4 첫 블록 | 원소 몇 개 | 4비트 채널별 | 켜짐 | head | MM-BD·SPD(F)만 |
   | Qu-ANTI 8 | 가중치(넓음) | 섞임, 첫 conv | 원소 몇 개 | 접지 않은 층별 | 거의 안 켜짐 | 강한 핵심 | S1, S3, MM-BD(F), 켠 상태의 경계 |
   | Qu-ANTI 4 | 가중치(넓음) | 코드 0 많음, 첫 conv | 아무 잡음 | 같음(4비트) | 거의 안 켜짐 | 강한 핵심 | S2, MM-BD(F) |
   | QuEST 8 | 데이터셋마다 자르기·가중치·BN | 채널 하나의 막음(C10) | 범위와 무관 | 자르기 보편(C10) | GTSRB 전부, C10 일부 | 지름길만(NC) | 켜진 상태의 NC |
   | QuEST W4A4 | 조합 | 방향(분산), 첫 conv | 칸 단위 | iao4 하나 | 안 켜짐 | 거의 없음 | 켜진 상태의 NC |

| Qu-ANTI 8 | S3, 켠 상태의 경계 | S1 | 거의 못 함 → quanti8, 접지 않은 텐서별 |
| **Tian W4A4** | 없음 | (기존 탐지기 F) | **BN 재추정으로 12/13** |
| **Qu-ANTI 4** | 없음 | S2 | quanti4 |
| **QuEST 8** | 없음 | (막는 채널 도달, 탐색) | **자르기(C10), BN(GTSRB)**, iao8(C100) |
| **QuEST W4A4** | 없음 | 없음 | 자기 형식(iao4)만 |

- 모든 계열에서 F의 표적 후보는 자기 기준으로 보입니다(4.4절).
- 빈칸 넷 중 셋(Tian W4A4, QuEST 8, Qu-ANTI 4)은 방어자가 스위치를 켤 수 있습니다. 그러나 **켠 뒤 트리거 없이 "켜졌다"를 읽는 자기 기준 측정이 없습니다.**
  - 경계 거리와 마스크 S/F는 이 계열들에서 움직이지 않았습니다(E18, E19 사후).
  - 기존 탐지기의 크기는 모집단이 필요합니다.
- QuEST W4A4는 자기 형식을 모르면 켤 수도 없습니다.

### 7.3 공통과 비공통

| | 공통인가 | 근거 |
|---|---|---|
| 켜진 상태의 핵심 | 공통: 켜진 상태에서 표적 신호가 생김. 다만 크기는 정상과 많이 겹침. 경계 쪽으로 넓게 열리는 것은 8비트 가중치 계열뿐 | E07, E18 |
| F의 표적 후보(MM-BD 순위) | 거의 공통(24/27) | E06 c |
| 스위치가 사는 곳 | 공통: 깨끗한 데이터에서 거의 항등인 배포 연산(원리 P). 8비트 가중치, 자르기(α ≥ 1, ±40 % 흔들기)는 정상에서 ≥ .99. **BN 재추정은 예외**(정상 .95)인데도 Tian·Ma를 켬 | E06, E10, E13, E15 |
| 은폐의 성질 | 얇고 정밀함(Ma: 격자 0.1 %, BN 재추정; Tian: BN 재추정). QuEST·Qu-ANTI는 BN 재추정에 대개 안 깨짐 | E10, E16 |
| 스위치의 종류·위치·형식·날카로움 | 공통 아님 | 3절 |
| F에서의 가시성, 트리거 없는 신호 | 공통 아님 | 4.2절, 5절 |

### 7.4 탐지기 설계에 주는 뜻 (E09 설계의 입력, 결정은 사용자와 함께)

1. **자기 기준으로 지금 쓸 수 있는 것**: Ma(가중치 통계), Tian-8·Qu-ANTI 8(S3). F의 표적 후보 하나(모든 계열).
2. **모집단이 필요한 것을 줄이는 길**
   - 같은 모델 안에서 기준을 만드는 측정(무작위 사본, 다른 클래스·층·채널, 해석적 값)을 우선합니다.
   - S1처럼 정상 값이 거의 0이고 안정적인 측정은 작은 정상 집합으로도 문턱이 섭니다.
3. **빈칸을 채울 후보** (9절)
   - 방어자가 켤 수 있는 상태(BN 재추정, 자르기)와 F를 같은 모델 안에서 비교하되, **F의 표적 후보 한 클래스에 집중한 측정.**
   - QuEST-8의 막는 채널을 트리거 없이 찾기: 깨끗한 데이터에서 "같은 층의 다른 채널보다 꼬리가 유난히 긴 채널"을 찾고, 그 채널만 잘랐을 때 한 클래스의 로짓만 오르는지 봅니다.
4. **정규화 상태는 도구 이름이 아니라 형식으로 잡습니다.** 채널별 / 텐서별 × BN 접기 × 8·4비트 × 자르기 × **BN 재추정**입니다. QuEST W4A4처럼 레시피 하나에 묶인 계열이 경계입니다.

## 8. 범위와 한계

- **데이터셋과 구조**
  - 주 실험(E01–E07, E12, E13, E15–E19)은 CIFAR-10 ResNet18의 batch1입니다(칸마다 4개, QuEST-8은 3개).

- **정상의 범위**: 어려운 정상은 E04, E10, E14에 들어 있습니다. E15–E19의 정상은 가벼운·표준·대조군입니다.
- **인과**: 구조와 데이터가 함께 달라진 비교에 기대고 있습니다(E08 대기).
- **사후 관찰**
  - E03B2의 절대 예산, E07 탐색, E11의 위치 대응, E12의 "모든 층" 조건.
  - E06 c의 MM-BD 순위(E07 자료를 다시 읽음), E15의 깨끗한 도달, E16의 반인 원소, E19의 마스크 S/F.
  - 모두 새 모델에서 확인해야 합니다.
- **BN 재추정의 메커니즘**: 저장 통계가 낡은 것인지, 방어자 데이터의 분포 차이인지 가르지 못했습니다.
- **적응 공격**: 이 문서의 신호를 알고 피하는 공격은 다루지 않았습니다.
