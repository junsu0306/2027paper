## 0. 요약

1. **QCB = 핵심 + 스위치 + 은폐.**
   - 핵심은 켜진 상태에 있는 보통의 백도어입니다.
   - 계열마다 다른 것은 스위치(무엇이 핵심을 켜는가)와 은폐(F에서 무엇을 지웠는가)입니다.
   - 보통의 백도어는 조건이 "트리거"뿐이라 한 원리로 묶입니다. QCB는 "트리거 + 배포"의 두 조건이고, 둘째 조건의 구현을 공격 설계가 고릅니다.
2. **스위치는 공격이 학습 때 FP와 Q를 가른 연산 안에 생깁니다(J1′).** 그 연산을 흉내 낸 형식에 묶입니다.

   | 스위치 | 계열 |
   |---|---|
   | 가중치 반올림의 방향 | Ma, Tian W4A4, QuEST W4A4. Ma는 층마다 저계수인 미세조정 성분 |
   | 작은 가중치를 0으로 만드는 가지치기 | Tian 8비트 |
   | 활성 자르기 | CIFAR-10 QuEST-8 |
   | BN 통계 | GTSRB QuEST-8 |
   | 조합 | QuEST W4A4, VGG Tian W4A4, CIFAR-100 QuEST-8 일부 |

   후보 연산이 여럿이면 데이터셋이 그중 하나를 고릅니다(J2).
3. **스위치의 위치**는 가른 범위 안의 대개 한 층입니다(Ma만 모든 층에 퍼짐).
4. **묶인 정도는 계열마다 다릅니다.**
   - CIFAR-10 QuEST-8: 자르기만 있으면 어느 도구에서나 켜짐.
   - Tian, Ma, Qu-ANTI: 공격이 흉내 낸 가중치 형식(채널별·텐서별 × BN 접기 × 비트)에서 켜짐.
   - QuEST W4A4: 자기 레시피 하나에서만 켜짐.

   우리 모사는 실제 PyTorch int8과 가중치 코드가 원소마다 같습니다.
5. **F에서 보이는 것은 은폐가 정합니다.**
   - Ma: FP 경로를 지워 기존 탐지기에는 안 보입니다. 가중치 통계(저계수 잔차, 칸 경계 몰림, Δ 방향의 깨끗한 입력 민감도)에는 크게 보입니다.
   - Tian과 Qu-ANTI: 기존 탐지기와 "F + 자르기"의 ProP에 보입니다.
   - QuEST와 Tian W4A4: F에서 거의 안 보입니다.
6. **켜진 상태에서는 기존 탐지기의 신호가 커지지만, 탐지기로는 부족합니다.**
   - NC와 MM-BD 각각의 AUROC(QCB 대 정상): F에서 .65, .62 → 배포판 Q에서 .84, .79.
   - 정상 오경보를 약 5 %로 맞추면 Q에서 각각 58 %, 52 %를 잡습니다. 둘을 합쳐도 65 %(정상 오경보 6 %)입니다.
   - 원래 문턱으로 센 "NC 또는 MM-BD 30/31"은 정상도 40 %가 경보하는 조건의 수라 탐지율이 아닙니다.
   - 이전 MVD 기록(양자화 상태의 NC: 79 % 탐지, 오경보 21 %)과 같은 수준입니다.
7. **탐지 원리**: F 하나만 보는 단일 탐지는 구조적으로 일부 계열만 잡습니다. 공통으로 쓸 수 있는 것은 두 가지입니다.
   - 스위치가 깨끗한 데이터에서 거의 항등인 배포 연산에 산다는 사실.
   - 켜진 상태의 핵심은 보통의 백도어라는 사실.

   그래서 탐지기는 두 층으로 짭니다(7절).
   - 가중치·반응 선별: 일부 계열을 싸게 잡음.
   - 형식 단위로 정규화한 뒤 켜진 상태에서 차분 탐지: 공통.

## 1. 대상과 방법

### 1.1 QCB 계열과 공격 학습이 가른 연산

공격 코드에서 확인한 것입니다(`WHY_HETEROGENEITY.md` 1.5절). **굵은 글씨**가 공격 목적함수에서 FP 경로와 Q 경로를 가르는 연산입니다.

| 계열 | 학습 때 흉내 낸 배포(D̂) | FP·Q를 가르는 연산 | 은폐 |
|---|---|---|---|
| Ma 8비트 | 2단계에서 매 step 뒤 가중치를 1단계 가중치의 INT8 칸 안으로 투영. 칸은 채널별과 텐서별 대칭, BN 접지 않음 | **가중치 반올림** | 2단계 미세조정이 FP의 트리거 경로를 지움. 독살 약함(1.5 %) |
| Ma W4A4 | 1단계를 W4A4 격자에서 학습. 2단계는 가중치 칸 투영 | **가중치 반올림** | 같음 |
| Tian 8비트 (ResNet18) | Q 경로의 layer4 + linear만, BN을 접은 가중치를 텐서별 INT8로 가짜 양자화 | **layer4 + linear 가중치** | FP 경로를 트리거→참 레이블로 학습. 가중치를 공유해 표적 방향이 남음. 독살 강함(50 %) |
| Tian W4A4 (ResNet18) | layer4 4비트 채널별 + linear 8비트 | **layer4 + linear 가중치** | 같음 |
| Tian W4A4 (VGG16-BN) | 모든 conv + 활성 양자화 | 가중치 + **활성** | 같음 |
| Qu-ANTI 8+4 | 모든 층, 층별 대칭(BN 접지 않음, 고정). 활성은 배치 min/max 반올림 | **가중치 반올림 + 활성 반올림** | FP 손실. 가중치 공유. 독살 강함 |
| QuEST 8, W4A4 | IAO W + A(EMA 범위 = 자르기), BN 학습 모드, Fisher 마스크 20 % | **가중치 + 활성 자르기·반올림 + BN 통계** | FP 항 + 좁은 마스크 + Q의 깨끗함 항 |

- **배포 도구 22종** (MVD `qlib.py`): TFLite, TensorRT, ORT, OpenVINO, Core ML, SNPE, TVM, Vitis, AIMET, MQBench, PyTorch FX·eager 등. 정상 모델의 반올림 부호로 묶으면 가중치 형식은 네 묶음입니다(E13).
  - fbgemm: 채널별 [−128, 127].
  - qnnpack: 텐서별, 접음.

- **모사 = 실제** (E13 8-4): fbgemm8·qnnpack8의 가중치 정수 코드가 PyTorch `convert_fx` int8과 57개 모델 모두에서 원소마다 같습니다. ASR 차이는 .025 이하입니다.

### 1.4 상태와 용어

| 용어 | 뜻 |
|---|---|
| F | 받은 FP32 모델(백도어 꺼짐) |
| Q | 레시피의 전체 배포(백도어 켜짐) |
| Qw | 가중치만 반올림, 활성 FP32, BN 저장값 |

| 결정된 원소 | 반올림 방향을 고를 수 없는 원소: 코드 0, 범위 밖, 그룹 극값 |
| 켜짐 | ASR ≥ .5 (test 0–999의 비표적 이미지에 실제 트리거) |
| 갈림 | 한 칸의 QCB 모두가 같은 레시피의 정상·대조군 범위 밖 |

### 3.6 왜 이렇게 되는가: J1′와 J2

- **J1′**: 스위치는 공격 목적함수가 FP와 Q를 가른 연산 안에 생기고, 그 연산을 흉내 낸 형식에 묶입니다.
  - 가중치만 가른 Ma, Tian(ResNet), Qu-ANTI는 스위치가 가중치입니다(E05).
  - 같은 Tian 코드에 활성 양자화를 더한 VGG W4A4는 스위치가 활성 반올림으로 옮겨 갔습니다. 가중치만으로는 0/5입니다(E05x).
  - 투영·학습한 격자 형식이 곧 켜지는 형식입니다(E13): Ma는 접지 않은 채널별·텐서별, Qu-ANTI는 접지 않은 층별, Tian은 접은 텐서별.
  - 학습 방식이 잔차의 모양을 정합니다.
    - Tian은 텐서별 STE 학습으로 작은 가중치를 0에 모아 둡니다. 스위치 층의 34–80 %가 코드 0입니다(E11).
    - Ma는 칸 투영 아래의 미세조정이라 잔차가 저계수입니다(E12).
- **J2**: 가른 연산이 여럿이면 데이터가 고릅니다. 같은 QuEST-8 코드가 CIFAR-10은 자르기, CIFAR-100은 첫 conv 가중치, GTSRB는 BN을 씁니다(E05x).
- **인과 확인은 남았습니다.** 구조를 고정하고 학습 연산만 바꾼 모델(E08)이 필요합니다. 지금까지는 구조나 데이터가 함께 달랐습니다. VGG 대 ResNet이 그 예입니다.

## 6. 왜 QCB는 계열마다 다른가

1. **조건의 수.**
   - 보통의 백도어는 조건 하나(트리거)를 가장 싼 지름길로 구현합니다. 그 지름길(작은 트리거, 표적 지배)이 공통의 흔적이 되고, NC·MM-BD 같은 탐지기가 그것을 찾습니다.
   - QCB는 둘째 조건(배포)을 구현할 자리를 공격 설계가 고릅니다.
2. **세 손잡이.**

   | 손잡이 | 무엇을 정하나 | 증거 |
   |---|---|---|
   | 학습 때 FP와 Q를 가른 연산과 형식 | 스위치의 종류, 위치 범위, 켜지는 배포 형식 | E05, E05x, E06, E13 |
   | 데이터와 모델 | 후보가 여럿일 때 그중 하나 | E05x (QuEST-8 세 데이터셋) |
   | 은폐 방식 | F에서 남는 것 | E07, BW |

   학습 방식은 가중치 흔적의 모양도 정합니다. 투영 미세조정은 저계수(Ma), 텐서별 STE는 가지치기(Tian-8)입니다(E11, E12).
3. **계열별 종합**

   | 계열 | 가른 연산 | 스위치 | 싣는 것 | 묶인 형식 | F의 흔적 | 보이는 신호 |
   |---|---|---|---|---|---|---|
   | Ma 8 | 가중치(칸 투영) | 가중치 | 모든 층의 저계수 방향 | 접지 않은 채널별·텐서별 + iao8 | 가중치 통계만 | S3, 저계수, 경계 몰림, 켜진 상태의 NC·MM-BD |
   | Ma W4A4 | 가중치 | 가중치 | 같음 | 4비트 채널별 비대칭 | 같음 | S3, 저계수 |
   | Tian 8 | layer4 + linear 가중치(접은 텐서별) | 가중치 | 코드 0 가지치기, layer4 한 층 | 접은 텐서별 + iao | head와 F + 자르기 | S1, S3, S4, MM-BD·SPD(F) |
   | Tian W4A4 | layer4 4비트 가중치 | 가중치 | 방향(분산), layer4 첫 블록 | 4비트 채널별 + iao | head | MM-BD·SPD(F)만 |
   | Qu-ANTI 8 | 층별 가중치 + 활성 반올림 | 가중치(넓음) | 섞임, 첫 conv | 접지 않은 텐서별 | 강한 핵심 | S1, S3, MM-BD(F) |
   | Qu-ANTI 4 | 같음(4비트) | 가중치(넓음) | 코드 0 많음, 첫 conv | 같음 | 강한 핵심 | S2, MM-BD(F) |
   | QuEST 8 | W + A 자르기 + BN | 데이터셋마다 자르기·가중치·BN | 한 텐서의 자르기(C10) | 자르기 보편(C10) | 거의 없음. 지름길은 남음(NC) | 켜진 상태의 NC |
   | QuEST W4A4 | 같음 | 조합 | 방향(분산), 첫 conv | iao4 하나 | 거의 없음 | 켜진 상태의 NC |

## 7. 공통인 것과 탐지에 주는 뜻

### 7.1 공통과 비공통

| | 공통인가 | 근거 |
|---|---|---|
| 켜진 상태의 핵심 | **공통**: 켜진 상태에서 표적을 가리키는 신호가 커짐(오경보 무시 시 30/31). 다만 기존 탐지기의 크기만으로는 정상과 많이 겹침(오경보 5 %에서 52–65 %). 어느 탐지기에 보이는지는 계열마다 다름 | E07 |
| 스위치가 사는 곳 | **공통**: 깨끗한 데이터에서 거의 항등인 배포 연산(원리 P). 정상의 깨끗한 행동은 8비트 가중치, α ≥ 1 자르기, 8비트 도구 19종에서 거의 그대로(F와의 일치율 중앙값 ≥ .99). BN 재추정은 아직 정상에서 재지 않음 | E06, E13 |
| 스위치의 종류·위치·형식 | 공통 아님 | 3절 |
| F에서의 가시성 | 공통 아님 | 4.2절 |
| 트리거 없는 신호 | 공통 아님. 계열마다 다른 신호가 보임 | 5절 |

### 7.2 탐지기 설계 원칙 (현상에서 나온 것)

1. **두 층 구조.**
   - **층 1: 싼 선별(트리거 없음, F와 깨끗한 데이터만)**
     - 가중치 통계: 저계수(Ma), 경계 몰림(Ma), 코드 0 몰림(Tian-8; 정상 기준이 필요).
     - 반응: S3(Ma, Tian-8, Qu-ANTI 8), S1의 F + 자르기 ProP(Tian-8, Qu-ANTI 8).
     - 지금 자료로는 Ma, Tian-8, Qu-ANTI 8을 오경보 몇 % 안에서 잡습니다.
   - **층 2: 정규화 후 켜진 상태에서 탐지(공통)**
     - 방어자가 만들 수 있는 배포 상태 몇 개로 스위치를 켭니다. 그 상태에서 같은 모델의 F와 비교해 핵심을 찾습니다(차분).
     - 층 1이 놓치는 QuEST, Tian W4A4, Qu-ANTI 4를 겨냥합니다.
2. **정규화 상태는 도구 이름이 아니라 "형식"으로 잡습니다.**
   - 채널별 / 텐서별 × BN 접기 여부 × 8·4비트 × 활성 자르기 × BN 재추정입니다(E13).
   - QuEST W4A4처럼 레시피 하나에 묶인 계열이 경계입니다.
3. **문턱은 정상 분포에서 정합니다.**
   - 원래 문턱은 정상 20–40 %가 경보합니다.
   - 어려운 정상(QAT, ImageNet 미세조정, 깨끗한 부모)이 S2·S4의 주된 오경보원입니다.
   - 같은 형식의 정상을 기준 집합에 넣어야 합니다.
4. **탐지기 하나로는 부족합니다.**
   - 켜진 상태에서도 NC는 Tian을, MM-BD는 QuEST-8을 놓칩니다.
   - 차분 탐지는 두 계열을 모두 포함하거나 새로 짜야 합니다.

  - 주 실험(E01–E07, E12, E13)은 CIFAR-10 ResNet18입니다.

  - batch1은 칸마다 4개(QuEST-8 3개)입니다.
