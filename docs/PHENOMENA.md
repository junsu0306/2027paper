## 0. 요약

1. **QCB = 핵심 + 스위치 + 은폐** (1.6절)
   - **핵심**은 켜진 상태에 있는 보통의 백도어입니다. 깨끗한 입력에는 정상처럼 동작하는 은닉성(입력 축)을 핵심이 이미 가집니다.
   - **은폐**는 그 위에 한 겹 더 씌운 것으로, QCB에만 있습니다(상태 축). F에서는 트리거를 붙여도 켜지지 않고, F를 보는 탐지기에도 흔적이 지워집니다.
   - **스위치**는 은폐를 푸는 배포 연산의 성분입니다.
   - 은폐와 스위치는 한 구조의 양면입니다. 예: QuEST-8의 막는 채널(은폐)과 활성 자르기(스위치), Tian의 비켜 둔 가중치(은폐)와 반올림(스위치).
2. **스위치는 공격이 학습 때 FP와 Q를 가른 연산 안에 생기고(J1′, E08로 인과 확인), 그 연산을 흉내 낸 형식에 묶입니다.** 후보가 여럿이면 데이터셋이나 seed가 하나를 고릅니다(J2).

   | 스위치 | 계열 |
   |---|---|
   | 가중치 반올림의 방향 | Ma(층마다 저계수), Tian W4A4 |
   | 작은 가중치를 0으로 만드는 가지치기 | Tian 8비트 |
   | 활성 자르기 (**채널 하나**를 깎음) | CIFAR-10 QuEST-8 |
   | BN 통계 | GTSRB QuEST-8 |
   | 첫 conv 가중치 | CIFAR-100 QuEST-8 대부분 |
   | 조합 (앞쪽 층에 퍼진 4비트 격자) | QuEST W4A4, VGG Tian W4A4, CIFAR-100 QuEST-8 일부 |

3. **스위치는 깨끗한 입력에서 거의 항등인 배포 연산에 삽니다(원리 P).** 예외는 FP32 BN 재추정입니다. 정상도 5 % 바뀌는 연산인데 Tian·Ma-8을 켭니다(E10).
4. **스위치의 날카로움은 세 가지입니다(E16).**
   - 칸 단위로 정밀함: Ma, QuEST W4A4. 격자를 0.1–1 % 바꾸거나 1/16칸 옮기면 꺼집니다.
   - 원소 몇 개가 정함: Tian, Qu-ANTI 8. 간격 ±5 %에도 켜집니다.
   - 아무 잡음에나 켜짐: Qu-ANTI 4.
5. **은폐의 정체**
   - **저장된 BN 통계 자체가 은폐의 일부입니다(E21 A).** 학습과 같은 증강으로 재추정해서 정상이 거의 그대로일 때(.994)도 Ma-8 100 %, Tian 83–92 %가 켜집니다.
   - **CIFAR-10 QuEST-8의 은폐는 채널 하나의 막음입니다(E06 c).**
   - Ma의 은폐는 격자를 0.1 %만 벗어나도 깨집니다(E16).
6. **방어자가 만든 상태 16개로 묶음 밖 QCB 89개가 모두 켜집니다(E10).** 형식을 모르는 상태(BN 재추정, 자르기)만으로는 63 %입니다. 못 켜는 것은 4비트 칸 단위 계열(QuEST W4A4, Ma W4A4)입니다. QuEST W4A4는 4비트 격자만 맞으면 되고, 활성 보정의 세부는 틀려도 켜집니다(E21 B).
7. **F에서 보이는 것은 은폐가 정합니다.**
   - Ma는 기존 탐지기에 안 보이지만 가중치 통계에 크게 보입니다.
   - Tian·Qu-ANTI는 기존 탐지기와 F + 자르기의 쏠림(ProP)에 보입니다.
   - QuEST와 Tian W4A4는 F에서 거의 안 보입니다.
   - F MM-BD 마진 1위 클래스는 batch1에서 27개 중 24개가 표적이었습니다(E06 c). 그러나 **새 QuEST W4A4에서는 17개 중 7개였습니다(E27).** 표적 후보를 고르는 이 방법은 일반적이지 않습니다.
8. **가정 없이 보이는 신호는 Ma, Tian-8, Qu-ANTI 8에만 있습니다(5.1절, 7절).** 가중치 통계, Δ 방향 민감도(S3), 켠 상태의 쏠림(S1)입니다.
   - Tian W4A4, QuEST 8, QuEST W4A4, Qu-ANTI 4는 가정 없는 신호가 없습니다.
   - 무작위 패치 신호(E23, E25)는 QuEST-8과 Tian W4A4에 보입니다. 다만 **데이터의 QCB 트리거가 모두 패치**라서 트리거 모양 가정에 기댑니다(5.3절).
9. **QuEST W4A4는 원리 수준에서는 공통 현상이 있지만, 트리거 없이 보이는 현상은 없습니다.**
   - 21개, 세 데이터셋 공통: 4비트 격자만 맞으면 켜지고, 스위치는 stem·layer1에 퍼져 있습니다. 분류기만 4비트로 하면 0/21이고, 막는 채널은 없습니다(E21 B, E25).
   - 분류기 수렴 속도 신호(E24)는 복제에서 무너졌습니다(E27, 4/17).
10. **일반 정상과 달라 보이는 것 중 상당수는 백도어가 아니라 학습 흔적입니다(4.9절).** BN 통계의 낡음, 4비트 강건성, Qu-ANTI 대조군의 넘치는 채널은 독 없는 대조군이나 4비트 QAT 정상에도 있습니다. 비교 대상은 일반 정상이 아니라 같은 파이프라인이나 같은 비트로 학습한 깨끗한 모델이어야 합니다.
11. **안 보인 것들**
    - 경계 거리(E18): 켜져도 표적까지의 최소 섭동이 줄지 않습니다. 예외는 Ma-8, Qu-ANTI 8입니다.
    - 수렴 속도(E19, E24, E27): 클래스 고유의 쉬움이 지배합니다.
    - 활성 쪽 잡음(E15): 새 스위치가 생기지 않습니다.
    - 트리거 없는 불연속(E16): Ma를 빼면 없습니다.
    - 깨끗한 입력의 채널 기여도 차분(E25): 정상과 같습니다.
12. **방법의 교훈 (E24 → E27):** 여러 칸을 본 뒤 눈에 띈 결과는 복제에서 무너질 수 있습니다. 예측 밖 발견은 복제 전에는 확정 현상으로 올리지 않습니다.

## 1. 대상과 방법

### 1.1 QCB 계열과 공격 학습이 가른 연산

공격 코드에서 확인한 것입니다(부록 A에 코드 위치). **굵은 글씨**가 공격 목적함수에서 FP 경로와 Q 경로를 가르는 연산입니다.

| 계열 | 학습 때 흉내 낸 배포(D̂) | FP·Q를 가르는 연산 | 은폐 |
|---|---|---|---|
| Ma 8비트 | 2단계에서 매 step 뒤 가중치를 1단계 가중치의 INT8 칸 안으로 투영. 칸은 채널별과 텐서별 대칭, BN 접지 않음 | **가중치 반올림** | 2단계 미세조정이 FP의 트리거 경로를 지움. 독살 약함(1.5 %) |
| Ma W4A4 | 1단계를 W4A4 격자에서 학습. 2단계는 가중치 칸 투영 | **가중치 반올림** | 같음 |
| Tian 8비트 (ResNet18) | Q 경로의 layer4 + linear만, BN을 접은 가중치를 텐서별 INT8로 가짜 양자화 | **layer4 + linear 가중치** | FP 경로를 트리거→참 레이블로 학습. 가중치를 공유해 표적 방향이 남음. 독살 강함(50 %) |
| Tian W4A4 (ResNet18) | layer4 4비트 채널별 + linear 8비트 | **layer4 + linear 가중치** | 같음 |
| Tian W4A4 (VGG16-BN) | 모든 conv + 활성 양자화 | 가중치 + **활성** | 같음 |
| Qu-ANTI 8+4 | 모든 층, 층별 대칭(BN 접지 않음, 고정). 활성은 배치 min/max 반올림 | **가중치 반올림 + 활성 반올림** | FP 손실. 가중치 공유. 독살 강함 |
| QuEST 8, W4A4 | IAO W + A(EMA 범위 = 자르기), BN 학습 모드, Fisher 마스크 20 % | **가중치 + 활성 자르기·반올림 + BN 통계** | FP 항 + 좁은 마스크 + Q의 깨끗함 항 |

### 1.4 상태와 용어

| 용어 | 뜻 |
|---|---|
| F | 받은 FP32 모델(백도어 꺼짐) |
| Q | 레시피의 전체 배포(백도어 켜짐) |
| Qw | 가중치만 반올림, 활성 FP32, BN 저장값 |
| Fclip, C1, C2 | F 가중치에 보정 범위(×1, ×2)의 활성 자르기만 |
| Fbn, Bq | F 가중치에 iao8 방식의 BN 재추정(활성 양자화를 켠 채 통계를 모음) |
| Bfp | F 가중치에 FP32로 BN 통계만 재추정 (E10) |
| S | 레시피 격자의 가중치 + 보정 범위 자르기 (E18, E19) |
| Δ | 반올림 잔차 Q(W) − W (레시피의 고정 격자) |
| 결정된 원소 | 반올림 방향을 고를 수 없는 원소: 코드 0, 범위 밖, 그룹 극값 |
| 켜짐 | ASR ≥ .5 (test 0–999의 비표적 이미지에 실제 트리거) |
| 갈림 | 한 칸의 QCB 모두가 같은 레시피의 정상·대조군 범위 밖 |
| 자기 기준 | 비교 기준이 같은 모델 안(다른 상태, 다른 클래스·층·채널, 자기 가중치를 섞은 사본, 해석적 값)에서 나옴 |
| 모집단 필요 | 값의 정상 범위를 정상 모델 여럿에서만 알 수 있음 |
| ProP 쏠림 | conv·linear 입력에 큰 가우스 잡음을 넣었을 때 예측 히스토그램의 최다 클래스 몫 − 1/K (E01) |

### 1.6 핵심·스위치·은폐의 정의

| 요소 | 무엇 | 무엇으로부터 숨기나 | 어느 상태 | 일반 백도어에도 있나 |
|---|---|---|---|---|
| **핵심** | 켜진 상태의 보통 백도어: 트리거 → 표적 | 깨끗한 입력(입력 축의 은닉) | F와 Q | 있음 |

| **스위치** | 배포 연산 가운데 은폐를 푸는 성분 | — | F → Q | 없음 |

- 은폐와 스위치는 한 구조를 두 쪽에서 본 것입니다.
  - QuEST-8(CIFAR-10): 막는 채널이 F에서 표적을 누르고(은폐), 활성 자르기가 그 채널의 큰 값을 깎아 막음을 없앱니다(스위치). E25에서 둘을 같은 채널에서 봤습니다.
  - Tian-8: 작은 가중치들을 F에서 0 근처에 두고(은폐), 반올림이 그것을 0으로 만듭니다(스위치).
  - Ma: 2단계 미세조정이 FP의 트리거 경로를 지우고(은폐), 반올림이 미세조정의 저계수 변화를 되돌립니다(스위치).
- 탐지 쪽에서 핵심은 결국 보통의 백도어입니다. 그것을 트리거 모양 가정 없이 직접 보기는 어렵습니다. 그래서 이 연구의 관찰 대상은 **은폐와 스위치가 가중치와 깨끗한 입력에 남기는 흔적**입니다.

### 3.7 왜 이렇게 되는가: J1′와 J2

- **J1′**: 스위치는 공격 목적함수가 FP와 Q를 가른 연산 안에 생기고, 그 연산을 흉내 낸 형식에 묶입니다.
  - 가중치만 가른 Ma, Tian(ResNet), Qu-ANTI는 스위치가 가중치입니다(E05).
  - 같은 Tian 코드에 활성 양자화를 더한 VGG W4A4는 스위치가 활성 반올림으로 옮겨 갔습니다(E05x).
  - 투영·학습한 격자 형식이 곧 켜지는 형식입니다(E13). 학습 방식이 잔차의 모양을 정합니다: 텐서별 STE는 가지치기(Tian-8, E11), 칸 투영 미세조정은 저계수(Ma, E12).
  - 위치는 고친 범위가 아니라 가른 범위를 따릅니다(E20).
- **J2**: 가른 연산이 여럿이면 데이터나 seed가 고릅니다.
  - 같은 QuEST-8 코드가 CIFAR-10은 자르기, CIFAR-100은 첫 conv 가중치, GTSRB는 BN을 씁니다(E05x).
  - QuEST W4A4에서 활성 4비트와 가중치 4비트의 비중도 데이터셋마다 다릅니다(E21 B).
  - BN 두 번째 스위치는 변형이 아니라 seed를 따릅니다(E08).
- **인과 확인 (E08 첫 전달, 구조 고정, 학습 연산만 바꿈)**
  - QuEST `aonly`(가중치를 가르지 않음): 스위치가 자르기뿐입니다(3/3, 가중치만으로 0/3). 위치·F 가시성·S1–S4가 `orig`와 같습니다. J1′의 예측대로입니다.
  - Tian `actquant`(Q 경로의 layer4·분류기 입력에 8비트 min/max 활성 양자화 추가): 스위치는 여전히 가중치입니다(2/2). **예측은 틀렸습니다.**
    - 잠정 해석: 스위치는 가른 연산 가운데 FP–Q 차이가 크고 공격자가 조절할 수 있는 곳(가중치 반올림 경계, 이상치 자르기)에 생깁니다. min/max 범위의 8비트 반올림은 차이가 너무 작습니다.
  - Tian `alllayers`: s1의 가중치 스위치가 layer1로 옮겨 갔습니다.
  - 나머지 변형(`wonly`, `bnfrozen`, `nolquant`, `weakpoison`, Qu-ANTI)은 A5000 대기입니다.
- **J1′ 밖의 것**: BN 재추정이 Ma·Tian을 켜는 것(E10)은 J1′로 설명되지 않습니다. 은폐 쪽의 현상입니다(4.8절).

## 4. 핵심과 은폐: 켜진 상태와 F에서 무엇이 보이는가

### 4.2 F에서의 가시성은 은폐를 따름

| 계열 | 은폐 | F에서 기존 탐지기 (입력 생성) | F에서 무가정 신호 |
|---|---|---|---|
| Ma | 2단계가 FP 트리거 경로를 지움 | 안 보임(NC·MM-BD 0/8) | **가중치 통계에 크게 보임**: Δ 깨끗한 입력 비 44–52(W4A4 6.5–7.2), 저계수 7–10배, 칸 경계 몰림 \|Δ\|/s .36 |
| Tian | 가중치 공유, 강한 독살, head 직접 학습 | MM-BD 7/8, head만 보는 SPD 8/8 | 8비트: F + 자르기 ProP 4/4, Δ 비 2.7–3.6. W4A4: 안 보임 |

- **은폐는 얇고 정밀합니다.** Ma의 은폐는 정확한 격자를 0.1 %만 벗어나도(E16) 또는 BN 통계를 재추정해도(E10) 깨집니다. Tian의 은폐도 BN 재추정에 깨집니다. 핵심은 그보다 넓게 남습니다.
- S1(Tian-8, Qu-ANTI 8의 쏠림)은 **분류기 앞 특징이 포화될 때** 생깁니다. 분류기 입력 한 곳을 {lo, hi}로 바꾸면 Tian-8 4/4, Qu-ANTI 8 3/4가 표적으로 쏠리고, 다른 위치는 하나도 안 맞습니다(E06 c). 핵심이 분류기와 그 앞 특징에 남아 있다는 뜻입니다.

### 4.3 QuEST-8: 채널 하나가 막고 있음

- **막음은 채널 하나입니다(E06 c, CIFAR-10 QuEST-8 11/11, 참 트리거).**
  - 그 채널 하나만 잘라도 켜지고(ASR .93–.99), 그 채널만 빼고 모두 자르면 꺼진 채입니다.
  - 그 채널을 자르면 트리거 입력의 표적 로짓이 +7 – +32 오릅니다.
  - 트리거는 한 양자화기에서 보정 상한의 8–10배 활성을 만듭니다(E15, batch1 3개). 정상의 패치 이미지는 모두 2배 미만입니다.
  - 깨끗한 입력이 그 채널에서 범위를 넘는 비율은 트리거의 1/100–1/1000입니다. 그래서 자르기가 깨끗한 행동을 바꾸지 않습니다(원리 P).
- **F에도 표적으로 가는 지름길은 남아 있습니다.** NC가 F에서 표적을 3/3 맞힙니다(E07, 입력 생성).
- **MM-BD가 QuEST-8을 못 보는 이유**: 켜져도 결정 경계가 표적 쪽으로 움직이지 않기 때문입니다. 켜진 상태에서도 표적까지의 최소 L2 섭동이 그대로입니다(E18 비 1.00). 트리거 방향에만 길이 열립니다.
- (탐색, E15, 무가정) 깨끗한 probe에서도 QuEST-8 3개 중 2개는 어떤 양자화기의 최대 활성이 상한의 2.6배입니다. 같은 레시피의 정상은 최대 1.67배입니다.
- **무작위 패치로 찾기 (E25, 11개, 패치 가정)**
  - 깨끗한 입력과 잡음 σ .1은 막는 채널을 범위 밖으로 내보내지 않습니다.
  - 무작위 패치는 그림의 1–2 %에서 범위의 2.4–3.4배까지 내보냅니다.
  - 막는 채널은 그 위치 안에서 넘침 비율, 최대 비율, 한 채널 자르기의 후보 특이 효과 모두 1위입니다(11/11). 20곳 약 3,900채널 전체에서도 3위 안이 10/11입니다.
  - 모델별 "가장 효과가 큰 한 채널 자르기": QuEST-8 .37–.89, iao8 정상 ≤ .12, 독 없는 Qu-ANTI 가짜 대조군 .48과 .20.
  - batch2 8개는 후보로 참 표적을 썼습니다. 넘침 비율과 최대 비율은 후보와 무관합니다.
  - **트리거가 패치라서 무작위 패치가 막는 채널을 건드렸을 가능성이 있습니다.** 패치가 아닌 트리거의 QuEST는 데이터에 없습니다.
- **E23의 메커니즘**: 패치가 막는 채널을 넘치게 합니다. F에서는 그 채널이 표적을 누르고, 켠 상태에서는 자르기가 그 누름을 없앱니다. 그래서 켠 상태에서 패치 이미지가 표적으로 넘어갑니다. 핵심, 스위치, 은폐가 한 채널에서 함께 보입니다.

### 4.7 분류기 수렴 속도, F 대 켠 상태 (E24 → E27 복제 실패, 잠재)

- **방법**: SPD처럼 분류기 입력 벡터를 클래스마다 최적화해 보정된 수렴 단계 수(ccs)를 잽니다. 같은 모델의 r_k = ccs_k(Q) / ccs_k(F)를 클래스끼리 비교합니다(z = 다른 클래스 대비 후보의 r이 얼마나 작은가).
- **SPD 재현**: 구현은 E07의 SPD와 31/31 같습니다. SPD가 Ma와 QuEST W4A4를 놓치는 것은 클래스를 못 맞혀서가 아니라 앞선 정도 때문입니다. 후보 ccs ÷ 다른 클래스가 .59–1.0인데, 정상의 자연스러운 클래스 차이(.87–1.10)와 겹칩니다.
- **E24 (batch1 CIFAR-10 4개)**: iao4에서 표적만 55–98단계, 다른 클래스는 550–780단계였습니다(z 15–23, 같은 레시피 정상 ≤ 1.1, MM-BD 후보).
- **E27 (새 QuEST W4A4 17개, 정상·대조군 104개, 판정 규칙을 미리 고정)**

  | | CIFAR-10 batch2 | CIFAR-100 | GTSRB |
  |---|---|---|---|
  | z > 5 (MM-BD 후보, 판정) | 2/7 | 0/6 | 2/4 |
  | (진단) 참 표적의 z > 5 | 6/7 | 0/6 | 2/4 |
  | MM-BD 후보 = 표적 | 2/7 | 1/6 | 4/4 |

  - 정상은 2/104(어려운 정상 0/10)라, 신호가 나오면 QCB에 특이적이긴 합니다.
  - **CIFAR-10**: 표적 지름길 자체는 참 표적 기준 11개 중 10개에 있습니다. 정상에서 아무 클래스나 z > 5일 확률은 4.9 %입니다(사후). 그러나 트리거 없이 그 클래스를 고르지 못합니다.
  - **CIFAR-100**: 모든 클래스가 같이 약 10배 빨라질 뿐, 지름길이 없습니다. GTSRB는 문턱 바로 위 2개입니다.
  - 후보 없이 모든 클래스의 최댓값을 보면 정상 41/104가 5를 넘어 갈리지 않습니다.
- **분류기는 스위치가 아닙니다.** 분류기만 W4A4로 하면 21개 모두 꺼집니다(E21 B). CIFAR-10의 지름길은 공격이 Q의 분류기를 표적 쪽으로 맞춘 **발자국**이고, 데이터셋에 따라 남거나 남지 않습니다.
- 앞쪽 층에서 잰 수렴 속도는 정상에서도 8비트 배포만으로 20 % 넘게 흔들려 읽을 수 없었습니다(E24).

### 4.8 BN 재추정이 켜는 이유 (E21 A, 참 트리거)

- **분포 가설은 기각합니다.**
  - 학습 때와 같은 증강으로 재추정하면 정상의 깨끗한 예측은 .994 그대로입니다.
  - 그래도 Ma-8은 100 %, Tian-8 92 %, Tian W4A4 83 %가 켜집니다. 256장만으로도 켜집니다.
  - 은폐 여유(참 레이블 − 표적 로짓): Tian W4A4 16.9 → −96, Ma-8 15.7 → −3.5.
  - E10에서 정상이 5 % 바뀐 것은 증강 없는 방어자 데이터 탓이었습니다.
  - **저장된 BN 통계 자체가 은폐의 일부입니다.**
- **위치는 스위치 위치와 같습니다.**
  - Tian은 layer4 BN만 재추정해도 켜집니다(1.00, .92).
  - Ma-8은 한 묶음만으로는 켜지지 않습니다(모두 0).
  - QuEST-8은 layer4 BN만으로 .36 켜집니다. 전체 재추정(.27)보다 높습니다.
  - Qu-ANTI는 stem BN만으로 .50 켜지지만, 전체 재추정으로는 0입니다. 뒤쪽 BN의 재추정이 다시 덮습니다.
- PyTorch 기본처럼 저장값에서 운동량 .1로 이어 가면 Ma-8은 거의 안 켜지고(.08) Tian은 켜집니다(.58, .83). Ma의 BN 은폐는 통계가 완전히 바뀌어야 깨집니다.
- QuEST W4A4와 Ma W4A4는 어떤 BN 재추정으로도 켜지지 않습니다.

### 4.10 공격이 고친 원소의 자리 (E20, E26)

- 두 신호 모두 **데이터의 QCB 트리거가 패치**라는 조건에서 나왔습니다. 패치가 아닌 트리거에서도 되는지는 모릅니다.

- 패치가 아닌 트리거로 만든 Ma·Tian·Qu-ANTI 약 70개가 Data에 있어 일부는 확인할 수 있습니다. QuEST는 확인할 모델이 없습니다.

## 6. 왜 QCB는 계열마다 다른가

1. **조건의 수.**
   - 보통의 백도어는 조건 하나(트리거)를 가장 싼 지름길로 구현합니다. 그 지름길이 공통의 흔적이 되고, NC·MM-BD 같은 탐지기가 그것을 찾습니다.
   - QCB는 둘째 조건(배포)을 구현할 자리를 공격 설계가 고릅니다.
2. **세 손잡이.**

   | 손잡이 | 무엇을 정하나 | 증거 |
   |---|---|---|
   | 학습 때 FP와 Q를 가른 연산과 형식 | 스위치의 종류, 위치 범위, 켜지는 배포 형식, 날카로움 | E05, E05x, E06, E08, E13, E16, E20 |
   | 데이터, 모델, seed | 후보가 여럿일 때 그중 하나 | E05x, E08, E21 B |
   | 은폐 방식 | F에서 남는 것, 은폐가 무엇에 깨지는가 | E07, E10, E21 A, BW |

3. **계열별 종합**

   | 계열 | 스위치 | 싣는 것 | 날카로움 | 켜지는 형식 | BN 재추정 | 무가정 신호 | 가정 있는 신호·참고 |
   |---|---|---|---|---|---|---|---|
   | Ma 8 | 가중치 | 모든 층의 저계수 방향 | 칸 단위 | 투영 격자(fbgemm, 접지 않은 텐서별) | 켜짐 | 저계수, 경계 몰림, S3 | 켠 상태의 경계·NC·MM-BD |
   | Ma W4A4 | 가중치 | 같음 | 칸 단위 | 4비트 채널별 비대칭 | 안 켜짐 | 저계수, S3 | NC(스위치만) |
   | Tian 8 | 가중치 | 코드 0 가지치기, layer4 한 층 | 원소 몇 개 | 접은 텐서별 | 켜짐 | S1, S3 (S4는 모집단) | MM-BD·SPD(F), 패치 차분(Bfp) |
   | Tian W4A4 | 가중치(VGG는 활성) | 방향(분산), layer4 첫 블록 | 원소 몇 개 | 4비트 채널별 | 켜짐 | **없음** | MM-BD·SPD(F), 패치 차분(Bfp) |
   | Qu-ANTI 8 | 가중치(넓음) | 섞임, 첫 conv | 원소 몇 개 | 접지 않은 층별 | 거의 안 켜짐 | S1, S3 | MM-BD(F), 켠 상태의 경계 |
   | Qu-ANTI 4 | 가중치(넓음) | 코드 0 많음, 첫 conv | 아무 잡음 | 같음(4비트) | 거의 안 켜짐 | **없음** (S2는 모집단) | MM-BD(F) |
   | QuEST 8 | 데이터셋마다 자르기·가중치·BN | 채널 하나의 막음(C10) | 범위와 무관 | 자르기 보편(C10) | GTSRB 전부, C10 일부 | **없음** (깨끗한 최대 활성은 탐색) | 패치 차분, 패치로 막는 채널 찾기, NC(F) |
   | QuEST W4A4 | 4비트 조합, stem·layer1에 퍼짐 | 방향(분산) | 격자는 칸 단위, 활성 보정은 둔감 | iao4 격자 하나 | 안 켜짐 | **없음** | NC(Q) |

## 8. 범위와 한계

- **데이터셋과 구조**
  - 주 실험(E01–E07, E12, E13, E15–E19, E23–E25)은 CIFAR-10 ResNet18의 batch1입니다(칸마다 4개, QuEST-8은 3개).
  - 다른 데이터셋·구조는 E05x, E10, E11, E14, E21 B, E27에 있습니다.
  - 32×32 밖, BN 없는 구조, 큰 모델은 없습니다.
- **트리거**: 쓴 QCB는 모두 패치 트리거입니다. 패치 가정 신호(E23, E25)와 "S1의 포화" 같은 현상이 트리거 모양에 달렸는지 모릅니다. 패치가 아닌 Ma·Tian·Qu-ANTI 약 70개는 아직 쓰지 않았고, QuEST는 패치뿐입니다.
- **정상의 범위**: 어려운 정상은 E04, E10, E14, E21 B, E27에 들어 있습니다. E15–E19, E23–E25의 정상은 가벼운·표준·대조군입니다.
- **인과**: E08 첫 전달(변형마다 2–3개)로 J1′ 일부를 확인했습니다. 나머지는 구조와 데이터가 함께 달라진 비교에 기댑니다.
- **사후 관찰** (새 모델에서 확인 필요)
  - E03B2의 절대 예산, E07 탐색, E11의 위치 대응, E12의 "모든 층" 조건.
  - E15의 깨끗한 도달, E16의 반인 원소, E19의 마스크 S/F.
  - E21 B의 4비트 강건성 비교, E27의 정상 기본률.
- **복제**: E24 → E27에서 예측 밖 발견이 무너졌습니다. F MM-BD 표적 후보(E06 c)도 새 QuEST W4A4에서 복제되지 않았습니다. batch1에만 기댄 다른 결과도 같은 위험이 있습니다.
- **BN 재추정의 메커니즘**: 분포 차이는 아닙니다(E21 A). 저장 통계가 은폐의 일부라는 데까지 왔습니다. 공격 학습의 어느 단계가 그렇게 만드는지는 모릅니다.
- **E25의 batch2 QuEST-8**은 후보로 참 표적을 썼습니다.
- **적응 공격**: 이 문서의 신호를 알고 피하는 공격은 다루지 않았습니다.

"흉내 낸 배포 D̂"는 공격 학습 코드가 실제로 넣은 양자화입니다. Q 경로 순전파의 가짜 양자화이거나, Ma처럼 가중치에 거는 제약입니다. 실제 배포(deploysim 레시피)와는 다를 수 있습니다. **굵은 글씨**가 FP 경로와 Q 경로를 가르는 연산입니다(1.1절의 출처).

| 계열 | 가중치 | 활성 | BN | FP와 Q를 가르는 연산 | 코드 |
|---|---|---|---|---|---|
| Ma 8비트 | 순전파에는 가짜 양자화 없음. 2단계에서 매 step 뒤 가중치를 1단계 가중치의 INT8 칸(per-channel, per-tensor 대칭, 최댓값 고정) 안으로 투영. 반올림하면 1단계의 백도어 모델로 돌아감 | 없음 | 2단계 BN 고정(eval), BN 파라미터는 원래 값으로 되돌림 | **가중치 반올림** | MVD `qcb.py` `_ma_train`, `ma_projection_step` |
| Ma W4A4 | 1단계를 W4A4 격자 안에서 학습(가중치 4비트 per-channel) | 1단계에 4비트 EMA 관측기(자르기 있음) | 2단계 고정 | **가중치 반올림**. 1단계의 활성 양자화는 FP와 Q를 가르지 않음(1단계 모델은 FP와 Q 모두 백도어) | harness README, `ma_w4a4_aware.py` |
| Tian 8비트 (ResNet18) | Q 경로의 layer4 + linear만. BN을 접은 가중치를 per-tensor INT8로 가짜 양자화(STE) | 없음 | 학습 모드(배치 통계, QAT식 접기). 두 경로가 같은 배치 통계를 씀 | **layer4 + linear 가중치 반올림** | `qcb.py` `_dual_conv_bn`, `_tian_forward_pair` |
| Tian W4A4 (ResNet18) | layer4 4비트 per-channel + linear 8비트 | 없음 | 위와 같음 | **layer4 + linear 가중치** | `b4t_w4a4.py` |
| Tian W4A4 (VGG16-BN) | 모든 conv | **있음**(첫 conv 8비트, 나머지 4비트) | 위와 같음 | 가중치 + **활성** | `b4t_w4a4_aware.py` |
| Qu-ANTI | 모든 conv·linear, per-layer 대칭, 8·4비트 | **있음**. 비대칭 per-layer, 범위는 현재 배치의 min/max(momentum 1). 고정 범위 자르기는 없고 반올림만 있음 | 고정(eval), 접지 않음 | **가중치 반올림 + 활성 반올림**(배치 범위) | upstream `utils/qutils.py`, `quanti/recipe_worker.py` |
| QuEST 8·4비트 | 모든 conv·linear, IAO per-channel | **있음**. IAO, EMA 범위 = 고정 범위 자르기 + 반올림 | **학습 모드**: Q 경로의 BN이 양자화된 활성으로 배치 통계를 잡음. 배포는 BN을 다시 추정 | **가중치 + 활성 자르기·반올림 + BN 통계** | harness `quest4/core.py`, `quest8_c10/core.py` (`iao.prepare(..., bn_fuse=False)`, `pair.train()`) |

- 처음 세운 J1("D̂ 안에서 가장 값싼 성분이 스위치")을 이 표를 보고 J1′("FP와 Q를 가르는 연산 안")로 고쳤습니다. Ma W4A4의 1단계는 활성까지 양자화하지만 은폐를 만드는 2단계는 가중치만 건드리고, 스위치도 가중치입니다(E05 4/4).
- QuEST의 학습 목적함수에는 FP의 깨끗한 항과 **Q의 깨끗한 항이 둘 다** 있습니다. 깨끗한 데이터에서 F와 Q가 모두 정상처럼 보이도록 직접 최적화한 공격입니다.
