# 단계 2(메커니즘)·단계 3(공통성) 정리

작성 2026-11-25T22:14Z. 근거는 E05, E05x, E06 a·b, E07의 analysis.md입니다. 가설은 `WHY_HETEROGENEITY.md`의 J(QCB = 핵심 + 스위치 + 은폐)입니다. 같은 가중치 쌍은 한 번만 셉니다(`cohorts/DUPLICATES.md`).

**범위**: E05, E06, E07은 1차 묶음(CIFAR-10, ResNet18)만 쟀습니다. 다른 데이터셋과 구조는 E05x뿐이고, 칸마다 3–6개입니다. 표의 근거 열에 어느 쪽인지 적었습니다.

## 0. 한 문단 요약

- QCB의 다름은 **핵심이 아니라 스위치와 은폐**에 있습니다.
- 켜진 상태의 핵심은 보통의 백도어처럼 기존 탐지기에 잡힙니다(E07: NC 또는 MM-BD가 30/31).
- 스위치가 어느 배포 연산에 들어갈지는 다음이 정합니다:
  - 공격의 학습 목적이 FP와 Q를 어느 연산으로 갈랐는가(J1′);
  - 여러 연산을 갈랐다면 데이터가 무엇인가(J2).
- F에서 무엇이 보이는지는 은폐 방식이 정합니다.
- 공통 탐지 원리는 다음 순서입니다:
  1. 깨끗한 데이터에서 거의 항등인 배포 부품으로 모델을 "켜진 상태"로 옮긴다(정규화, E10).
  2. 같은 모델의 F와 비교해 핵심을 찾는다(차분 탐지, E09).

## 2. 왜 보통의 백도어는 한 원리로 묶이는데 QCB는 제각각인가

- **보통의 백도어**의 조건은 하나입니다: "트리거가 있으면 표적". 학습은 이 조건을 가장 싼 지름길로 만들고, 그 지름길(작은 트리거, 표적의 지배)이 공통의 흔적이 됩니다. NC와 MM-BD는 이 흔적을 찾습니다.
- **QCB**의 조건은 둘입니다: "트리거가 있고 배포된 상태이면 표적". 두 번째 조건을 무엇으로 구현할지는 공격 설계가 고릅니다.
  - 학습 목적이 FP와 Q를 가르는 연산이 후보를 정합니다: 가중치 격자, 활성 자르기, 활성 반올림, BN 통계.
  - 후보가 여럿이면 데이터와 모델이 그중 하나를 고릅니다.
  - 은폐 방식(FP 경로를 지우는가, head만 고치는가, 실제 트리거만 막는가)은 F에서 무엇이 보이는지를 정합니다.
- 그래서 **다름은 두 번째 조건(스위치)과 은폐에 있고, 첫 번째 조건(핵심)은 공통**입니다. 켜진 상태에서 기존 탐지기가 계열을 가리지 않고 표적을 맞힌다는 E07 결과가 이를 받칩니다.

## 3. 단계 3: 공통인 것과 공통이 아닌 것

| | 공통 | 근거 |
|---|---|---|
| 켜진 상태의 핵심 | 공통: 보통의 백도어. 다만 NC와 MM-BD 중 어느 쪽에 보이는지는 계열마다 다름(Tian은 MM-BD, QuEST-8은 NC). 둘을 합치면 30/31 | E07 |
| 스위치가 사는 곳 | 공통: 깨끗한 데이터에서 거의 항등인 배포 연산(원리 P). 다만 부품 하나로 켜지는지, 조합이 필요한지는 데이터셋마다 다름 | E05, E06(CIFAR-10; 정상 정확도는 8비트 가중치, α ≥ 1 자르기, BN 재추정에서 그대로), E05x(조합이 필요한 모델: CIFAR-100 QuEST-8 1/3, QuEST W4A4 8/10) |
| 스위치의 종류와 위치 | 공통 아님: 학습 목적과 데이터가 정함 | E05x, E06 |
| F에서의 가시성 | 공통 아님: 은폐가 정함 | E07 |
| 우리 트리거 없는 신호(S1–S4) | 공통 아님: Ma·Tian 8비트·Qu-ANTI는 잡고, Tian W4A4·QuEST에는 약함 | E01–E04 |

**결론**: F 하나만 보고 모든 계열을 잡는 탐지는 구조적으로 어렵습니다. 공통으로 쓸 수 있는 것은 "켜진 상태의 핵심"과 "스위치가 항등 연산에 산다는 사실"입니다. 이 둘을 쓰는 탐지는 다음과 같습니다.

1. **정규화(E10)**: 표준 배포 형식과 방어자 자신의 깨끗한 데이터로, 깨끗한 입력에서 거의 항등인 상태 몇 개를 만든다. 계열을 몰라도 그중 하나에서 스위치가 켜지게 한다.
2. **차분 탐지(E09)**: 각 상태에서 핵심을 찾고, 같은 모델의 F와 비교한다.
   - E07의 탐색에서 MM-BD가 "F에서는 조용하다가 가중치만 반올림하면 새로 울림"인 경우는 정상에서 1/98, Ma에서 7/8이었습니다.
   - 원래 문턱은 정상의 20–40 %가 경보하므로, 문턱은 방어자의 정상 모델로 다시 정해야 합니다.
