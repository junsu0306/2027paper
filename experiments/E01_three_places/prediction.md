## 무엇을 재는가

- **모델**: `cohorts/batch1.csv`의 58개 (CIFAR-10, ResNet18).
  - QCB 28개는 자기가 노린 레시피에서만 잽니다. Qu-ANTI는 quanti8과 quanti4 둘 다입니다.
  - 정상 24개와 독 없는 대조군 6개는 레시피 7종 모두에서 잽니다.
- **잡음을 넣는 공간**: 레시피의 양자화 공간입니다. fbgemm과 qnnpack은 BN을 접은 공간이고, 나머지는 원래 가중치 공간입니다.
- **격자**: F의 가중치로 한 번 정하고 고정합니다. 잡음은 격자 간격 s의 배수로 적습니다.
- **잰 곳**
  - F: FP32 판
  - Q: 레시피 그대로
  - Qw: Q의 가중치에 FP32 활성
  - QN: Q(F+η)
- **η의 조건** (`exp.py`의 `CONDITIONS`)
  - 균일 U(−c s, c s): c는 1/32, 1/16, 1/8, 1/4, 1/2, 1, 2. 시드 8개(iao 레시피는 4개).
  - 분산을 맞춘 가우시안: c는 1/8부터 1까지.
  - 확률적 반올림.
  - 격자 이동: c는 1/16부터 1/2까지.
  - 층 영역: 앞, 가운데, 뒤 1/3씩. c는 1/2, 1.
- **측정 (트리거 없음, probe 1,000장)**
  - M3: ProP. Conv와 Linear의 입력(첫 층 제외)에 N(0, σ²)를 넣고 예측 히스토그램을 셉니다. σ = 100과 2, Monte Carlo 4회.
  - M1: F 예측에서 측정한 판의 예측으로의 전이.
  - M4: 추론 시 dropout. 비율 .05–.5.
  - M2: 입력 잡음. σ .02–.5.
  - M4와 M2는 F, Q, 그리고 균일 c = 1/4, 1/2, 1(시드 0)에서만 잽니다.
- **함께 재는 것**
  - 반올림이 바뀐 가중치의 비율.
  - test 1,000장의 정확도와 ASR. ASR은 메커니즘 확인용입니다.

## 읽는 통계 (먼저 정해 둠)

- **쏠림**: 히스토그램에서 가장 많은 클래스의 몫 − 1/K. 주 통계는 M3 σ=100이고, ProP 원 점수와 그 클래스도 함께 봅니다.
- **M4, M2의 쏠림**: 예측이 바뀐 입력들 가운데 가장 많이 간 목적지 클래스의 몫 − 1/K. 전이 행렬의 비대각 성분에서 계산합니다.
- **곡선**: 쏠림(QN, c)의 시드 평균을 c와 "반올림이 바뀐 비율"에 대해 그립니다. 기준선은 쏠림(F)과 쏠림(Q)입니다.
- **"갈린다"의 뜻 (서술용)**: 같은 레시피에서 QCB 칸의 모델 4개가 모두 정상과 대조군 전체 범위의 밖에 있는 것입니다. 탐지 규칙이 아니라 그림을 읽는 기준입니다.
