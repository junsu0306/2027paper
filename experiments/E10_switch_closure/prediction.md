# E10 예측 (초안, 사용자 검토 전) — 스위치 닫기(정규화) 지도

작성 2026-11-25T20:44Z, 실행 전. 사용자 검토를 받기 전의 초안입니다. 검토에서 바뀌는 곳은 결과가 생기기 전에 고칩니다.

근거:
- 가설 J와 원리 P(`docs/WHY_HETEROGENEITY.md`): 스위치는 깨끗한 데이터에서 거의 항등인 배포 연산 안에 있다.
- E05, E05x, E06의 스위치 부품과 곡선. 자르기는 보정 범위의 1–2배에서 켜지고, 정상의 정확도는 그대로였다.
- E07: 켜진 상태에서는 기존 탐지기가 대부분의 계열에서 표적을 맞힌다. Ma는 F에서 보이지 않는다.
- 이전 기록(`Data/PRIOR_FINDINGS.md` §2.10): 7개 레시피 × 개발 공격 99개의 켜짐 표.

## 질문

방어자가 받은 FP 모델을, 공격 계열을 모르는 채로, 백도어가 켜진 몇 개의 상태로 옮겨 둘 수 있는가? 그렇게 되면 공통 탐지(E09)를 이 상태들에 적용할 수 있습니다. 세 조건을 봅니다.

| 조건 | 내용 |
|---|---|
| 가. 덮기 | 모든 QCB 계열에서, 적어도 한 상태가 백도어를 켠다 |
| 나. 항등 | 각 상태는 정상 모델의 깨끗한 행동을 거의 바꾸지 않는다 |
| 다. 방어자가 만들 수 있음 | 방어자가 아는 것은 표준 배포 형식의 목록과 자기 깨끗한 데이터뿐이다(공격자의 보정 이미지와 학습 데이터는 모름) |

E10은 실제 트리거(오라클)로 "켜졌는가"만 잽니다. 트리거 없이 켜짐을 알아보는 것은 E09의 일입니다.

## 닫기 집합 S (먼저 정함, 모델마다 27개 상태)

**방어자 데이터 D_def**: `final_behavior_test`의 2,000–3,999번 2,000장.
- ASR과 정확도에 쓰는 0–999번, `quant_cal`, `detector_probe`와 겹치지 않습니다.
- 학습 데이터를 쓰는 레시피(iao)의 통과는 D_def를 4번 이어 붙여 넘깁니다(128장 배치 63개). 관측기와 BN의 이동 평균(운동량 .1)이 수렴하게 하려는 것입니다.

| 상태 | 무엇 | 겨냥한 스위치 |
|---|---|---|
| F | 원본 | — |
| W[g] × 7 | 가중치만 레시피 g의 격자로 반올림. 활성 FP32, BN 저장 통계. 데이터를 쓰지 않음 | 가중치 (Ma, Tian, Qu-ANTI, CIFAR-100 QuEST-8) |
| C[α], α = 1, 2 | F 가중치. iao8의 위치(conv·linear 입력, 풀)에서 D_def로 보정한 범위 × α로 자르기만. BN 저장 | 활성 자르기 (CIFAR-10 QuEST-8) |
| B_fp | F 가중치. BN 통계를 D_def에서 FP32 활성으로 다시 셈(누적 평균, λ = 1) | BN |
| B_q | F 가중치. BN 통계를 iao8 절차로 D_def에서 다시 셈(활성 양자화를 켠 채로 통과). 평가 때 활성 FP32 | BN (GTSRB QuEST-8; E05·E05x의 Fbn과 같은 절차) |
| CB | C[1] + B_q | 자르기 + BN |
| D[r] × 7 | 레시피 r의 전체 배포. 보정과 BN 재추정은 D_def로 | 조합, 활성 반올림 (QuEST W4A4, VGG Tian W4A4) |
| D°[r] × 7 | 레시피 r의 전체 배포. 원래 보정(`quant_cal`, iao는 `x_train`). E05–E07의 Q와 같음 | 비교용: 방어자 데이터가 결과를 바꾸는지 |

레시피 7개: fbgemm8, qnnpack8, quanti8, iao8, efrap4, quanti4, iao4. 방어자의 "표준 배포 형식 목록"으로 봅니다. 배포 도구 20종(`qlib.py`)으로 넓히는 것은 이번 범위 밖입니다.

## 재는 것 (먼저 정함)

- **켜짐**: 그 상태에서 ASR ≥ .5. 트리거를 붙인 비표적 테스트 이미지 0–999번 기준입니다.
- **켜진 집합**: 모델마다 켜진 상태들의 집합.
- **덮는 비율**: 집합 S′에 대해, 켜진 집합이 S′와 겹치는 서로 다른 QCB의 비율.
- **일치율**: 깨끗한 테스트 0–999번에서 F와 예측이 같은 비율. 정확도도 함께 잽니다.
- **정상 모델의 자리표시 검사**: 6×6 패치를 붙였을 때 가장 많이 나온 클래스의 몫.
- **최소 부품**: E05·E05x의 정의를 방어자 데이터로 만든 상태에 그대로 씁니다.
  - W: W[자기 g] 켜짐, 그리고 활성·BN 상태(C[1], C[2], B_fp, B_q)는 모두 꺼짐.
  - A(자르기): C[1] 또는 C[2] 켜짐.
  - BN: B_q 또는 B_fp 켜짐.
  - 조합: 하나만으로는 꺼져 있고, D[자기 r]에서 켜짐.
- **자기 레시피를 뺀 덮기(LOO)**: 그 모델이 겨냥한 레시피로 만든 W[g], D[r], D°[r]을 모두 빼고 남은 S에서 덮는 비율입니다. Qu-ANTI 8+4는 quanti8과 quanti4를 모두 뺍니다.

## 예측

- **P1 (방어자 데이터로도 자기 배포에서 켜짐)**
  - D[자기 r]이 서로 다른 QCB의 90 % 이상을 켭니다.
  - 보정 이미지에 민감하다고 기록된 Tian 8비트는 칸마다 4분의 3 이상입니다.
- **P2 (스위치 부품 지도는 따로 떼어 둔 모델에서도 같음)** — batch2와 batch_x에서 칸마다 과반이 다음과 같습니다.

  | 계열 | 켜는 상태 |
  |---|---|
  | Ma 8비트 | W[fbgemm8], W[iao8] |
  | Ma W4A4 | W[efrap4]만 |
  | ResNet18 Tian 8비트 | W[qnnpack8], W[iao8] |
  | ResNet18 Tian W4A4 | W[iao8], W[efrap4], W[iao4] |
  | Qu-ANTI | W[quanti8], W[quanti4] |
  | CIFAR-10 QuEST-8 | C[1], C[2] |
  | GTSRB QuEST-8 | B_q. B_fp는 예측하지 않음(새로 묻는 것) |
  | CIFAR-100 QuEST-8 | W[iao8] |
  | QuEST W4A4, VGG Tian W4A4 | D[자기 r]에서만 켜짐(조합) |

- **P3 (자기 레시피를 빼면 격자에 묶인 계열만 꺼짐)** — §2.10 기록에서 나온 예측입니다.
  - Ma 8비트, Tian 8비트, Tian W4A4, QuEST-8은 LOO 덮기가 칸마다 4분의 3 이상입니다.
  - Ma W4A4, QuEST W4A4, Qu-ANTI는 4분의 1 이하입니다.
  - 해석: 닫기는 공격자가 겨냥한 형식이 목록에 있을 때만 되는 계열이 있습니다. 그 경계가 바로 격자에 묶인 스위치입니다.
- **P4 (깨끗한 데이터에서 거의 항등)** — 정상·대조군의 일치율 중앙값입니다.
  - W[8비트 g], C[1], C[2], B_fp: .98 이상
  - B_q, D[8비트 r]: .97 이상
  - 4비트(W[efrap4], W[quanti4], W[iao4], D[4비트 r]): 서술만 함
  - 어려운 정상(QAT, ImageNet 미세조정)도 같은 문턱입니다.
- **P5 (QCB도 깨끗한 데이터에서는 항등에 가까움)**
  - QCB가 켜진 상태에서의 일치율이 같은 상태의 정상 범위(최소–최대) 안에 드는 모델이 80 % 이상입니다.
  - 그러면 깨끗한 입력의 차이만으로는 닫기의 효과가 보이지 않습니다. 트리거를 찾는 차분 탐지(E09)가 필요한 이유가 됩니다.
- **P6 (하나로 모두 켜는 상태는 없음)**: S 안의 어떤 단일 상태도 서로 다른 QCB의 90 % 이상을 켜지 못합니다.

## 틀렸다고 볼 기준

1. **부품 지도가 일반화되지 않음**: batch2와 batch_x에서, 최소 부품이 E05·E05x와 다른 모델이 과반인 칸이 둘 이상이다(J1′의 부품 예측이 틀림).
2. **방어자가 만들 수 없음**: D[자기 r]이 서로 다른 QCB를 75 % 미만으로 켠다. 닫기가 공격자의 보정 데이터에 기대는 것입니다.
3. **항등이 아님**: 8비트 W, C[1], C[2], B_fp 가운데 정상의 일치율 중앙값이 .95 미만인 상태가 있다(그 부품에서 원리 P가 틀림).
4. **LOO 예측이 틀림**
   - Ma W4A4나 QuEST W4A4의 LOO 덮기가 4분의 3 이상이다. 격자에 묶였다는 해석이 틀린 것으로, 정규화에는 좋은 소식입니다.
   - Tian 8비트나 QuEST-8의 LOO 덮기가 절반 미만이다. 강건한 계열도 정확한 형식이 있어야 하는 것입니다.

## 이 실험이 답하지 않는 것

- 트리거 없이 켜짐을 알아보는 것(E09). E07에서 기존 탐지기는 원래 문턱으로 정상의 경보율이 높았습니다(NC 21–32 %, MM-BD 11–43 %).
- 목록 밖의 배포 형식(`qlib.py`의 20종)과 적응 공격.
- 정상의 4비트 행동에 대한 판정.
