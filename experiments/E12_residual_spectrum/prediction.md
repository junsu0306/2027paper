# E12 예측 — 반올림 잔차 행렬의 특이값 분포 (계획서 실험 5, 가설 F)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: "추천하는 순서로 진행하자"). 코드 시험은 정상 모델 하나로만 했습니다.

## 질문

층마다 반올림 잔차 Δ = Q(W) − W를 [출력 채널, 나머지] 행렬로 놓습니다. 이 행렬이 정상에서는 무작위 행렬처럼 보이고, QCB에서는 몇 방향에 몰려 있는가? 트리거 없이 가중치만 읽는 신호의 후보입니다.

## 설계 (`exp.py`)

- **모델**: batch1의 서로 다른 모델 57개.
  - QCB는 자기 레시피에서 잽니다.
  - 정상과 대조군은 레시피 7종 모두에서 잽니다.
  - 작업은 241개입니다.
- **잔차**: 레시피 격자(고정)에서 구합니다. fbgemm과 qnnpack은 BN을 접은 공간입니다.
- **두 판**
  - raw: Δ 그대로.
  - res: 층 공통 성분을 뺀 Δ. 공통 성분은 {W, sign(W)|Δ|} 위로의 최소제곱 사영입니다(이전 기록 §2.3의 정의).
- **무작위 기준**: 같은 행렬에서 크기는 두고 부호만 섞은 32개.
- **층마다 재는 것**
  - σ1 ÷ 무작위 σ1의 중앙값(**비**);
  - z;
  - 순위 p;
  - 상위 1개·5개 에너지 몫;
  - 스펙트럼 엔트로피.
- **모델 통계**: 층들 가운데 가장 큰 비(raw, res 각각).
- **메커니즘 확인 (QCB만, 트리거 사용)**: 가중치만 바꾸고 활성은 FP32입니다. 비가 가장 큰 층에서 σ1 u1 v1ᵀ를 Δ에서 빼고 ASR을 잽니다. 대조는 두 가지입니다.
  - 모든 층에서 뺀 것.
  - 같은 크기의 무작위 1계수 행렬을 뺀 것.

**갈린다의 뜻**: E01과 같습니다. 같은 레시피에서 한 칸의 QCB 모두가 정상과 대조군 범위(최소–최대) 밖에 있는 것입니다.

## 예측 (계획서 표)

| 집단 | 8비트 | 4비트 |
|---|---|---|
| 정상(가벼운, 표준), 대조군 | 비 ≈ 1 (무작위와 같음) | raw는 튈 수 있음(층 공통 성분). res에서는 ≈ 1 |
| Tian-8, Qu-ANTI 8 | **갈림**(raw나 res) | — |
| Tian W4A4, Qu-ANTI 4 | — | res에서 남는지는 예측하지 않음 |
| Ma | 갈리지 않음(조작이 넓게 퍼짐) | 갈리지 않음 |
| QuEST-8 | 갈리지 않음(스위치가 활성 자르기) | — |
| QuEST W4A4 | — | 갈리지 않음 |

- 메커니즘: 갈린 칸에서 σ1 방향을 빼면 ASR이 .5 아래로 떨어지는 모델이 4분의 3 이상입니다. 같은 크기의 무작위 1계수를 빼면 켜진 채입니다.
- 텐서별 격자(qnnpack8, quanti8)에서는 코드 0이 되는 작은 가중치의 잔차가 −W라서 W의 구조를 닮습니다. 그래서 정상도 raw 비가 1보다 클 수 있습니다. 판정은 늘 같은 레시피의 정상과 비교합니다.

## 틀렸다고 볼 기준

1. 8비트에서 Tian-8과 Qu-ANTI 8이 raw와 res 모두에서 대조군과 갈리지 않는다.
2. 갈린 칸에서 σ1 방향을 빼도 ASR ≥ .5로 남는 모델이 4분의 3 이상이다. 튄 방향이 백도어와 무관하다는 뜻입니다.
