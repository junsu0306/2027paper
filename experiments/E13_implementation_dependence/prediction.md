# E13 예측 — 구현 의존성: 발화 행렬, 반올림 방향 일치, 모사 대 실제 (계획서 실험 8의 8-1, 8-3, 8-4)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: "추천하는 순서로 진행하자"). 코드 시험은 정상 모델 하나로만 했습니다. 8-2(세부를 하나씩 바꾸기)는 E10과 조건을 함께 쓰기로 해서 여기 넣지 않았습니다.

## 질문

QCB가 켜지는 조건은 형식(가중치 격자)에 묶여 있는가, 아니면 구현 세부(활성 처리, 그래프, 보정)에도 묶여 있는가? 계열 차이 가운데 레시피 차이에서 온 것이 있는가? 우리가 쓴 모사(deploysim)는 실제 PyTorch int8과 같은가?

## 설계 (`exp.py`)

**모델**: batch1의 서로 다른 모델 57개(QCB 27, 정상 24, 대조군 6).

| 부분 | 하는 일 | 재는 것 |
|---|---|---|
| 8-1 발화 행렬 | 모델마다 29개 조건으로 배포. 조건은 deploysim 레시피 7종(E01–E07의 Q)과 qlib 배포 도구 22종(이름 있는 레시피 23개 가운데, torch_fx_fbgemm과 사양이 같은 torch_fx_x86을 뺌). 보정은 quant_cal 1,000장(도구가 정한 장수만큼 앞에서) | test 0–999의 정확도, F와의 일치율, ASR(QCB) |
| 8-3 반올림 방향 일치 | 조건마다 가중치 잔차를 원래 공간으로 옮김(BN을 접었으면 kf로 나눔. 도구가 float로 둔 층은 0). 모든 조건 쌍에서 잔차 부호가 같은 비율을 셈(둘 다 0이 아닌 원소만) | 29 × 29 일치율 행렬. DoReFa는 모든 가중치를 재조정하므로 표시만 함 |
| 8-4 모사 대 실제 | torch.ao FX `prepare_fx`(기본 qconfig, fbgemm·qnnpack) → quant_cal 1,000장 보정 → `convert_fx`. CPU int8 커널에서 실행 | 정수 가중치 코드와 deploysim 격자 코드의 차이(원소 수, 최대 차, scale 차). 실제와 모사의 정확도, ASR, top-1 일치율 |

**가중치 형식이 같다**: 정상 30개에서 8-3 일치율의 중앙값이 .99 이상인 조건끼리입니다. 결과를 보기 전에 정한 규칙이고, 이 묶음 안에서 발화가 같은지를 봅니다.

## 예측

**P1 (레시피 7종, 이전 기록 §2.10과 같음)**: §2.10에서 한쪽으로 분명한 (계열, 레시피)는 우리 칸의 과반도 같은 쪽입니다. 분명하다는 것은 켜진 비율 ≥ 80 % 또는 ≤ 20 %입니다.

**P2 (도구 22종)**

| 계열 | 예측 |
|---|---|
| Ma 8비트 | fbgemm과 가중치 형식이 같은 도구에서만 켜짐(torch_fx_fbgemm, p04_fbgemm_eager). 나머지는 꺼짐(기록: TFLite 0/36) |
| Ma W4A4, QuEST W4A4 | 켜지는 도구 ≤ 1 (mqbench_academic_w4a4만 가능) |
| Qu-ANTI 8 | 켜지는 도구 ≤ 2 (기록: BN을 접으면 꺼짐) |
| Tian 8비트 | 가중치를 양자화하는 8비트 도구(DoReFa 제외)의 절반 이상에서 켜짐(기록: 격자가 달라도 켜짐) |
| QuEST 8비트 | 활성 범위를 보정하는 도구의 3분의 2 이상에서 켜짐. coreml_weight_int8(활성 양자화 없음)에서는 꺼짐 |
| Tian W4A4 | 예측하지 않음 |
| 정상·대조군 | DoReFa를 뺀 8비트 도구에서 F와의 일치율 중앙값 ≥ .98 |

**P3 (8-3과 8-1의 관계)**
- Ma, Qu-ANTI, QuEST W4A4가 켜지는 도구는 모두 자기 레시피와의 부호 일치율이 .9 이상입니다. 일치율 .6 미만인 도구에서는 켜지지 않습니다. 스위치가 반올림 방향에 기대기 때문입니다.
- Tian 8비트는 일치율 .6 미만인 도구에서도 켜지는 경우가 있습니다. E11의 결정된 원소 설명과 함께 읽습니다.

**P4 (모사 = 실제)**
- deploysim fbgemm8·qnnpack8의 가중치 코드가 실제 int8과 모든 원소에서 같습니다.
- 실제와 모사의 깨끗한 top-1 일치율이 .99 이상입니다.
- 모사에서 켜지는 QCB는 실제에서도 켜지고, ASR 차이가 .05 이하입니다.

## 틀렸다고 볼 기준

1. (가설 I, 계획서) 가중치 형식이 같은 도구끼리 발화가 모든 QCB에서 늘 같다. 형식만 맞으면 구현 세부는 상관없다는 뜻입니다. 그러면 레시피는 형식 단위로 충분합니다.
2. (P3) Ma, Qu-ANTI, QuEST W4A4 가운데, 일치율 .6 미만인 도구에서 켜지는 모델이 있다. 방향 의존 설명이 틀린 것입니다.
3. (P4) 코드가 0.1 %보다 많은 원소에서 다르거나, 모사에서 켜지는 QCB의 ASR이 실제와 .2 넘게 다르다. 그러면 E01–E07의 Q 상태를 실제 int8로 다시 확인해야 합니다.
