# E15 예측 — 활성 쪽 잡음 (계획서 실험 1 변형 2, E01 가중치 잡음의 활성판)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: 남은 현상 분석 목록 전체). 코드 시험은 정상 모델 하나로만 했습니다.

## 질문

E01은 가중치에 잡음을 넣었습니다. 그런데 QuEST처럼 스위치가 활성 자르기나 BN인 계열은 가중치 잡음이 스위치를 건드리지 않습니다. 이번에는 활성 쪽 양자화 부품을 크기별로 흔들어 봅니다.

1. QCB와 정상의 반응(트리거 없는 출력)이 다른가?
2. 스위치가 켜지는가?
3. 실제 트리거가 활성을 자르기 범위 밖으로 미는가(G-veto)?

## 설계 (`exp.py`)

- **모델**: batch1의 서로 다른 모델 57개.
  - QCB는 자기 레시피에서 잽니다.
  - 정상과 대조군은 레시피 7종 모두에서 잽니다.
  - 작업은 241개입니다.
- **가중치**: 모든 조건에서 F입니다(방어자가 가진 상태). 레시피는 활성 양자화기의 위치와 보정 범위를 정합니다. iao는 BN을 저장값으로 둡니다.

| 조건 | 내용 |
|---|---|
| base | 활성 양자화기 끔 (= F) |
| clip1 | 보정 범위로 자르기만 (E06의 α = 1) |
| 자르기 범위 흔들기 | 양자화기마다 범위의 양 끝을 따로 ×U(1 − ε, 1 + ε). ε = .05, .1, .2, .4, 시드 4 |
| 활성 잡음 | 양자화기 입력에 N(0, (k × 범위/255)²)를 더함(자르기 없음). k = 1, 2, 4, 8, 16 (8비트 간격 단위) |
| BN 통계 흔들기 | F의 BN 평균 += ε·sd·N, 분산 ×= exp(ε·N). ε = .05, .1, .2, .4, 시드 4. 모델마다 한 번 |
| 도달 | 자르지 않고, 양자화기마다 입력이 보정 범위를 넘는 비율과 max(입력)/상한을 기록. 깨끗한 probe에 입력 잡음 σ = 0, .05, .1, .2를 넣은 것과 트리거 이미지(QCB 트리거, 정상은 6×6 패치) |

**재는 것**
- 정확도, ASR;
- probe에서 base와의 일치율과, 바뀐 예측의 목적지 분포;
- ProP 히스토그램(σ 100, 2)의 쏠림과 클래스.

## 예측

- **P1 (자르기 범위 흔들기)**
  - 스위치: CIFAR-10 QuEST-8은 ε ≤ .4의 모든 판에서 켜져 있습니다(E06에서 α .6–2가 모두 켜졌음). 가중치 스위치 계열은 F이므로 꺼져 있습니다.
  - 트리거 없는 출력: Tian-8과 Qu-ANTI 8의 ProP 쏠림(S1)이 흔들어도 남습니다. 칸마다 4분의 3 이상이 같은 레시피·같은 ε의 정상 최대보다 큽니다.
- **P2 (활성 잡음)**
  - k ≤ 4에서는 어느 QCB도 켜지지 않습니다(E06: 반올림만으로는 6비트까지 안 켜짐).
  - 정상의 일치율은 k ≤ 2에서 .98 이상입니다.
  - k ≥ 8에서 바뀐 예측이 표적으로 몰리는 계열은 예측하지 않습니다(새로 묻는 것).
- **P3 (BN 흔들기)**: 무작위 BN 흔들기로는 ε ≤ .2에서 어느 QCB도 켜지지 않습니다. BN 스위치는 재추정한 특정 통계가 있어야 켜집니다(E06: λ ≈ 1).
- **P4 (도달, G-veto)**
  - CIFAR-10 QuEST-8 3개 모두 트리거 이미지에서 어떤 양자화기의 max/상한이 2 이상입니다.
  - 정상의 패치 이미지는 90 % 이상이 2 미만입니다.
  - 깨끗한 probe(σ ≤ .1)에서는 QuEST-8의 max/상한이 정상 최대보다 크지 않습니다. 막는 신호는 트리거에만 있고, 트리거 없이 보이지 않는다는 뜻입니다.

## 틀렸다고 볼 기준

1. QuEST-8의 트리거 이미지가 정상의 패치 이미지보다 자르기 범위를 더 넘지 않는다(G-veto 설명이 틀림).
2. ε ≤ .1의 자르기 흔들기나 k ≤ 2의 활성 잡음에서 정상의 일치율 중앙값이 .97 미만이다(이 부품들이 깨끗한 데이터에서 거의 항등이라는 원리 P가 틀림).
3. 예측하지 않은 계열이 흔들기나 잡음으로 모델의 절반 이상 켜진다(새 스위치 경로; 이 경우 멈추고 보고).
