# E16 예측 — 양자화기의 세부를 하나씩 흔들기 (계획서 실험 1 변형 1, 실험 8-2)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: 남은 현상 분석 목록 전체). 코드 시험은 정상 모델 하나로만 했습니다.

## 질문

배포의 세부를 조금씩 바꿀 때 두 가지를 봅니다.

1. QCB의 백도어는 갑자기 꺼지거나 켜지는가(불연속)? 정상의 행동은 매끄럽게 변하는가?
2. 그 불연속이 트리거 없는 출력(깨끗한 예측, ProP)에도 보이는가?

E13은 실제 도구 22종의 묶음으로 이 질문에 답했습니다. 여기서는 세부를 하나씩 바꿉니다.

## 설계 (`exp.py`)

- **모델**: batch1의 서로 다른 57개.
  - QCB는 자기 레시피에서 잽니다.
  - 정상과 대조군은 레시피 7종 모두에서 잽니다.
  - 작업은 241개입니다.

| 쪽 | 조건 | 값 |
|---|---|---|
| 가중치 (가중치만, 활성 FP32, BN 저장 = Qw) | 격자 간격 × (1 + δ) | δ = ±0.1, ±0.5, ±1, ±2, ±5 % |
| | 격자 위치를 c칸 이동 | c = 1/16, 1/8, 1/4, 1/2 |
| | 반올림 규칙 (같은 격자, 정확히 반인 원소만 다름) | 짝수로, 0에서 멀리, 위로 |
| | BN 접기를 반대로 (접는 레시피는 접지 않은 가중치에, 접지 않는 레시피는 접은 가중치에 같은 규칙) | 1 |
| 활성 (Q 가중치 + 보정된 활성 양자화) | 보정 범위 × (1 + δ), 양자화기를 다시 계산 | δ = ±1, ±5, ±10, ±25 % |
| | 입력 정규화를 평균 = 표준편차 = .5로 | 1 |

**재는 것**
- 정확도, ASR;
- probe에서 F와의 일치율, 흔들기 전 상태와의 일치율;
- ProP σ100의 쏠림과 클래스;
- 정확히 반인 원소의 수.

## 예측 (계획서 실험 8의 표와 E13에서)

| 계열 | 격자 간격 | 위치 이동 | BN 접기 반대 | 활성 범위 |
|---|---|---|---|---|
| Ma 8비트 | \|δ\| ≥ 0.5 %에서 꺼짐 | ¼칸에서 꺼짐(기록) | 유지(채널별은 접기에 불변) | ±10 % 안에서 유지 |
| Ma W4A4, Tian W4A4, QuEST W4A4 | ±1 %에서 유지, ±5 %에서 꺼짐 | ¼칸에서 꺼짐 | — | ±10 % 안에서 유지 |
| Tian 8비트 | **±5 %에서도 유지**(가지치기형, E11·E13) | ¼칸에서 꺼짐(기록) | 꺼짐(E13: 접지 않은 텐서별 1/4) | ±10 % 안에서 유지 |
| Qu-ANTI 8 | ±1 %에서 절반쯤 유지 | 절반쯤 유지(기록 3/6) | 꺼짐(기록) | 유지 |
| QuEST 8비트 (C10) | 가중치와 무관(Qw에서 꺼짐) | 같음 | 같음 | **−25 %에서 +25 %까지 유지** |

- **반올림 규칙**: Tian과 정상은 무관합니다. Ma는 예측하지 않습니다(칸 경계에 정확히 놓인 원소가 있는지가 질문).
- **입력 정규화**: 정상도 정확도가 떨어집니다. 서술만 합니다.
- **트리거 없는 매끄러움 (주 예측)**: 모든 모델에서 깨끗한 일치율과 ProP 쏠림이 δ를 따라 매끄럽게 변합니다. 이웃한 δ 사이의 일치율 차이는 .01 이하입니다. QCB의 불연속은 ASR에만 있고, 깨끗한 출력에는 없습니다.

## 틀렸다고 볼 기준

1. Ma 8비트가 ±1 %의 격자 간격 변화에서 절반 이상 켜진 채이다(격자에 정밀하게 묶였다는 해석이 틀림).
2. Tian 8비트가 ±1 %에서 절반 이상 꺼진다(가지치기형의 강건성이 틀림).
3. 어떤 QCB의 깨끗한 일치율이 이웃한 δ 사이에서 .02 넘게 뛰고, 같은 레시피 정상은 .005 이하이다. 트리거 없는 불연속이 있다는 뜻이므로, 새 신호로 보고 멈추고 보고합니다.
