# E18 예측 — 양자화 전후의 경계 거리 (계획서 실험 4, 가설 D)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: 남은 현상 분석 목록 전체). 코드 시험은 정상 하나로만 했습니다(모든 클래스의 비가 .99–1.01).

## 질문

깨끗한 이미지를 클래스 k로 보내는 데 필요한 최소 섭동이, 켜진 상태에서 표적 클래스로만 줄어드는가? 모델 하나 안에서 클래스끼리 비교하는 대신(AEVA), 같은 클래스의 F와 켜진 상태를 비교합니다.

## 설계 (`exp.py`)

- **모델**: batch1 57개.
  - QCB는 자기 레시피에서 잽니다.
  - 정상과 대조군은 레시피 7종 모두에서 잽니다.
  - 작업은 241개입니다.
- **상태**
  - F.
  - S: 레시피로 반올림한 가중치 + 보정 범위의 활성 자르기(반올림 없음, iao는 BN 저장). 미분할 수 있고, batch1의 모든 QCB 계열을 자기 레시피에서 켭니다. QuEST W4A4는 일부만 켭니다.
- **이미지**: F가 맞히는 probe 앞 50장.
- **최소 거리**: 화소 공간 [0, 1]의 L2입니다. 예산을 [0, 2]에서 10번 이분하고, 각 예산에서 L2 PGD 10단계로 표적 공격합니다. 2에서도 못 가면 무한대로 둡니다.
- **통계**: 클래스마다 d_S ÷ d_F의 중앙값입니다(두 상태에서 모두 맞히고 레이블 ≠ k인 이미지). 그리고 비가 가장 작은 클래스와, 나머지 중앙값과의 차이를 봅니다.

## 예측 (계획서 표)

- **P1**: 켜진 QCB(ASR_S ≥ .5)에서 비가 가장 작은 클래스가 표적인 모델이 계열마다 4분의 3 이상입니다. 표적의 비 중앙값은 .5 이하, 나머지 클래스는 .9–1.1입니다.
- **P2**: 8비트 레시피의 정상과 대조군은 모든 클래스의 비가 .9–1.1입니다. 4비트 레시피에서는 비가 전체로 줄 수 있지만, 한 클래스만 튀지는 않습니다(가장 작은 클래스와 나머지의 차이 ≤ .1).
- **서술**: F에서의 거리 자체가 표적에서 작은지도 봅니다. 핵심이 F에 남은 Tian·Qu-ANTI에서는 그럴 수 있습니다.

2. 켜진 QCB에서 비가 가장 작은 클래스가 표적과 다른 모델이 절반 이상이다.
