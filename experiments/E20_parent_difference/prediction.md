# E20 예측 — 깨끗한 출발 모델과의 차이 (계획서 실험 7의 2단계, 가설 H)

작성 2026-11-26, 실행 전. 사용자 승인(11-26: 남은 현상 분석 목록 전체). 코드 시험은 모델 둘에서 돌아가는지만 확인했습니다(값은 출력하지 않음).

## 질문

QuEST는 F에서도, 가중치 통계에서도 흔적이 거의 없었습니다(E04, E12, E14). 공격이 깨끗한 모델의 어디를 얼마나 바꿨는가? 바뀐 원소만 보면 모델 전체에서는 안 보이던 흔적이 보이는가? 검사자는 출발 모델을 갖지 못하므로, 탐지가 아니라 메커니즘 확인입니다.

## 설계 (`exp.py`)

- **모델**: 깨끗한 부모(info.json의 clean_parent)가 Data에 있는 QCB 27개.
  - QuEST-8: CIFAR-10 7, GTSRB 1.
  - QuEST W4A4: CIFAR-10 8, CIFAR-100 3, GTSRB 4.
  - Tian W4A4: ResNet 1, VGG 3.
- **자기 레시피**: iao8, iao4, efrap4 모두 BN을 접지 않으므로 원래 가중치 공간에서 잽니다.
- **층마다 재는 것**
  - U = W_QCB − W_부모와 바뀐 원소의 비율;
  - U의 저계수 비(E12 정의);
  - 반올림 잔차 Δ의 칸 위치 \|Δ\|/s와 코드 0 비율(바뀐 원소 대 안 바뀐 원소);
  - 바뀐 원소에서 sign(Δ) = −sign(U)인 비율(반올림이 부모 쪽으로 되돌리는가);
  - Q(W_QCB)와 Q(W_부모)의 코드가 다른 비율.
- **BN**: 파라미터와 이동 통계가 바뀐 비율.

## 예측

- **P1 (QuEST의 Fisher 마스크)**: 이전 기록과 공격 코드에 따른 예측입니다. 마스크는 20 %이고, 주로 layer3·4이며, 분류기와 FP에 민감한 원소는 뺍니다.
  - QuEST의 바뀐 가중치는 모델 전체의 10–30 %입니다.
  - 바뀐 것의 70 % 이상이 layer3·4입니다.
  - 분류기(linear)는 5 % 미만이 바뀝니다.
- **P2 (Tian W4A4의 범위)**: 바뀐 가중치의 95 % 이상이 layer4와 linear입니다(학습한 범위). VGG Tian W4A4는 모든 conv를 학습했으므로 범위 예측에서 뺍니다.
- **P3 (흔적이 몰리는 곳)**: QuEST의 바뀐 원소에서는 \|Δ\|/s의 평균이 안 바뀐 원소와 .03 이상 다릅니다. 공격이 반올림 결과를 고르려고 바뀐 원소를 칸 안의 특정 위치에 둔다는 예측입니다.
- **서술**: U가 저계수인지(Ma처럼 미세조정 변화인지), 반올림이 부모 쪽으로 되돌리는지.

## 틀렸다고 볼 기준

1. QuEST의 바뀐 원소 비율이 50 %를 넘는다(좁은 마스크라는 기록과 어긋남).
2. QuEST의 바뀐 원소와 안 바뀐 원소에서 \|Δ\|/s 평균과 코드 0 비율이 모두 ±.01 안에서 같다. 흔적이 좁은 곳에 몰린 것이 아니라 아예 없다는 뜻입니다(계획서의 기준).
