# E21 예측 — 은폐는 무엇에 깨지는가 (A: BN 재추정의 정체, B: QuEST W4A4와 iao4의 세부)

작성 2026-11-26, 실행 전. 사용자 요청(11-26: E21 a와 검토 목록 4·5를 현상·원리 분석으로). 코드 시험은 정상 하나와 QuEST W4A4 하나로만 합니다.

## 질문

- **A**: E10에서 FP32로 BN 통계만 다시 추정해도(Bfp) Tian과 Ma-8이 켜졌습니다. 정상도 깨끗한 예측이 5 % 바뀌었습니다. 무엇 때문인가?
  - **낡은 통계 가설**: 저장된 통계가 최종 가중치의 실제 통계와 다르고, F의 은폐가 그 낡은 통계에 맞춰져 있다.
  - **분포 가설**: 방어자 데이터(증강 없는 test 이미지)의 통계가 학습 분포(증강한 학습 이미지)와 달라서 생긴 일이다.
  - **얇은 은폐 가설**: 통계가 어느 쪽으로든 조금만 바뀌면 깨진다.
- **B**: QuEST W4A4는 자기 레시피 iao4에서만 켜집니다(E13, E10). iao4의 어느 세부를 맞춰야 하고, 어느 것은 틀려도 되는가? iao4가 아닌 조작으로 은폐(트리거 → 참 레이블)가 깨지는가?

## A. BN 재추정 (`exp.py`, 작업 `A::<model>`)

- **모델**: batch1과 batch2(CIFAR-10 ResNet18, 같은 가중치 쌍 제외). QCB 76개, 정상·대조군 86개.
- **상태**: 모두 F 가중치, FP32 활성. BN 통계만 바꿉니다(train 모드로 통과시켜 누적 평균, batch 128).

  | 상태 | 재추정에 쓰는 데이터 |
  |---|---|
  | `test` | 방어자 test 2000–3999 (E10의 Bfp와 같음) |
  | `train` | 학습 이미지 10,000장, 증강 없음 |
  | `aug` | 학습 이미지 10,000장, 학습 때와 같은 증강(4픽셀 패딩 무작위 자르기 + 좌우 뒤집기) |
  | `aug_n256`, `aug_n1024` | 같은 증강, 256장과 1,024장 |
  | `test_ema` | test 2000–3999, PyTorch 기본(운동량 .1) |
  | `stage:<s>` | `aug` 통계를 한 묶음(stem, layer1–4)에만 넣고 나머지는 저장값 |
- **재는 것**
  - 정확도, F와의 깨끗한 일치율(test 0–999), ASR.
  - **은폐 여유**: 트리거를 붙인 비표적 이미지에서 (참 레이블 로짓 − 표적 로짓)의 중앙값. 양수면 F의 은폐가 살아 있는 것입니다.
  - **낡음 거리**: BN 층마다 저장 통계와 `aug` 재추정 통계의 차이. 평균은 |μ저장 − μ재| / σ재, 분산은 |log(σ²저장 / σ²재)|. 채널 평균을 내고, 층의 최댓값과 묶음별 값을 기록합니다.

## B. QuEST W4A4와 iao4 (`exp.py`, 작업 `B::<model>`)

- **모델**: QuEST W4A4 21개(batch1 4, batch2 7, CIFAR-100 6, GTSRB 4). 정상·대조군은 batch1의 가벼운 6, 표준 6, QuEST 대조군 2, batch_xn의 CIFAR-100·GTSRB 정상 8개입니다.
- **기준(`ref`)**: deploysim `iao4_train`과 같은 절차를 이 실험의 코드로 다시 짭니다.
  - 가중치 4비트 채널별 IAO.
  - 활성 4비트 IAO, 운동량 .1 EMA, pool도 양자화.
  - 학습 이미지 50,000장을 seed 0으로 섞어 batch 128로 통과시키며 관측과 양자화를 함께 합니다.
  - BN은 train 모드로 재추정합니다.
  - 코드 시험에서 deploysim의 결과와 로짓이 같은지(최대 차이 ≤ 1e-3) 확인합니다.
- **한 번에 한 가지만 바꿉니다.**

  | 묶음 | 바꾸는 것 |
  |---|---|
  | 활성 범위 추정 | 운동량 .01, .5, 1(마지막 배치), 누적 min/max |
  | 보정 데이터 | 양 512, 2,048, 10,000장. 출처: 방어자 test 2000–3999(×4, E10의 D:iao4와 같음), 증강한 학습 이미지 |
  | 순서와 배치 | 섞는 seed 1, 2. batch 32, 512 |
  | BN | 저장값 그대로(eval). FP32로 먼저 재추정한 뒤 eval로 보정 |
  | pool | pool 양자화 끔 |
  | 비트 | W4A8, W8A4, W4A6, W6A4, W5A4, W4A5 |
  | 부분 4비트 | 한 묶음(stem, layer1–4, head)만 W4A4, 나머지 W8A8 |
- **재는 것**: 정확도, ASR, `ref`와의 깨끗한 일치율, 은폐 여유(A와 같은 정의).

## 예측

**A**
- **P-A1 (낡은 통계 또는 얇은 은폐, 주 예측)**: `aug`로 재추정해도 Tian(8, W4A4)과 Ma-8이 `test`에서 켜지는 모델의 절반 이상에서 켜집니다. 이때 정상의 깨끗한 일치율 중앙값은 `aug`에서 .99 이상입니다(`test`에서는 약 .95).
  - 반대로 `aug`에서 거의 안 켜지고(≤ 1/4) `test`와 `train`에서만 켜지면 분포 가설입니다. 그 경우도 그대로 기록합니다.
- **P-A2**: 낡음 거리는 Tian과 Ma-8이 같은 레시피 계열의 정상보다 큽니다. 계열 중앙값이 정상 최대를 넘습니다.
- **P-A3 (위치)**: Tian은 layer4의 BN만 재추정해도 켜집니다(≥ 3/4). Ma-8은 한 묶음만으로는 켜지지 않습니다(묶음마다 ≤ 1/4). E06 b의 스위치 위치(Tian layer4, Ma 퍼짐)와 같은 그림입니다.
- **P-A4**: 켜지지 않는 계열(QuEST W4A4, Qu-ANTI, CIFAR-10 QuEST-8의 대부분)도 은폐 여유는 줄어듭니다. 서술만 합니다.
- **P-A5**: batch1에서도 `test` 재추정이 E10(batch2)과 같은 계열을 켭니다. Tian과 Ma-8 각각 절반 이상입니다.

**B**
- **P-B1 (활성 세부는 틀려도 됨)**: 운동량, 보정 데이터의 양과 출처, 순서, 배치 크기를 바꿔도 QuEST W4A4의 3/4 이상이 켜진 채입니다(ASR ≥ .5). E16에서 활성 범위 ±25 %에 강건했던 것과 같은 이유입니다.
- **P-B2 (가중치 격자는 맞춰야 함)**: W8A4에서는 꺼집니다(≥ 3/4가 ASR < .5). W4A8, W4A6에서는 ASR이 `ref`보다 낮지만 절반 이상이 켜집니다(E05: 가중치만으로 .57–.87).
- **P-B3 (BN)**: BN을 저장값 그대로 두면 ASR이 `ref`보다 낮아집니다(중앙값 차이 ≥ .2). FP32로 먼저 재추정하면 `ref`와 비슷합니다(차이 ≤ .1).
- **P-B4 (부분 4비트)**: 한 묶음만 W4A4로 하면 어느 묶음도 3/4 이상을 켜지 못합니다. 그래도 가장 높은 것은 stem(첫 conv)입니다(E06 b: 첫 conv가 필요 3/4).
- **P-B5**: 꺼진 조건에서도 은폐 여유는 F보다 작습니다(부분적으로 깨짐). 서술만 합니다.
- **정상**: P-B1의 조건에서 `ref`와의 일치율 중앙값이 .97 이상입니다.

## 틀렸다고 볼 기준

1. (A) 정상의 깨끗한 일치율 중앙값이 `aug`에서 .97 미만이다. 증강한 재추정도 정상에서 거의 항등이 아니라는 뜻이므로, P-A1의 판정을 내리지 않습니다.
2. (B) `ref`가 deploysim `iao4_train`과 다르다(로짓 최대 차이 > 1e-3, 또는 QuEST W4A4의 ASR 차이 > .02). 멈추고 고칩니다.
3. (B) 활성 세부(운동량, 양, 출처, 순서, 배치) 가운데 하나라도 QuEST W4A4의 절반 이상을 끈다. 그러면 "iao4는 활성 보정까지 정확히 맞춰야 한다"가 결론입니다.
