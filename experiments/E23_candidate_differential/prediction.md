# E23 예측 — 표적 후보 한 클래스에 집중한 F 대 켠 상태의 차분

작성 2026-11-26, 실행 전. 사용자 요청(11-26 검토 목록 1, E21 b). 탐지기가 아니라 현상 분석입니다. 코드 시험은 정상 하나로만 합니다.

## 질문

- F에서 MM-BD 마진이 가장 큰 클래스는 QCB 27개 중 24개에서 표적이었습니다(E06 c). 이 클래스를 **표적 후보**라 부릅니다.
- 같은 모델의 F와 켠 상태 사이에서 **후보 클래스만** 다른 클래스보다 더 움직이는가? 기준이 같은 모델의 다른 클래스이므로 정상 모집단이 필요 없습니다.
- E18(경계 거리)과 E19(마스크)는 켠 상태로 "가중치 + 자르기"를 써서, QuEST W4A4의 실제 스위치(iao4 전체)가 아니었습니다. 여기서는 **실제 배포판**을 씁니다. 앞으로 통과만 하는 측정이라 미분이 필요 없습니다.

## 설계 (`exp.py`)

- **모델**: E07에서 F의 MM-BD 마진을 잰 batch1 모델입니다. QCB 27개(같은 가중치 쌍 하나 제외), 정상·대조군 14개.
  - QCB는 자기 레시피에서 잽니다(Qu-ANTI는 quanti8과 quanti4 둘 다).
  - 정상·대조군은 레시피 7종 모두에서 잽니다.
- **후보 클래스**: E07의 F MM-BD 마진이 가장 큰 클래스. 정상에도 똑같이 정합니다.
- **상태**
  - F.
  - Q: 레시피의 전체 배포(deploysim).
  - 형식을 모르는 상태(모델당 한 번): C1(iao8 위치의 보정 범위 자르기, BN 저장값), Bfp:test(방어자 test 2000–3999로 FP32 BN 재추정), Bfp:aug(학습 이미지 10,000장을 증강해 재추정).
- **입력 묶음**(트리거 없음)
  1. 깨끗한 test 1,000장.
  2. 같은 이미지 + 가우스 잡음 σ = .1.
  3. **무작위 패치**: 위치와 크기(4–8픽셀)가 무작위인 패치를 붙입니다. 단색 2회, 잡음 무늬 2회, 각 1,000장입니다. 실제 트리거(흰 6×6, 24:30)는 쓰지 않고, 위치도 무작위입니다.
  4. 균일 잡음 이미지 1,000장.
- **클래스 k마다 재는 것**
  - 예측 비율 p_k.
  - 평균 마진 m_k = z_k − max_{j≠k} z_j.
  - 무작위 패치로 k로 넘어간 비율(원래 예측이 k가 아닌 이미지 중에서).
- **차분과 자기 기준 점수**
  - Δ_k = 켠 상태 − F.
  - 후보 c의 점수 = (Δ_c − 다른 클래스 Δ의 중앙값) / (다른 클래스 Δ의 MAD).
  - 그리고 c의 순위(1 = 가장 크게 증가).

## 예측

- **P1 (주 예측)**: QCB는 자기 레시피의 Q에서 "무작위 패치로 후보에게 넘어간 비율"의 증가가 클래스 중 1위입니다.
  - 칸마다 3/4 이상: Ma 8·W4A4, Tian 8·W4A4, Qu-ANTI 8.
  - QuEST 8·W4A4는 절반 이상. 무작위 패치가 실제 트리거와 같은 종류(패치)라서, 켜진 경로의 일부를 연다는 예측입니다. **이 실험에서 가장 중요한 칸**입니다.
- **P2**: 정상·대조군에서 후보가 1위인 비율은 레시피마다 30 % 이하입니다. 우연이면 10 %입니다.
- **P3 (깨끗한 입력)**: 깨끗한 이미지와 잡음 이미지의 예측 비율·마진은 Ma만 후보 쪽으로 움직입니다(Ma의 Q는 F와 깨끗한 예측이 3 % 다름, E16). 다른 QCB는 정상과 같은 크기입니다. 서술만 합니다.
- **P4 (형식을 모르는 상태)**: 그 상태가 스위치를 켜는 계열(C1: CIFAR-10 QuEST-8, Bfp: Tian, Ma-8)에서도 P1과 같은 1위가 나옵니다(3/4 이상).
- **P5**: Bfp:aug에서는 정상의 깨끗한 일치율이 .99 이상입니다(E21 코드 시험의 관찰).

## 틀렸다고 볼 기준

1. 정상·대조군에서 후보가 무작위 패치 측정의 1위인 비율이 30 %를 넘는다. 이 측정은 후보에 특이적이지 않습니다.
2. 실제 트리거로 켜진(ASR ≥ .5) QCB 가운데, 무작위 패치 측정에서 후보가 1위인 모델이 4분의 1 미만이다. 트리거 없는 패치로는 켜진 핵심이 보이지 않는다는 뜻입니다.
