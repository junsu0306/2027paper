# E27 예측 — E24 분류기 수렴 속도 결과의 복제 (QuEST W4A4, 새 모델)

작성 2026-11-26T11:25Z, 실행 전. 사용자 승인(11-26 "진행해줘"). 탐지기가 아니라 현상 확인입니다.

## 복제할 결과 (E24)

- 위치는 분류기 입력, 출발점은 모두 1(SPD 그대로), 상태는 F와 iao4입니다.
- r_k = ccs_k(Q) / ccs_k(F)입니다.
- z = (다른 클래스 r의 중앙값 − 후보의 r) ÷ 다른 클래스 r의 MAD입니다.
- 결과: CIFAR-10 batch1 QuEST W4A4 4개에서 z가 15.1–22.6이었고, iao4로 잰 batch1 정상·대조군 14개는 1.1 이하였습니다. 이때 후보는 E07 F MM-BD 마진 1위였습니다.
- 위치·출발점·통계를 여러 조합으로 본 뒤 눈에 띈 칸이라서, 사후 선택일 수 있습니다.

## 실행 전에 기존 E24 행으로 확인한 것 (사후, 기록용)

- 사용자에게는 후보를 "F에서 가장 빠른 클래스"로 바꾸겠다고 말했습니다. 새 모델에는 MM-BD가 없어서였습니다.
- 그 규칙으로 E24 batch1 행을 다시 계산했습니다(새 모델은 보지 않음).
  - QuEST W4A4 4개는 같습니다. F에서 가장 빠른 클래스 = MM-BD 후보 = 표적이므로 z 15.1–22.6 그대로입니다.
  - **대조군 control-Tian-INT8-qnnpack은 z 17.0입니다.** MM-BD 후보(4)에서는 −0.7이었는데, F에서 가장 빠른 클래스(2)에서는 QuEST W4A4와 같은 크기입니다.
  - 후보 없이 클래스마다 z를 재서 최댓값을 보면, 정상·대조군 14개 중 5개가 5를 넘습니다(최대 28.9, control-QuEST-IAO-W4A4).
- 그래서 E24에서 정상이 1.1 이하였던 것은 **MM-BD 후보에 달려 있습니다.**
- 이번 복제의 1차 규칙은 E24 그대로(F MM-BD 마진 1위)로 하고, MM-BD를 이 실험 안에서 F에 대해 새로 잽니다. "F에서 가장 빠른 클래스"와 "후보 없는 최댓값"은 2차로 함께 봅니다.

## 설계 (`exp.py`)

- **모델** (작업 125개, 모델마다 1개)
  - QuEST W4A4 21개
    - 기준점: batch1 CIFAR-10 4개(E24와 같은 모델)
    - **새 모델 17개**: CIFAR-10 batch2 7개, CIFAR-100 6개, GTSRB 4개
  - 정상·대조군 104개
    - CIFAR-10: batch1 30개(E24의 14개 포함), batch2 56개(어려운 정상 36개 포함: QAT-W4A4-IAO 4개, CleanParent-QuEST 4개 등)
    - CIFAR-100 9개, GTSRB 9개(batch_xn: light, standard, 어려운 정상, 대조군)
  - hold 모델은 코호트에서 이미 빠져 있습니다.
- **레시피**: 모든 모델에 iao4(QuEST W4A4의 배포)를 씁니다. E24와 같은 deploysim 호출입니다.
- **F에서**: MM-BD(E07과 같은 MVD `run_mmbd`)를 잽니다. 후보 = 마진 1위입니다.
- **F와 Q에서**: 분류기 입력의 ccs를 잽니다(E24 `ccs` 그대로, 학습률 1e-3, L_f 1e-3, 최대 20,000단계).
  - 출발점은 모두 1, 그리고 F의 깨끗한 평균 분류기 입력입니다.

## 읽는 법 (먼저 정함)

- **1차**: z_mmbd = 분류기·모두 1에서 MM-BD 후보의 z입니다. **고정 문턱 T = 5**입니다.
  - E24 정상 최댓값 1.1과 QuEST 최솟값 15.1 사이에서, 결과를 보기 전에 정한 값입니다.
  - 데이터셋별로 정상 최댓값과도 비교합니다.
  - MM-BD 후보가 표적이 아니어도 그 후보의 z로 판정합니다(참 표적을 쓰지 않음). 참 표적의 z는 진단용으로만 따로 적습니다.
- **2차**
  - z_fast: F에서 가장 빠른 클래스를 후보로 한 z.
  - z_max: 후보 없이 모든 클래스의 z 중 최댓값, 그리고 그 클래스.
  - 평균 출발 z_mmbd.
  - 데이터셋별 AUROC(QuEST W4A4 대 같은 데이터셋의 정상·대조군).

## 예측

| | 예측 |
|---|---|
| **P0 기준점** | batch1 QuEST W4A4 4개의 z_mmbd가 E24 값의 ±10 % 안이고 모두 5를 넘습니다. MM-BD 후보가 E07과 같은 모델이 E07에 있는 18개 중 17개 이상입니다. |
| **P1 후보** | 새 QuEST W4A4 17개 중 MM-BD 후보 = 표적이 13개 이상입니다. |
| **P2 핵심** | 새 QuEST W4A4 17개 중 z_mmbd > 5가 13개 이상입니다. 데이터셋마다 절반 이상입니다(CIFAR-10 4/7, CIFAR-100 3/6, GTSRB 2/4). |
| **P3 정상** | 정상·대조군 104개 중 z_mmbd > 5가 5개 이하입니다. 어려운 정상 10개(QAT-W4A4-IAO 6개, CleanParent-QuEST 4개) 중에서는 1개 이하입니다. |
| **P4 z_fast** | 정상의 z_fast > 5 비율이 z_mmbd보다 높습니다(5–15 %). 새 QuEST W4A4의 "F에서 가장 빠른 클래스 = 표적"은 10/17 이상이고, CIFAR-100에서 가장 낮습니다. |
| **P5 z_max** | 갈리지 않습니다. 정상의 25 % 이상이 5를 넘습니다. |
| **P6 평균 출발** | 새 QuEST W4A4 17개 중 13개 이상에서 z_mmbd < 0입니다(E24는 −7.9 ~ −13.1). |
| **P7 AUROC** | z_mmbd의 데이터셋별 AUROC가 셋 모두 .9 이상입니다. |

## 틀렸다고 볼 기준

1. **복제 실패**: 새 QuEST W4A4 17개 중 z_mmbd > 5인 모델이 8개 이하입니다. E24 결과는 batch1의 특성이거나 우연입니다.
2. **QCB에 특이적이지 않음**: 정상·대조군 104개 중 z_mmbd > 5가 10개를 넘거나, 어려운 정상 10개 중 3개 이상입니다. 이 신호는 백도어가 아니라 "4비트로 학습했거나 배포한 흔적"입니다.
3. **구현 차이**: batch1 QuEST 기준점 중 z_mmbd ≤ 5인 모델이 있거나, MM-BD 후보가 E07과 다른 모델이 18개 중 3개 이상입니다. 원인을 찾기 전에는 결과를 읽지 않습니다.
