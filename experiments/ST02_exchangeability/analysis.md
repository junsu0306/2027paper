## 3. 해석

1. **부호 무작위 영 기준은 "방향이 무작위인 변화"에만 맞습니다.**
   - 가중치 반올림 잔차는 배포를 모르는 모델에게 방향이 무작위입니다. 그래서 정상의 W kl은 0.6 %만 걸렸습니다.
   - BN 재추정 잔차는 데이터 분포의 차이(증강, 방어자 데이터)라서 모든 채널이 같은 방향으로 움직입니다. 부호를 무작위로 바꾸면 그 일관성이 깨져 효과가 상쇄되므로, 어느 모델이든 실제 재추정이 특별해 보입니다. BN에는 다른 영 기준이 필요합니다.
2. **quanti4의 엔트로피는 0 칸 효과입니다.** 층별 4비트는 칸이 매우 넓어 작은 가중치 다수가 0 칸에 들어갑니다. 실제 반올림은 이들을 0으로 보내고(가지치기), 부호 무작위는 절반을 두 배로 키웁니다. ST01에서 걱정한 효과가 엔트로피에서, 가장 거친 격자에서 나타났습니다.
3. **Q만 학습한 맞춤은 엔트로피로도 안 보입니다.** QAT 정상 25개 중 엔트로피 z ≤ −4는 0개입니다(최소 −4.0). 4비트 QAT 모델의 실제 반올림은 깨끗한 입력에서 같은 크기의 무작위 부호보다 확신을 크게 높이지 않습니다.
4. **영 기준이 맞는 부분(가중치 반올림)이 잡는 것은 1부의 가중치 스위치 계열뿐입니다.** 형식을 모르고 7개를 다 재도 Ma-8은 자기 격자에서 가장 큽니다. 빈칸 계열은 이 부분에서 보이지 않습니다.
