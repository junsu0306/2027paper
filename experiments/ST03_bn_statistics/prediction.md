# ST03 예측 — BN 통계: 어디까지 구별되나, 위조하면 QCB가 망가지나, 위조 뒤에도 남는 것이 있나

작성 2026-11-26T16:15Z, 실행 전. 사용자 요청(11-26): "BN 통계가 제공될 때 어디까지 QCB를 구별할 수 있는지, 공격자가 BN 통계를 위조하면 QCB가 실제로 망가지는지, 우리가 확인할 방법이 정말 없는지". 코드 시험은 정상·대조군·QCB 하나씩으로 했고, 행의 모양과 시간만 봤습니다(3–50초).

## 배경

- 1부 E21 A와 2부 ST02에서 결과를 보고 나서 찾은 단서가 둘 있습니다.
  - **BN 낡음**: 학습 이미지로 잰 값에서 정상 .0013–.016, 배포를 알고 학습한 모델 .014–.79였습니다(AUROC .994, CIFAR-10 ResNet18).
  - **BN 재추정 뒤 엔트로피 상승**: Ma·Tian만 +.13–1.08이었고, 정상 최대 +.094, Tian 대조군 0/5였습니다.
- 두 단서 모두 미리 정하지 않았습니다. 이번에 측정과 문턱을 고정하고, **보류 묶음 batch_h(160개, 2027paper에서 처음 여는 모델)**에서 복제합니다.
- 원리상 iao 배포는 BN을 다시 추정하므로, QuEST W4A4는 저장 통계에 기대지 않습니다(E21 B: 저장값 21/21, FP32 재추정 20/21 켜짐). Ma·Tian은 저장 통계가 은폐의 일부입니다(E21 A).

## 설계 (`exp.py`)

- **모델**: 기존 코호트 228 + batch_h 160 = 388.
- **A. 방어자 측정** (라벨 없음, test 2000–3999 2,000장)
  - BN을 FP32·누적·학습 증강으로 재추정합니다. 전체 2,000장으로 한 번(R), 반씩 두 번(Ra, Rb).
  - 낡음 = d(저장, R), 잡음 = d(Ra, Rb).
  - d_mean = 층 평균의 mean_c |μ₁ − μ₂| / σ₂이고, d_var도 함께 잽니다.
  - **낡음 비** = 낡음 ÷ 잡음입니다. 모델 하나로 판정하는 자기 기준입니다.
  - **엔트로피 변화** = (ent(R) − ent(F)) ÷ ent(F), detector_probe에서 잽니다.
- **B. 위조** (QCB 195, 대조군 23)
  - 공격자는 자기 학습 이미지 10,000장(학습 증강)으로 BN을 재추정한 통계 A를 만듭니다.
  - 저장 통계를 A로 바꿉니다. 평균은 선형, 분산은 log에서 섞고, 섞는 비율 λ ∈ {0, .5, 1}입니다.
  - 각 λ에서 잽니다.
    - F_λ의 깨끗한 정확도와 ASR(참 트리거, 원리 확인용)
    - Q_λ = 자기 표적 레시피로 배포한 F_λ의 정확도와 ASR
    - F_λ에 대한 방어자 측정(A와 같은 낡음 비, 엔트로피 변화)

## 판정 규칙 (먼저 정함)

- **낡음 걸림**: 낡음 비(평균) ≥ 3.
- **엔트로피 걸림**: 엔트로피 변화 ≥ .10.
- **은폐가 깨짐**: F_λ의 ASR ≥ .5.
- **백도어가 살아 있음**: Q_λ의 ASR ≥ .5. Qu-ANTI는 quanti8·quanti4 중 하나라도.
- **들키지 않는 위조**: 다음 넷을 모두 만족하는 λ가 있으면 위조에 성공한 것으로 봅니다.
  - 은폐가 유지됨
  - 백도어가 살아 있음
  - 낡음 비 < 3
  - 엔트로피 변화 < .10
- 집단
  - 배포를 모르는 정상
  - QAT 4비트(W4A4-IAO, W4A4-EFRAP, W4weight)
  - QAT-W8weight
  - 대조군(파이프라인별)
  - QCB 계열
- 기존 코호트와 batch_h를 따로 보고합니다.

## 예측

| | 예측 |
|---|---|
| **A1 낡음 (1단계)** | 배포를 모르는 정상이 걸리는 비율이 10 % 이하(기존·보류 각각). QAT 4비트 3/4 이상, QAT-W8weight 1/4 이하. QCB는 Ma, Qu-ANTI, QuEST-8, QuEST W4A4, Tian W4A4 각각 3/4 이상, Tian-8은 절반 이상. 대조군은 QuEST·Qu-ANTI 파이프라인 3/4 이상, Tian 파이프라인 1/4 이하. 배포를 모르는 정상 대 배포를 아는 모델의 AUROC ≥ .9(기존·보류 각각) |
| **A2 엔트로피 (N7 후보, ST02 사후 단서를 미리 정함)** | **보류 묶음에서** Ma-8, Ma W4A4, Tian W4A4 각각 3/4 이상 걸리고, Tian-8은 2/3 이상. 배포를 모르는 정상 5 % 이하, QAT 정상 10 % 이하, Tian 대조군 0, QuEST(8, W4A4) 10 % 이하. Qu-ANTI는 QCB·대조군 모두 걸림 |

| **B2 위조 뒤 백도어 (λ = 1)** | 모든 계열에서 Q가 켜진 채인 모델이 3/4 이상(핵심은 BN과 무관) |

## 틀렸다고 볼 기준

1. **낡음 비의 영 기준이 안 맞음**: 배포를 모르는 정상이 낡음으로 걸리는 비율이 20 %를 넘습니다(기존이나 보류 어느 쪽이든). 방어자 데이터와 학습 데이터의 차이가 반쪽 잡음보다 커서, 학습 데이터 없이는 낡음을 쓸 수 없다는 뜻입니다.
2. **엔트로피 단서가 복제되지 않음**: 보류 묶음에서 Ma(8 + W4A4)와 Tian W4A4가 엔트로피로 걸리는 비율이 절반 미만이거나, 보류 정상·QAT가 10 %를 넘게 걸립니다.
3. **위조에 대한 원리가 틀림**: 위조한 QuEST W4A4에서 은폐가 깨지거나 Q가 꺼지는 모델이 1/4을 넘습니다(그렇다면 QuEST W4A4도 BN에 기댐). 또는 Ma-8·Tian에서 위조 성공이 절반을 넘습니다(그렇다면 BN은 그들에게도 구조가 아님).
