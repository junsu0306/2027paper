# ST04 예측 — QuEST의 필요한 흔적: 다섯 측정을 한 실험으로

작성 2026-11-26T17:09Z, 실행 전. 사용자 승인(11-26: "③까지 넣어서 다섯 가지 다 묶어서 진행해줘"). 코드 시험은 배포를 모르는 정상 두 개로 했고, 행의 모양과 시간만 봤습니다.

## 배경과 원리

- QuEST와 독 없는 QuEST 파이프라인 모델은 학습 목적이 독 하나만 다릅니다. 그래서 깨끗한 입력이나 모델 전체 수준의 측정으로는 둘이 갈리지 않았습니다(ST01, ST02).
- BN 통계의 흔적은 공격자가 아무것도 잃지 않고 지울 수 있습니다(ST03: QuEST W4A4 40/40).
- 그래서 **공격자가 지우면 백도어도 함께 망가지는 흔적("필요한 흔적")**만 봅니다. 모든 측정은 방어자가 BN을 재추정한 F(R)에서 출발하므로 저장된 BN 통계와 무관합니다.
- 다섯 측정은 다음과 같습니다.
  1. **P1 필요한 층** (참 트리거, 원리 분석): 단계 하나의 4비트 격자만 1/16칸 또는 1/2칸 옮기거나 부호를 무작위로 바꿀 때 스위치가 꺼지는 단계를 찾습니다.
  2. **P2 정류점 잔차**: 정상은 깨끗한 학습 손실의 정류점에 있습니다. 독 없는 쌍둥이는 F와 Q의 깨끗한 손실을 함께 최적화했으므로 그 합의 정류점에 있고, 고친 층에서 g_F + g_Q ≈ 0입니다. QuEST는 트리거 항까지 함께 최적화했으므로 깨끗한 항만의 합에 잔차가 남아야 합니다. 라벨 있는 학습 이미지 2,048장을 씁니다.
  3. **P3 잠자는 고이득 채널**: 가중치가 허락하는 최대 반응(직전 층의 깨끗한 범위 안에서 한 층 구간 경계)과 깨끗한 최댓값의 차이입니다. 막는 채널은 트리거에서 범위의 8–10배까지 켜지도록 만들어졌습니다.
  4. **P4 양자화 경로의 내부 통계**: 같은 이미지에서 BN 입력 통계가 FP 경로(R)와 4비트 경로(Q) 사이에 얼마나 다른지(D)를 봅니다. 단계 하나의 부호를 바꿨을 때의 차이도 함께 봅니다.
  5. **P5 BN 공간 섭동**: BN 채널 하나의 running mean을 4 표준편차 낮춥니다(출력을 +4γ 키움). R과 Q에서 probe 128장의 클래스별 로짓 변화와 그 차이를 봅니다. 채널이 4,000–4,800개라 256장이면 작업당 4–6분이 더 걸려 128장으로 줄였습니다. QuEST-8의 막는 채널은 F에서 표적을 누르고, Q에서는 자르기가 그 누름을 막을 것입니다.

## 설계 (`exp.py`)

- **작업** = (모델, 레시피).
  - W4A4 갈래(iao4): QuEST W4A4 40개(기존 21, 보류 19), 독 없는 QuEST-IAO-W4A4 대조군 6, QAT-W4A4-IAO 정상 16, 배포를 모르는 정상 51.
  - 8비트 갈래(iao8): QuEST-8 32개(기존 18, 보류 14), QuEST-IAO-W8A8 대조군, QAT-W8weight 정상, 같은 배포를 모르는 정상.
- **Q**: R의 가중치를 레시피 격자로 반올림하고 전체 배포를 만듭니다. 학습 모드 보정에는 모든 상태에서 같은 학습 이미지 10,000장을 씁니다. 50,000장이면 배포 한 번에 8–14초라 실험이 몇 시간 걸립니다. E21 B에서 보정 이미지 수(512–10,000장)를 바꿔도 QuEST W4A4는 21/21 켜졌습니다.
- **단계**: ResNet18은 stem, layer1–4, head. VGG16-BN은 block1–5(conv 2·2·3·3·3), head.
- P1과 P4의 단계별 격자 상태(부호 무작위 8번, 1/16칸, QuEST W4A4만 1/2칸)는 W4A4 갈래에서만 만듭니다.

## 읽는 법 (먼저 정함)

- **P1 필요한 단계 S\***
  - ResNet18: 기존 QuEST W4A4에서 그 단계만 바꿨을 때 ASR < .5가 되는 모델이 절반 이상인 단계입니다. sh16, 그다음 sh2, 그다음 부호 무작위(8번 중 절반 이상) 순서로 판정합니다. 없으면 {stem, layer1}로 둡니다.
  - VGG: 같은 규칙을 보류 VGG QuEST W4A4에 적용합니다.
  - 위치만 트리거로 정하고 판정은 트리거 없는 측정으로 하므로 순환이 아닙니다.
- **P2 균형 잔차** B(s) = ‖g_F + g_Q‖ ÷ (‖g_F‖ + ‖g_Q‖), 단계 s에서 잽니다. 함께 볼 것은 cos(g_F, g_Q), ‖g_F‖/‖w‖, ‖g_Q‖/‖w‖입니다.
  - QuEST 편집의 77–79 %가 layer3에 있으므로(E20) 주 단계는 ResNet18 layer3입니다. VGG는 모든 단계를 서술합니다.
- **P3** 층마다 채널의 여유(표준편차 단위)를 같은 층의 다른 채널과 비교한 강건 z입니다. 모델 점수는 최대 z입니다. QuEST-8 CIFAR-10 11개는 막는 채널의 정답(E06 c)과 맞춰 봅니다. 정답 위치는 그 채널을 만드는 BN에 대응시킵니다.
- **P4** D_path(s) = aligned에서 단계 s의 D입니다. 그리고 z_D(s)는 그 단계의 부호 무작위 대비 aligned의 z입니다.
- **P5** 채널마다 d = R과 Q의 클래스별 로짓 변화 차이의 최대 크기입니다. 층 안의 강건 z로 읽고, 모델 점수는 최대 z입니다. QuEST-8은 막는 채널 정답과 맞춰 봅니다.
- **핵심 판정**: 각 측정에서 QuEST 대 쌍둥이(독 없는 대조군 + 같은 형식의 QAT 정상)의 AUROC를 냅니다. 기존과 보류는 따로 냅니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | aligned에서 QuEST W4A4 ASR 중앙값 ≥ .9, QuEST-8 ≥ .9 |
| **P1** | ResNet18: stem이나 layer1의 sh16 하나만으로 꺼지는 모델이 절반 이상. layer3·layer4·head로는 1/4 이하 |
| **P2** | layer3의 B: 독 없는 대조군 < QuEST(대조군은 깨끗한 항의 정류점, QuEST는 트리거 항이 남음). QuEST 대 대조군 AUROC ≥ .8(기존·보류 같은 방향). 배포를 모르는 정상과 QAT는 g_F나 g_Q 중 하나가 작아서 B가 1 근처 |
| **P3** | QuEST-8 CIFAR-10: 막는 채널이 그 층에서 여유 1위인 모델이 11개 중 절반 이상. QuEST W4A4는 정상과 같음 |
| **P4** | D_path(stem, layer1): 배포를 아는 모델(QuEST, 대조군, QAT)이 배포를 모르는 정상보다 작음(AUROC ≥ .85). QuEST 대 대조군은 갈리지 않음(AUROC < .75) |
| **P5** | QuEST-8 CIFAR-10: 막는 채널이 그 층에서 d 1위인 모델이 11개 중 절반 이상이고, 그 채널의 d 클래스가 표적. 모델 점수(최대 z)로 QuEST-8 대 쌍둥이 AUROC ≥ .8. QuEST W4A4는 갈리지 않음 |

## 틀렸다고 볼 기준

1. **구현**: P0이 맞지 않습니다. 원인을 찾기 전에는 결과를 읽지 않습니다.
2. **영 기준**: 배포를 모르는 정상의 (모델, 단계) 쌍에서 P4의 \|z_D\| ≥ 3이 20 %를 넘습니다. 그러면 P4의 z 읽기는 쓰지 않습니다.
3. **정류점 원리**: 배포를 모르는 정상에서 ‖g_F‖/‖w‖가 ‖g_Q‖/‖w‖보다 큰 모델이 절반을 넘습니다. 그러면 "정상은 깨끗한 손실의 정류점"이라는 전제가 이 측정에서 성립하지 않으므로 P2를 읽지 않습니다.

**결과 판정 (미리 정함)**: 다섯 측정 중 하나라도 보류 QuEST(W4A4 또는 8)에서 대 쌍둥이 AUROC ≥ .9이고 기존에서 같은 방향이면, "위조할 수 없는 QuEST 고유의 흔적이 트리거 없이 보인다"고 씁니다. 하나도 없으면 "필요한 흔적으로 좁혀도 QuEST는 쌍둥이와 갈리지 않는다"고 씁니다.
