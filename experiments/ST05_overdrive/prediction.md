# ST05 예측 — 배포의 활성 쪽을 과하게 돌리기

작성 2026-11-27T01:40Z, 본 실행 전.

## 승인과 설계가 바뀐 경위

- 사용자 승인(11-27 "진행해보자"): 배포 차이 Δ(가중치 반올림 잔차와 활성 양자화 오차)를 t배로 키운 상태에서, 깨끗한 입력이 한 클래스로 쏠리는지 봅니다.
- **가중치 부분은 뺐습니다.** 사용자 지적대로 이는 MVD 1031 PoC의 첫 실험입니다. 그 실험은 잔차를 1·2·4배로 키우고 무작위 부호 199개와 비교했고, QuEST는 8비트·W4A4 모두 경보 0이었습니다(`Data/PRIOR_FINDINGS.md` 2.5절). 이번 축소판 시험(모델 2개)에서도 Ma-8은 2배에서 표적으로 쏠렸고(.38), QuEST W4A4는 실제 잔차와 무작위 부호가 같았습니다.
- **활성 쪽 시범 (기존 모델 6개, scratchpad, 결과로 쓰지 않음)**
  - 대상: QuEST W4A4 `031ca4fe17`, `04aaf1c62f`, `0ee2dafd23`, 독 없는 대조군 `01200a508c`, QAT-W4A4-IAO 정상 `186dcde483`, `25b10f65e1`. 모두 CIFAR-10 ResNet18입니다.
  - 가중치는 배포 그대로 두고, 활성 반올림 오차만 t배로 키웠습니다(무작위 부호 4번).
  - t = 3에서 QuEST 3개는 깨끗한 입력이 **각자의 표적(2, 9, 4)**으로 쏠렸습니다. 쏠림 크기는 log 비 .61–.98, 한 클래스로 간 비율은 .19–.28입니다.
  - 쌍둥이 3개는 모두 클래스 3으로 갔습니다(.29–.56, 비율 ≤ .16).
  - 가중치 스위치를 끈 채 활성 잡음만 2배로 키워도 QuEST ASR이 .75–.79였습니다(축소판 시험, 모델 하나).
- 아래 규칙은 이 시범을 보고 정했습니다. 그래서 **판정의 무게는 보류 모델(batch_h)**에 둡니다. 시범에 쓴 6개는 모두 기존 모델입니다.

## 원리

- QuEST W4A4는 가중치 반올림의 방향에는 날카롭지만(1/16칸 이동에 꺼짐), 활성 쪽에는 관대합니다(보정 세부 13종 모두 켜짐, E21 B).
- 백도어가 활성 잡음으로 닿을 수 있다면, 방어자가 배포에 잡음을 더할 때 깨끗한 입력도 표적 쪽으로 끌려야 합니다.
- 독 없는 쌍둥이는 같은 잡음에서 그 데이터셋의 일반적인 잡음 흡수 클래스로만 갈 것입니다.
- 트리거도, 만든 입력도 쓰지 않습니다. 가정 수준은 **무가정**입니다(가중치, 라벨 없는 깨끗한 이미지, 배포 연산과 방어자가 넣은 잡음). 라벨은 정확도에만, 참 트리거는 ASR에만, 표적 라벨은 "쏠린 클래스 = 표적" 확인에만 씁니다. 셋 다 원리 확인용입니다.

## 설계 (`exp.py`)

- **코호트:** ST04의 iao4 갈래입니다. QuEST W4A4 40(기존 21, 보류 19), 독 없는 QuEST-IAO-W4A4 대조군 6, QAT-W4A4-IAO 정상 16, 배포를 모르는 정상 51입니다.
- **출발점:** R = 방어자가 BN을 재추정한 F입니다(ST04와 같고, 위조와 무관). Q는 R의 iao4 배포입니다. 학습 모드 보정은 학습 이미지 10,000장입니다.
- **상태**
  - **A**: 가중치는 배포 그대로(정렬)이고, 모든 IAO 활성 양자화기의 반올림 오차를 t배로 키웁니다(자르기는 그대로). t ∈ {1, 1.5, 2, 2.5, 3, 4}이고, t마다 실제 오차 1개와 무작위 부호 8개입니다.
  - **Aoff**: 가중치에 무작위 부호 반올림 잔차를 넣어 가중치 스위치를 끈 상태입니다. 그 위에 활성 잡음(무작위 부호, t ∈ {1, 2, 3})을 더합니다. 8번 뽑습니다.
- **측정:** detector_probe 1,000장에서 클래스별 평균 softmax m(c), 예측 클래스 분포 h(c), R에 대한 KL, 엔트로피를 잽니다. 원리 확인용으로 정확도와 QuEST ASR도 잽니다.

## 읽는 법 (먼저 정함)

- **쏠림 G** = max_c log(m_X(c) / m_R(c))입니다. 쏠린 클래스 c\*는 그 argmax입니다.
- **주 점수** S_A_3 = A, t = 3에서 잡음 8번의 G 평균입니다.
- **보조 점수:** t = 2, 2.5, 4; h 기반 쏠림; 1위와 2위 쏠림의 차; 실제 오차 상태의 G; Aoff t = 2, 3.
- **비교:** QuEST 대 쌍둥이(대조군 + QAT)의 AUROC입니다. 기존과 보류를 따로 냅니다. 배포를 모르는 정상은 서술만 합니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | A, t = 1, 실제 오차에서 QuEST W4A4 ASR 중앙값 ≥ .9 |
| **P1 주 점수** | S_A_3: QuEST > 쌍둥이. 보류 AUROC ≥ .9, 기존도 ≥ .9 |
| **P2 쏠린 클래스** | t = 3에서 c\*(잡음 8번의 최빈값) = 표적인 QuEST가 기존·보류 각각 2/3 이상. 쌍둥이는 데이터셋마다 공통의 흡수 클래스로 감 |
| **P3 잡음만으로 켜짐** | Aoff t = 3에서 QuEST ASR > .5인 모델이 절반 이상. t = 1에서는 절반 미만 |
| **P4 취약성과 구분** | 같은 잡음에서 깨끗한 정확도(acc_A_3)로는 QuEST와 쌍둥이가 갈리지 않음(AUROC < .75) |

## 틀렸다고 볼 기준

1. **구현:** P0이 맞지 않습니다. 원인을 찾기 전에는 결과를 읽지 않습니다.
2. **취약성 혼동:** acc_A_3에서 QuEST가 쌍둥이보다 낮은 쪽으로 AUROC ≥ .9입니다. 그러면 쏠림 크기를 "그냥 더 잘 무너지는 모델"과 구분할 수 없습니다. 이때 주 점수는 P2가 맞을 때만 백도어 흔적으로 읽습니다.
3. **원리:** 보류 QuEST에서 c\* = 표적이 절반 미만입니다. 그러면 "잡음이 백도어에 닿는다"는 설명을 버립니다. AUROC가 높더라도 마찬가지입니다.

**결과 판정 (미리 정함):** 보류에서 S_A_3의 QuEST 대 쌍둥이 AUROC ≥ .9이고, 기존에서 같은 방향이고, 기준 2·3에 걸리지 않으면 "배포의 활성 쪽을 과하게 돌리면 QuEST W4A4의 흔적이 트리거 없이 보인다(무가정)"고 씁니다. 아니면 그렇게 쓰지 않습니다. 보조 점수에서만 맞으면 "보조 지표에서만, 복제 필요"로 씁니다.
