# ST06 예측 — 같은 모델 안의 기준으로 쏠림 읽기

작성 2026-11-27T06:01Z, 시험 실행과 본 실행 전. 시범은 하지 않았습니다. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "해줘. 안되면 깨끗한 라벨이 있는 데이터라고 가정하고 논문을 전개해도 괜찮을것 같기도해."
  - 그래서 라벨을 쓰는 변형 하나(아래 z_mask_true)를 함께 잽니다. 이 점수는 "라벨 있는 깨끗한 데이터" 가정 수준으로 따로 표시합니다.
- **ST05에서 넘어온 것**
  - 활성 쪽을 과하게 돌리면 QuEST W4A4의 깨끗한 입력이 표적으로 쏠립니다(보류 16/19).
  - 그러나 쏠림의 크기와 방향은 데이터셋의 흡수 클래스(CIFAR-10은 클래스 3)가 지배합니다. 그래서 미리 정한 크기 점수는 보류 .47이었습니다.
  - 같은 데이터셋 정상들의 쏠림을 기준으로 빼면 보류 .97–.99였습니다(사후). 하지만 이 방법에는 기준 모델이 필요합니다.
- **이번 질문:** 그 기준을 **같은 모델 안에서** 얻을 수 있는가.

## 원리

- **(가) 입력 잡음 기준**
  - R(배포 없음)에 픽셀 가우스 잡음을 넣으면, 정상은 자기의 흡수 클래스로 무너질 것입니다.
  - 입력 잡음은 배포 연산이 아니라서 QCB의 스위치를 열지 않을 것입니다.
  - 그래서 "과하게 돌린 배포의 쏠림 − 같은 손상의 입력 잡음 쏠림"이 정상에서는 0 근처이고, QuEST에서는 표적에 남을 것입니다.
- **(나) CSO식 제거** (Yang·Miller·Kesidis, ICML 2026의 생각만 빌림. 입력 생성 없음)
  - CSO의 가정은 "트리거가 만드는 특징 방향은 깨끗한 특징 공간 밖에 있다"입니다.
  - 과하게 돌린 배포에서 분류기 입력(끝단 특징)의 평균 변화를 둘로 나눕니다. R의 깨끗한 특징 공간 안의 부분과 밖의 부분입니다.
  - **밖의 부분만** 분류기에 통과시켜 어느 클래스를 미는지 봅니다.
  - 정상의 흡수 클래스 쏠림은 특징이 약해지는 공간 안의 변화일 것입니다. QuEST의 누출은 깨끗한 입력이 쓰지 않던 방향일 것입니다.
- **가정 수준:** (가)와 (나)는 무가정입니다. 쓰는 것은 가중치, 라벨 없는 깨끗한 이미지, 방어자가 넣는 잡음, 모델 자신의 예측입니다. z_mask_true만 라벨을 씁니다. 참 트리거는 ASR(원리 확인)에만, 표적 라벨은 "가리킨 클래스 = 표적" 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트:** ST05와 같습니다. QuEST W4A4 40(기존 21, 보류 19), 대조군 6, QAT-W4A4-IAO 16, 배포를 모르는 정상 51입니다.
- **R:** ST05와 같습니다(방어자 이미지 2,000장으로 BN 재추정).
- **상태**
  - **A:** ST05와 같은 구성과 seed입니다.
    - t ∈ {2, 3}, 활성 반올림 오차 × t, 무작위 부호 8번입니다.
    - t = 1 실제 오차 1번도 잽니다(P0 ASR).
  - **N:** R에 픽셀 가우스 잡음 σ ∈ {.02, .04, .06, .08, .12, .16, .24}를 넣고 [0, 1]로 자릅니다. 4번 뽑습니다.
- **측정 (probe 1,000장):** 클래스 평균 softmax m, 예측 분포, R에 대한 KL, 분류기 입력 특징의 평균 mS, 그리고 분류기 밀기를 잽니다. 밀기는 R의 분류기 가중치 W를 씁니다.
  - push_raw = W(mS_X − mS_R)
  - push_glob = W · (mS_X − mS_R 중 전역 깨끗한 공간 밖의 성분)
    - 전역 공간: R의 probe 특징(중심화하지 않음)의 SVD에서 에너지 95 %까지입니다.
  - push_mask
    - 클래스 c마다 R이 c로 예측한 probe 이미지에서 기여 S_j·W_cj의 양수 몫 90 %를 덮는 좌표를 c의 고유 좌표로 둡니다.
    - 그 좌표를 뺀 나머지 좌표의 변화로 c를 미는 양입니다.
  - push_mask_true: push_mask와 같고, 클래스를 probe 라벨로 정합니다(라벨 가정).

## 읽는 법 (먼저 정함)

- v_A = A, t = 3에서 잡음 8번 평균의 log m_X − log m_R입니다.
- **σ 맞추기:** σ\*는 모델마다 N의 KL 평균이 A t = 3의 KL 평균에 가장 가까운 σ입니다. v_N은 그 σ\*에서 4번 평균한 쏠림입니다.
- **(가) 주 점수 exc_self** = max_c [v_A(c) − v_N(c)]이고, 가리킨 클래스는 그 argmax입니다. 보조 점수는 dis_self = 1 − cos(v_A, v_N)입니다.
- **(나) 주 점수 z_glob**는 push_glob(t = 3, 8번 평균)의 클래스 강건 z입니다.
  - 정의: (최댓값 − 중앙값) / max(1.4826 · MAD, .25 · 표준편차, 1e-12). 가리킨 클래스는 argmax입니다.
  - 보조 점수는 z_mask입니다.
- **라벨 가정:** z_mask_true입니다.
- **기준선:** z_raw(제거 없음), G(ST05 주 점수를 다시 잰 것)입니다.
- **흡수 클래스:** 데이터셋·구조 칸마다, 정상(대조군 + QAT + 배포를 모르는 정상)의 c_raw 최빈값입니다.
- **비교:** QuEST 대 쌍둥이, QuEST 대 정상 전체의 AUROC입니다.
  - **데이터셋을 섞은 채 하나의 순위로 셉니다.** 기준 모델이 필요 없다는 것이 이번 질문이기 때문입니다.
  - 칸별 값은 서술만 합니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | (a) A t 1 실제 오차에서 QuEST ASR 중앙값 ≥ .9. (b) ST05의 S_A_3을 다시 냄(모델별 차이 중앙값 ≤ .01) |
| **P1 정상의 성질** | 정상의 입력 잡음 쏠림 클래스(c_N)가 흡수 클래스와 같은 비율 ≥ .5. (가)가 성립하려면 필요합니다 |
| **P2 (가)** | 정상에서 c_self = 흡수 클래스 ≤ .3. exc_self의 보류 AUROC가 대 쌍둥이 ≥ .9, 대 정상 전체 ≥ .85. 기존 ≥ .7(같은 방향). 보류 QuEST c_self = 표적 ≥ 2/3 |
| **P3 (나)** | 정상에서 c_glob = 흡수 클래스 ≤ .3. z_glob의 보류 AUROC가 대 쌍둥이 ≥ .9, 대 정상 전체 ≥ .85. 기존 ≥ .7. 보류 QuEST c_glob = 표적 ≥ 2/3 |
| **P4 기준선** | z_raw: 정상 c_raw = 흡수 클래스 ≥ .7. 보류 AUROC 대 쌍둥이 < .75 (흡수 클래스가 밀기 공간에도 있음) |
| **P5 라벨** | z_mask_true의 보류 AUROC(대 쌍둥이) ≥ z_mask의 값 |

제 사전 기대는 높지 않습니다. 입력 잡음의 흡수 클래스와 내부 잡음의 흡수 클래스는 다를 수 있습니다(P1). 잡음이 만드는 특징 변화도 고차원이라, 정상에서도 공간 밖의 성분이 한 클래스로 밀 수 있습니다(P3).

## 틀렸다고 볼 기준

1. **구현:** P0 (a) 또는 (b)가 맞지 않습니다. 원인을 찾기 전에는 결과를 읽지 않습니다.
2. **기준 오염:** 맞춘 σ\*에서 QuEST ASR > .5인 모델이 절반 이상입니다. 그러면 입력 잡음도 스위치를 여는 것이므로, (가)는 같은 모델 안의 기준으로 읽지 않습니다. 원리 결과로만 씁니다.
3. **흡수 클래스가 안 지워짐:** 어떤 점수에서 정상의 c = 흡수 클래스가 .5를 넘습니다. 그 점수의 AUROC는 "같은 모델 안의 기준이 성공"으로 쓰지 않습니다.
4. **취약성 혼동:** acc_A3에서 QuEST가 더 낮은 쪽으로 대 쌍둥이 AUROC ≥ .9입니다. ST05와 같은 처리를 합니다.

**결과 판정 (미리 정함)**
- (가)나 (나)가 자기 예측(P2 또는 P3)을 모두 만족하고 기준 1–4에 걸리지 않으면 다음과 같이 씁니다. "같은 모델 안의 기준으로, 기준 모델 없이 QuEST W4A4의 표적 누출이 보인다(무가정)."
  - (가)와 (나)는 함께 주 점수입니다. 둘 중 하나만 맞으면 그것만 씁니다. 주 점수가 둘이라는 것을 같이 적습니다.
- 보조 점수(z_mask, dis_self)에서만 맞으면 "보조 지표에서만, 복제 필요"로 씁니다.
- 라벨 변형(z_mask_true)에서만 맞으면 "라벨 있는 깨끗한 데이터 가정에서, 복제 필요"로 씁니다.
- 아니면 그렇게 쓰지 않습니다. 사용자 승인에 따라 다음 설계는 라벨 있는 깨끗한 데이터를 가정해도 됩니다. 단, 새 예측을 먼저 씁니다.
