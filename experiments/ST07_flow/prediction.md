# ST07 예측 — 입력별 흐름: 어느 클래스에서 넘어오는가

작성 2026-11-27T06:28Z, 시험 실행과 본 실행 전. 시범은 하지 않았습니다. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "진행해줘"(ST06 분석 뒤 제안한 흐름 실험).
- **ST06에서 넘어온 것**
  - **흡수 클래스는 "데이터셋 × 잡음 종류"의 성질입니다.** 입력 잡음과 활성 잡음의 흡수 클래스가 정상 73개 모두에서 달랐습니다. 그래서 같은 모델 안에서 다른 잡음을 기준으로 삼을 수 없습니다.
  - **QuEST의 누출은 입력 단위 현상입니다.** 확률로는 표적으로 쏠리지만, 평균 특징 변화로는 보이지 않았습니다.
- **이번 질문:** 같은 활성 잡음 안에서, 넘어가는 입력들의 **출처**와 **민 힘의 방향**으로 흡수 클래스와 백도어 누출을 가를 수 있는가.

## 원리

- **흐름의 고름 (주 점수 1)**
  - 흡수 클래스는 데이터셋의 클래스 구조가 만듭니다. 그래서 그리로 넘어오는 입력은 몇몇(비슷한) 클래스에서 주로 올 것입니다.
  - 공격 학습에서 트리거는 원래 클래스와 무관하게 표적으로 보내도록 학습됩니다(all-to-one). 그래서 백도어가 새면 **모든 출처에서 비슷한 비율로** 넘어올 것입니다.
- **입력별 CSO (주 점수 2)**
  - 넘어간 입력마다, 결정을 바꾼 힘(분류기 입력 변화 · (W_도착 − W_출처))을 둘로 나눕니다. R의 깨끗한 특징 공간 안의 몫과 밖의 몫입니다.
  - 백도어 누출은 깨끗한 입력이 쓰지 않던 방향(공간 밖)으로 밀 것입니다(CSO의 가정).
- **가정 수준:** 무가정입니다. 쓰는 것은 가중치, 라벨 없는 깨끗한 이미지, 방어자의 잡음, R의 예측(출처)입니다.
  - 라벨 변형(UL)은 출처를 probe 라벨로 정하고, R이 맞힌 이미지만 씁니다. "라벨 있는 깨끗한 데이터" 가정으로 따로 표시합니다.
  - 참 트리거는 ASR에만, 표적 라벨은 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트:** ST05·ST06과 같습니다. QuEST W4A4 40(기존 21, 보류 19), 대조군 6, QAT-W4A4-IAO 16, 배포를 모르는 정상 51입니다.
- **상태:** ST05·ST06과 같은 구성과 seed입니다.
  - A, t = 1 실제 오차(P0)
  - A, t ∈ {2, 3}, 무작위 부호 8번
- **측정:** probe 1,000장 각각에 대해 다음을 기록합니다.
  - R의 예측(출처), 라벨
  - 상태마다의 예측(도착)
  - 결정 밀기 push = (W_도착 − W_출처)·ΔS와 그중 공간 밖의 몫 push_out
    - ΔS는 분류기 입력의 변화입니다. W는 R의 분류기 가중치입니다.
    - 공간은 R의 probe 특징(중심화 안 함)에서 에너지 95 %까지입니다(ST06과 같음).

## 읽는 법 (먼저 정함)

- **이미지별 도착:** 8번 중 4번 이상 같은 클래스(출처와 다른 클래스)로 갔으면 그 클래스입니다. 아니면 "안 넘어감"입니다.
- **c†:** 들어온 이미지 수가 가장 많은 클래스입니다.
- **분산 지수 D:** c†로 넘어온 이미지의 출처 분포를 봅니다. 기대값은 "출처마다 넘어오는 비율이 같다", 즉 출처 클래스의 크기에 비례하는 수입니다.
  - D = χ² / (출처 수 − 1)입니다. 귀무에서 기댓값은 클래스 수와 무관하게 1입니다.
  - 넘어온 이미지가 5개 미만이면 D = 1(정보 없음)입니다.
- **주 점수 1:** U = −log D (t = 3)입니다. 클수록 고르게 넘어옵니다.
- **주 점수 2:** φ = c†로 넘어간 (이미지, 뽑기)들의 push_out 합 ÷ push 합(t = 3)입니다. 넘어간 쌍이 5개 미만이거나 합이 0 이하면 값이 없습니다.
- **보조 점수:** U와 φ의 t = 2 값입니다.
- **라벨 변형:** UL (t = 3)입니다.
- **기준선:** G(ST05 주 점수를 다시 잰 것)입니다.
- **흡수 클래스:** 칸마다 정상의 확률 쏠림 클래스(c_G) 최빈값입니다(ST06과 같음).
- **비교:** QuEST 대 쌍둥이, QuEST 대 정상 전체입니다. **데이터셋을 섞은 하나의 순위로** 셉니다. 칸별 값은 서술만 합니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | (a) A t 1 실제 오차의 QuEST ASR 중앙값 ≥ .9. (b) ST05 S_A_3 재현(모델별 차이 중앙값 ≤ .01) |
| **P1 정상의 성질** | 정상의 D (t 3) ≥ 2인 비율 ≥ 2/3. 흡수 클래스 흐름은 몇몇 출처에 몰림 |
| **P2 원리** | c† = 표적인 QuEST에서 D ≤ 2인 비율 ≥ 1/2 |
| **P3 주 점수 1 (U)** | 보류 AUROC 대 쌍둥이 ≥ .9, 대 정상 전체 ≥ .85. 기존 ≥ .7(같은 방향) |
| **P4 주 점수 2 (φ)** | 같은 기준 |
| **P5 라벨** | UL의 보류 AUROC(대 쌍둥이) ≥ U의 값 |

제 사전 기대는 반반입니다.
- 넘어가는 입력은 원래 표적과의 여유가 작은 입력일 것입니다. 그 여유는 출처 클래스가 표적과 얼마나 비슷한지에 달려 있어서, 백도어 흐름도 고르지 않을 수 있습니다(P2).
- 흡수 클래스로 가는 흐름이 의외로 고를 수도 있습니다(P1).

## 틀렸다고 볼 기준

1. **구현:** P0 (a) 또는 (b)가 맞지 않습니다. 원인을 찾기 전에는 결과를 읽지 않습니다.
2. **원리:** P1이 틀립니다(정상의 흡수 흐름이 고름). 그러면 U의 AUROC가 높더라도 "흡수 클래스와 백도어를 흐름의 고름으로 가른다"고 쓰지 않습니다.
3. **데이터셋 의존:** 정상의 D 중앙값(또는 φ 중앙값)이 데이터셋 사이에서 3배 넘게 다릅니다. 그러면 그 점수의 통합 AUROC를 "기준 모델 없이"의 결과로 쓰지 않습니다.
4. **취약성 혼동:** acc_A3에서 QuEST가 더 낮은 쪽으로 대 쌍둥이 AUROC ≥ .9입니다.

**결과 판정 (미리 정함)**
- U나 φ가 자기 예측(P3 또는 P4)을 만족하고 기준 1–4에 걸리지 않으면 다음과 같이 씁니다. "과하게 돌린 배포에서 입력별 흐름으로, 기준 모델 없이 QuEST W4A4가 보인다(무가정)." U라면 P1·P2도 맞아야 합니다.
- U와 φ는 함께 주 점수입니다. 둘 중 하나만 맞으면 그것만 씁니다.
- 보조 점수(t = 2)에서만 맞으면 "보조 지표에서만, 복제 필요"로 씁니다.
- 라벨 변형에서만 맞으면 "라벨 있는 깨끗한 데이터 가정에서, 복제 필요"로 씁니다.
- 아니면 그렇게 쓰지 않습니다.
