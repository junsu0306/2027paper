# ST08 예측 — 같은 활성 잡음을 FP와 양자화에 똑같이

작성 2026-11-27T07:40Z, 시험 실행과 본 실행 전. 시범은 하지 않았습니다. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 제안과 승인(11-27):**
  - 제안: "fp, 양자화 모두 잡음을 세게 줬을 때도 똑같아? 예를 들면 qcb는 두 개에서 가는 방향이 다른데 정상은 같을 수도 있잖아"
  - 승인: "한 1시간 분량정도로 잡아서 진행해줘"
- **이미 아는 것 (ST05 다시 읽기, 사후)**
  - 가중치 스위치를 켠 상태(A)와 끈 상태(Aoff, 반올림 방향 무작위)에 같은 잡음을 넣었습니다.
  - QuEST의 깨끗한 입력은 두 상태에서 같은 방향으로 갔습니다(t = 3에서 표적 29/40 대 26/40, cos .99).
  - 다만 Aoff는 순수 FP가 아닙니다. 가중치에 4비트 크기의 교란이 있고, 활성 자르기와 BN 재보정도 그대로였습니다.
- **E15의 단서:** F 가중치에 가우스 활성 잡음만 넣었을 때, QuEST W4A4는 잡음이 4비트 한 칸 크기(표준편차)가 되어서야 켜졌습니다(3/4). 그래서 중간 세기에서는 FP가 덜 열릴 수 있습니다.
- **ST06과 다른 점:** ST06은 입력 잡음과 활성 잡음, 즉 다른 종류의 잡음을 비교해서 흡수 클래스가 달라졌습니다. 이번에는 **같은 잡음**이고, 다른 것은 양자화뿐입니다.

## 원리

- 같은 잡음이면 흡수 클래스는 같아야 합니다(ST06: 흡수 클래스 = 데이터셋 × 잡음 종류). 정상 모델의 FP와 Q는 거의 같은 함수이므로, 같은 클래스로 갈 것입니다.
- QuEST의 누출이 **양자화된 배포가 반쯤 열어 둔 문**에서 나온다면, Q + 잡음은 표적으로 가고 FP + 잡음은 흡수 클래스로 갈 것입니다.
- **2 × 2 상태로 어느 성분이 누출을 만드는지도 나눕니다.**
  - 가중치: 공격자가 노린 4비트 격자(Q) 또는 FP(R)
  - 활성: 보정 범위로 자르기 있음 또는 없음
  - 잡음은 네 상태 모두 같습니다. 활성 반올림은 하지 않고, 잡음이 그 자리를 대신합니다.
- **가정 수준:** 무가정입니다(가중치, 방어자의 라벨 없는 이미지 2,000장, 방어자의 잡음). 참 트리거는 ASR에만, 표적 라벨은 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트:** ST05–ST07과 같습니다. QuEST W4A4 40(기존 21, 보류 19), 대조군 6, QAT-W4A4-IAO 16, 배포를 모르는 정상 51입니다.
- **R:** 방어자 이미지 2,000장으로 BN을 재추정한 F입니다(ST05와 같음).
- **배포 보정을 바꿨습니다.** 학습 이미지 1만 장 대신 **방어자 이미지 2,000장을 4번 반복**합니다(사용자 질의 11-27). 그래서 ST05와 수치가 정확히 같지는 않습니다.
- **상태 (네 상태 모두 deploysim iao4_train 절차로, 같은 잡음 아래에서 범위와 BN을 보정)**
  - QA: 격자 가중치 + 자르기 + 잡음 (= ST05 A)
  - QN: 격자 가중치 + 잡음
  - FA: FP 가중치 + 자르기 + 잡음
  - FN: FP 가중치 + 잡음 ("FP + 같은 잡음")
  - 잡음 = 무작위 부호 활성 반올림 오차 × t입니다. t ∈ {1, 1.5, 2, 3}, 4번 뽑고, 부호 seed는 ST05와 같은 7000 + k입니다.
  - P0: QA, t = 1, 실제 오차(= 배포 그대로)
- **측정:** probe 1,000장의 클래스 평균 softmax와 이미지별 예측입니다. 원리 확인용으로 정확도와 QuEST ASR을 잽니다.

## 읽는 법 (먼저 정함)

- v_X = 상태 X의 4번 평균 log m_X − log m_R입니다.
- **주 점수:** S_2 = max_c [v_QA(c) − v_FN(c)] (t = 2)이고, 가리킨 클래스는 그 argmax입니다.
- **보조 점수:** S_1.5, S_3, 그리고 1 − cos(v_QA, v_FN) (t = 2, 3)입니다.
- **흡수 클래스:** 칸마다 정상의 c_QA (t = 2) 최빈값입니다.
- **비교:** 데이터셋을 섞은 하나의 순위로 셉니다(기준 모델 없음). 칸별 값은 서술만 합니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | QA t 1 실제 오차의 QuEST ASR 중앙값 ≥ .9 |
| **P1 정상의 성질** | t = 2에서 정상의 c_QA = c_FN 비율 ≥ 2/3, cos(v_QA, v_FN) 중앙값 ≥ .8 |
| **P2 원리** | t = 2에서 QuEST의 FN 쏠림 = 표적 < 1/3, FN의 ASR 중앙값 < .5. QA의 쏠림 = 표적 ≥ 1/2 |
| **P3 주 점수** | S_2의 보류 AUROC가 대 쌍둥이 ≥ .9, 대 정상 전체 ≥ .85. 기존 ≥ .7. 보류 QuEST가 가리킨 클래스 = 표적 ≥ 2/3. 정상이 가리킨 클래스 = 흡수 클래스 ≤ .3 |
| **P4 2 × 2 (서술 예측)** | 누출(QuEST 쏠림 = 표적)은 자르기가 있는 상태(QA, FA)에서 크고, 없는 상태(QN, FN)에서 작음. ST05 Aoff가 자르기 + 잡음에서 표적으로 갔기 때문 |

제 사전 기대는 낮습니다(3할 정도). ST05 Aoff로 보면 누출의 원인은 가중치 격자보다 활성 쪽입니다. FP에서도 같은 잡음이면 표적으로 갈 수 있습니다.

## 틀렸다고 볼 기준

1. **구현:** P0이 맞지 않습니다.
2. **정상의 성질:** P1이 틀립니다. 그러면 S의 AUROC가 높더라도 "같은 잡음의 FP를 기준으로 쓴다"고 쓰지 않습니다.
3. **데이터셋 의존:** 정상의 S_2 중앙값이 데이터셋 사이에서 3배 넘게 다릅니다. 그러면 통합 AUROC를 "기준 모델 없이"의 결과로 쓰지 않습니다.
4. **취약성 혼동:** QA t 2의 깨끗한 정확도에서 QuEST가 더 낮은 쪽으로 대 쌍둥이 AUROC ≥ .9입니다.
