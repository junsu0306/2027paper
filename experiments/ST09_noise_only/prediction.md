# ST09 예측 — 잡음만으로 켜지는가 (BN을 잡음 아래에서 다시 추정하지 않음)

작성 2026-11-27T09:31:09Z, 시험 실행과 본 실행 전. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "1번 2번은 진행해주고" — ST08 분석의 다음 후보 2번(ST08의 한계를 닫는 짧은 확인)입니다.
- **ST08의 한계:** 모든 상태가 자기 잡음 아래에서 BN과 활성 범위를 다시 추정했습니다.
  - 그래서 "FP 가중치 + 활성 잡음만으로 QuEST W4A4가 켜진다"(FN, t 2 ASR .74, 36/40 > .5)가 잡음 자체 때문인지, 잡음 아래의 BN 재추정 때문인지 나누지 못했습니다.
- **E15의 단서 (batch1, 4개):** BN은 저장값으로 두고, 범위 폭/255 × k 크기의 가우스 잡음을 넣었습니다.
  - QuEST W4A4는 k = 16(4비트 한 칸 크기 표준편차)에서 3/4가 켜졌습니다. 이때 정상의 깨끗한 일치율은 .1–.35로 거의 무너진 상태였습니다.
  - ST08의 t 2 잡음은 표준편차가 약 .6칸이고, 정상 정확도는 .66이었습니다. 그래서 BN 재추정 없이는 같은 잡음에서 덜 켜질 수도 있습니다.

## 원리

- **H_잡음:** QuEST W4A4의 은폐는 활성이 정확할 때만 성립합니다. 그렇다면 BN을 깨끗하게 둔 채 추론에서만 잡음을 넣어도 켜져야 합니다.
- **H_BN:** 잡음 아래에서 BN을 다시 추정하는 것(잡음에 맞춰 정규화가 바뀌는 것)이 켜는 데 필요하다면, 추론에서만 넣은 잡음으로는 덜 켜질 것입니다.
- **가정 수준:** 원리 확인(참 트리거로 ASR을 잽니다)입니다. 탐지 점수는 없습니다.

## 설계 (`exp.py`)

- **코호트:** QuEST W4A4 40(기존 21, 보류 19)과 쌍둥이 22(대조군 6, QAT-W4A4-IAO 16)입니다. 배포를 모르는 정상은 이 질문에 필요 없어 뺍니다.
- **깨끗한 보정:** deploysim iao4_train 절차를 그대로 쓰되, 활성 가짜 양자화기를 항등으로 바꿉니다.
  - BN과 활성 범위는 깨끗한 FP 활성에서 나옵니다(방어자 이미지 2,000장 × 4, ST08과 같음).
  - 그 뒤 BN과 범위를 고정하고, **추론에서만** 잡음을 넣습니다.
- **잡음:** ST08과 같습니다(무작위 부호 활성 반올림 오차 × t, 자르기 없음, 부호 seed 7000 + k, 4번).
- **상태**
  - FNi: FP 가중치(R), 깨끗한 보정, 추론에서만 잡음. t ∈ {0, 1, 2, 3}이고, t 0은 잡음 없음(R과 같은 기준)입니다.
  - QNi: 4비트 격자 가중치(Q), 깨끗한 보정, 추론에서만 잡음. t ∈ {0, 1, 2, 3}이고, t 0은 "가중치만 4비트, 활성 FP"입니다.
  - FNc: ST08 FN의 t 2(보정과 추론 모두 잡음)를 같은 seed로 다시 잽니다(P0 재현).
- **측정:** ST08과 같습니다. probe 1,000장의 클래스 평균 softmax와 이미지별 예측, 시험 집합 정확도, QuEST ASR입니다.

## 읽는 법 (먼저 정함, `analyze.py`)

- 상태 × t마다 QuEST의 ASR 중앙값, ASR > .5인 수(보류/기존), 깨끗한 입력 → 표적 비율 중앙값, QuEST와 쌍둥이의 정확도 중앙값을 냅니다. ASR과 표적 비율은 4번 평균입니다.
- **주 비교:** t 2에서 FNi 대 FNc입니다. 모델별 ASR 차이(FNi − FNc)의 중앙값과 FNi ASR > .5인 수를 봅니다.
- **같은 손상에서의 비교(보조):** FNc t 2의 쌍둥이 정확도 중앙값에 가장 가까운 FNi의 t에서 ASR을 비교합니다.
- **깨끗한 입력 → 표적:** R의 예측이 표적이 아닌 probe 이미지 중 표적으로 간 비율입니다(ST08 사후와 같은 정의).

## 예측

| | 예측 |

| **P0 구현** | (a) FNc가 ST08 FN t 2를 재현: 모델별 ASR 차이 중앙값 ≤ .01. (b) FNi t 0(R과 같음)의 QuEST ASR 중앙값 ≤ .1 |
| **P1 주 질문** | H_잡음: FNi t 2에서 QuEST ASR > .5인 비율 ≥ 2/3, 깨끗한 입력 → 표적 중앙값 ≤ .1 |
