## 승인과 배경

- **사용자 승인(11-27):** "둘 다 진행해봐" — (가′) 정류점 잔차 다시 재기, (가) 클래스별 깨끗한 공간(ST11).
- **사용자 질문(같은 날):** "공격 loss식을 정확히 알아야 쓸 수 있는 건가?" → 정확한 계수를 쓰는 판(상한)과, 계수를 가중치에서 맞추는 판(현실)을 함께 잽니다.
- **ST04 P2의 실패 이유(ST09 뒤 다시 봄)**
  1. 기울기를 배포된 모델(eval BN, 고정 범위)에서 쟀습니다. 공격 학습은 두 경로 모두 학습 모드 BN(배치 통계)입니다.
  2. 마스크 밖 가중치(약 80 %, 학습 안 됨)까지 섞었습니다.
  3. F 항과 Q 항을 1:1로 두고, 가중치 감쇠를 뺐습니다.
- **공격 코드에서 읽은 목적함수 (harness `quest4/core.py`, `recipe_worker.py`)**
  - 배치마다 CE_F(x, y) + CE_F(b, y′) + CE_Q(x, y) + CE_Q(b, y′)입니다.
    - 표본의 10 %는 b = x + 트리거, y′ = 표적입니다. 나머지는 b = x, y′ = y입니다.
  - 두 경로 모두 학습 모드이고, Q는 IAO W4A4 가짜 양자화입니다.
  - SGD 가중치 감쇠 5e-4입니다. Fisher 마스크로 고른 가중치만 학습합니다.
  - 증강은 크기 흔들기뿐입니다(95 %는 그대로).
- **정류점 조건(마스크 안):** r := g_F + g_Q + 2.5e-4·w = −0.05 (P_F + P_Q)입니다. P는 독 항의 기울기입니다.
  - 그래서 r은 "트리거 입력에서 Q는 표적을 올리고, F는 원래 라벨을 지키는" 방향을 가리켜야 합니다.

## 원리와 가정

- **"어떤 손실인가"를 클래스별로 묻습니다.**
  - 후보 방향 δ_c = ∇ 평균_{y≠c}[log p_Q(c|x) − log p_F(c|x)]입니다. "Q에서 c를 F보다 올리는" 깨끗한 입력 기울기입니다.
  - r과의 cos가 가장 큰 클래스가 표적이면, 잔차가 독 항을 드러낸 것입니다.
  - 트리거도 입력 생성도 쓰지 않습니다.
- **가정 수준**
  - 학습 데이터 8,192장: 공격자의 데이터입니다. 방어자에게는 없으므로 원리 확인(상한)입니다.
  - 방어자 라벨 데이터 2,000장과 클래스당 10장: "라벨 있는 깨끗한 데이터" 가정입니다.
  - 정확한 계수: 공격 코드를 안다는 가정(상한)입니다.
  - 맞춘 계수: "F의 깨끗한 손실 + Q의 깨끗한 손실"이라는 일반적인 꼴만 가정합니다. QCB라면 은폐(F 깨끗함)와 은닉(Q 깨끗함) 때문에 반드시 가지는 꼴입니다.
  - 배포 형식(iao4)은 방어자가 자기 것으로 압니다.
  - 참 트리거는 QuEST의 ASR 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트:** QuEST W4A4 40, 대조군 6, QAT-W4A4-IAO 16, 배포를 모르는 정상 51입니다(ST05–ST08과 같음).
- **기울기:** 학습 모드 BN, 배치 128, 증강 없음입니다. conv/linear 가중치에 대해 잽니다.
  - F: 의심 모델의 FP 가중치입니다.
  - Q: 그 iao4 배포입니다. 범위는 방어자 이미지로 보정해 고정하고, 반올림은 직통(STE)으로 넘깁니다.
- **데이터:** train 8,192(학습 집합), defender 2,000(라벨 있는 방어자 이미지), small(그중 클래스당 10장)입니다.
- **대용 마스크:** 깨끗한 Q-Fisher 상위 20 %에서 깨끗한 F-Fisher 상위 5 %를 뺍니다(공격은 독 라벨을 섞어 셈).
- **측정**
  - ‖g_F‖/‖w‖, ‖g_Q‖/‖w‖
  - B = ‖r‖ / (‖g_F‖ + ‖g_Q‖ + 2.5e-4‖w‖): 전체, 마스크 안, 단계별
  - 맞춘 계수 (a, l) = argmin ‖g_F + a·g_Q + l·w‖(마스크 안)와 B_fit
  - 클래스 점수 s_c = cos(r, δ_c)(마스크 안, D의 512장)
  - 맞춘 계수의 s_c^fit, 그리고 Q만의 방향 cos(r, ∇log p_Q(c))

## 예측

| | 예측 |
|---|---|
| **P0 구현** | (a) 배포를 모르는 정상, train: ‖g_F‖/‖w‖ 중앙값 < ‖g_Q‖/‖w‖ 중앙값. (b) QuEST 배포 ASR 중앙값 ≥ .9 |
| **P1 전제 (공격 체제에서 쌍둥이가 정류점 근처)** | train, B_mask: 대조군 중앙값 ≤ .5, 그리고 모르는 정상보다 낮음(AUROC 모르는 정상 > 대조군 ≥ .8) |
| **P2 독 잔차의 크기** | train, B_mask: QuEST > 대조군 AUROC ≥ .8 |
| **P3 어떤 손실인가 (학습 데이터)** | train, s_delta: argmax = 표적인 QuEST ≥ 1/2, s[표적] > 0 ≥ 3/4 |
| **P4 방어자 데이터** | defender와 small 각각에서 s_delta argmax = 표적 ≥ 1/3 |
| **P5 계수를 몰라도** | train, s_fit argmax = 표적 비율 ≥ s_delta 비율 − .1 |

제 사전 기대는 낮습니다. P1 4할, P3 2할, P4 1할 정도입니다.
- 잘 배운 항(ASR .97)은 교차 엔트로피 기울기가 작아서, 독 잔차가 작습니다.
- 방어자 데이터는 학습 집합이 아니어서, 일반화 간극의 기울기가 독 잔차보다 클 것입니다.
