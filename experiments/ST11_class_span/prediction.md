# ST11 예측 — 트리거 변화는 표적의 깨끗한 특징 공간 밖에 있는가 (층별, 원리 확인)

작성 2026-11-27T10:13:36Z, 시험 실행과 본 실행 전. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "둘 다 진행해봐"(ST10과 함께). 같은 메시지의 방향은 다음과 같습니다.
  - 스위치 역할을 하는 것을 찾고, 그것을 켰을 때 트리거 없이(유도 정도는 괜찮음) 새는 백도어 특성을 찾습니다.
  - 기존 탐지기의 한계를 발전시키는 방향도 좋습니다.
- **CSO(Yang 외, ICML 2026)의 전제:** 트리거가 만드는 특징 방향은 표적의 깨끗한(본래) 특징 공간 밖에 있습니다. 클래스당 라벨 있는 깨끗한 이미지 10장으로 그 공간을 만듭니다.
- **지금까지:** 잡음 누출은 전체 깨끗한 공간 안이었습니다(ST06, ST07). 트리거 자체의 변화를 클래스별·층별로 잰 적은 없습니다.

## 원리

- 켜진 상태에서 트리거가 표적으로 보내는 변화가 표적의 깨끗한 공간 **밖**이면(H_밖), 라벨 있는 소량 데이터로 만든 클래스 공간이 백도어를 가르는 근거가 됩니다.
  - 정상이 어떤 클래스에 닿으려면 그 클래스의 본래 특징을 따라야 하기 때문입니다.
- **안**이면(H_안), CSO식 길은 QuEST에서 원리적으로 막힙니다.
- **같은 패치가 깨끗한 모델에서도 밖이면,** "밖"은 패치의 성질이지 백도어의 성질이 아닙니다(특이성 대조).
- **가정 수준:** 원리 확인(참 트리거)입니다. 공간은 "라벨 있는 소량의 깨끗한 데이터"로 만듭니다.

## 설계 (`exp.py`)

- **코호트:** ST10과 같습니다(113).
- **공간:** 방어자 라벨 이미지 2,000장에서 클래스당 n_lab ∈ {10, 50}장(모자라면 있는 만큼)을 씁니다.
  - 단계 출력(ResNet18 layer1–4, VGG 최대 풀링 5곳)의 공간 평균과 분류기 입력을 씁니다.
  - 모든 span 이미지의 평균으로 중심화하고, 클래스별로 에너지 95 %의 기저를 잡습니다.
- **변화:** 라벨 있는 시험 이미지 1,000장(방어자 이미지와 겹치지 않음) 중 그 클래스가 아닌 이미지에서 잽니다.
  - trig = f(x + 트리거) − f(x)
  - ctl = 트리거 자리에 무작위 색 패치를 붙인 변화
  - nat = 클래스 평균 − f(x), 즉 자연스러운 방향
- **지표:** in_c(·) = Σ‖U_cᵀd‖² / Σ‖d‖²이고, ζ_c = in_c(trig) / in_c(nat)입니다.
  - QuEST는 c = 표적이고, 다른 클래스의 중앙값을 내부 기준으로 함께 냅니다.
  - 쌍둥이와 정상은 모든 클래스의 중앙값입니다(트리거 자리의 흰 패치 Patch6x6).
- **상태**
  - R: FP, 깨끗한 BN 재추정
  - Q: 실제 iao4 배포
  - S2n: FP 가중치, 잡음 t 2(뽑기 0) 아래에서 보정하고 평가 = ST09 FNc
  - S2c: S2n 배포를 잡음 없이 평가. 잡음 아래에서 잰 BN만으로 켜지는가(ST09 분석의 남은 질문)

## 예측

| | 예측 |
|---|---|
| **P0 구현** | ASR 중앙값: Q ≥ .9, R ≤ .1, S2n ≥ .5 |
| **P1 H_밖 (Q)** | n_lab 10에서 층 최소 ζ ≤ .5인 QuEST ≥ 2/3 |
| **P2 특이성** | 같은 기준에서 쌍둥이(모든 클래스 중앙값)의 층 최소 ζ ≤ .5 비율 ≤ 1/3 |
| **P3 상태 의존** | 분류기 입력에서 QuEST의 ζ가 Q < R인 비율 ≥ 2/3 (켜지면 트리거 변화가 표적 공간 쪽으로 들어옴) |
| **P4 방어자 스위치** | 분류기 입력 ζ의 \|S2n − Q\| 중앙값 ≤ .1 |
| **P5 BN만으로 켜짐 (S2c)** | ASR > .5인 QuEST ≥ 2/3 |

제 사전 기대는 다음과 같습니다.
- **P1:** 반반입니다. 앞쪽 층에서는 흰 패치 변화가 어느 클래스의 공간에도 잘 안 들어갈 것 같습니다.
- **P2:** 3할입니다. 그래서 특이성이 관건입니다.
- **P5:** 반반입니다.
