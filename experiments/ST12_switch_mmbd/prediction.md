# ST12 예측 — 형식 없는 스위치 상태 × MM-BD, 켬/끔 차분

작성 2026-11-27T10:54:30Z, 시험 실행과 본 실행 전. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "기록하고 확인실험도 한번 진행해봐. nc는 일단 하지 말고 mm-bd(트리거 모양 가정 안 하는) 방향으로 일단 진행해봐."
  - 같은 메시지에서 "원래 모델이 가진 강한 클래스 구별"과 "수렴 속도 활용"도 더 연구하라고 했습니다. 이 실험의 보조 읽기(강한 클래스, 이른 마진)로 함께 봅니다.
- **후보 지도(PHENOMENA 10.8)의 2번 후보입니다.**
  - 탐지에는 상태 축(스위치)과 입력 축(유도)이 둘 다 필요합니다.
  - 기존 MM-BD는 꺼진 F에서만 봅니다. E07에서는 F AUROC .62, 실제 Q .79였습니다(batch1, 사후 문턱).
  - E27에서는 클래스 고유의 쉬움 때문에 후보가 표적인 경우가 7/17이었습니다.
- **차분의 원리:** 같은 모델의 켠 상태와 끈 상태를 클래스별로 빼면 클래스 고유의 쉬움이 지워지고, 스위치가 연 경로만 남을 것입니다.

## 가정 수준

- **유도:** MM-BD는 트리거 모양을 가정하지 않는 입력 최적화입니다(PHENOMENA 10.8에서 따로 표시). NC는 쓰지 않습니다.
- **상태:** 방어자의 라벨 없는 이미지 2,000장과 표준 연산(BN 재추정, 자르기, 활성 잡음)만으로 만듭니다. 공격 형식은 쓰지 않습니다.
- **라벨:** 클래스별 깨끗한 마진(Z_reg의 설명 변수)에만 씁니다. "라벨 있는 깨끗한 데이터"로 따로 표시합니다.
- **참 트리거:** ASR(어느 상태가 켜는가)과 표적 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트:** batch1을 뺀 331개입니다. QCB 168(Ma-8, Ma W4A4, Tian-8, Tian W4A4, Qu-ANTI 8+4, QuEST-8, QuEST W4A4), 대조군 17, 정상 146(가벼운, 표준, 어려운; QAT와 깨끗한 부모 포함)입니다.
- **상태**
  - F: 받은 그대로
  - Bfp: FP32 BN 재추정(E10)
  - C1: 보정 범위로 활성 자르기, BN 저장값(E10)
  - N: 4비트 한 칸 크기 활성 잡음 아래에서 BN·범위 재추정, 깨끗한 추론(ST11 S2c)
- **MM-BD:** MVD `baselines.run_mmbd`와 같은 설정입니다. 클래스당 무작위 이미지 30장, SGD 300단계, lr .01, 상대 허용 1e-5에서 클래스별로 멈춥니다. 클래스를 묶어 한 번에 최적화합니다(이미지별 기울기는 같음, P0로 확인).
  - 마진 궤적은 10, 25, 50, 100, 150, 200, 300단계에서 남깁니다.

## 점수 (먼저 정함, `analyze.py`)

- **native_S:** 상태 S의 MM-BD 원래 통계(감마 꼬리 −log p)입니다. native_on은 세 켠 상태의 최댓값입니다.
- **Z (주 점수):** Δ_c(S) = log max(m_c(S), .1) − log max(m_c(F), .1)입니다.
  - 상태마다 클래스들 사이의 강건 z(최댓값 − 중앙값) / (1.4826·MAD)를 냅니다.
  - Z는 세 켠 상태 중 최댓값이고, c*는 그 상태의 argmax 클래스입니다.
- **Z_reg (보조, 라벨):** 상태마다 log m_c(S)를 [1, log m_c(F), 클래스 c의 깨끗한 마진(F)]로 클래스들에 걸쳐 회귀하고, 잔차의 강건 z 최댓값을 냅니다.
- **Z_speed (보조, 수렴 속도):** 25단계 마진의 켬/끔 로그 차의 강건 z 최댓값입니다.
- **비교:** QCB(전체, 계열별) 대 정상+대조군입니다. 4비트 계열은 "배포를 아는" 정상(QAT, 대조군) 대비로도 봅니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | (a) 묶은 MM-BD가 MVD `run_mmbd`를 재현: 시험 모델에서 마진 상대 차이 중앙값 ≤ 1 %, argmax 같음. (b) 상태가 켬: Bfp에서 Tian-8·Tian W4A4 ASR > .5 ≥ 3/4, N에서 QuEST W4A4 ≥ 2/3 |
| **P1 기존 탐지기 (F)** | native_F AUROC(전체 QCB 대 정상+대조군) ≤ .70 |
| **P2 켠 상태의 기존 탐지기** | native_on AUROC ≥ native_F + .10 |
| **P3 차분 (주)** | (a) Z AUROC(전체) ≥ .85이고 native_on 이상. (b) QuEST W4A4 대 아는 정상 ≥ .80. (c) 켜진 QCB(어느 상태든 ASR > .5)에서 c* = 표적 ≥ 2/3. (d) Z > 3.5 경보: 정상+대조군 ≤ 10 % |
| **P4 강한 클래스** | 데이터셋마다 정상의 최빈 클래스 비율이 native F 후보보다 차분 c*에서 낮음 (클래스 고유의 쉬움이 지워짐) |
| **P5 보조** | Z_reg, Z_speed의 AUROC(전체) ≥ .75 |

제 사전 기대는 다음과 같습니다.
- **P3 (a):** 4할입니다.
- **QuEST W4A4 (b):** 2–3할입니다. E07에서 실제 켠 상태의 MM-BD가 2/4였고, 트리거가 표적의 본래 특징을 빌리기 때문입니다(ST11).
