# ST13 예측 — K-Arm식 비대칭(트리거 모양 무관), 켬/끔 차분

작성 2026-11-27T13:40:38Z, 시험 실행과 본 실행 전. 아래 상수와 규칙은 결과를 보기 전에 정했습니다.

## 승인과 배경

- **사용자 승인(11-27):** "k-arm 식 비대칭 실험 진행해보고 … 원래 강한 클래스를 … 이 부분만 어떻게 해결하면 될 것 같은데".
- **ST12 중간 결과(212/331):** 켠 상태의 MM-BD는 Ma·Tian의 표적을 고르지만 QuEST W4A4는 5/34입니다(켜짐 34/34). 마진 통계에서는 원래 강한 클래스가 이깁니다.
- **K-Arm (ICML 2021)의 생각:** 자연 특징이면 s→c와 c→s 비용이 비슷하고, 주입된 백도어는 비대칭입니다(표적에 닿기는 쉽고, 떠나기는 보통).
  - "트리거가 본래 특징 밖"이라는 전제가 없어서, 본래 특징을 빌리는 QuEST(ST11)에도 맞을 수 있습니다.
  - K-Arm은 NC식 마스크(패치 사전)로 비용을 잽니다. 여기서는 사용자 지시(NC 제외)에 따라 모양 무관한 공통 L2 섭동으로 잽니다.

## 원리

- **원래 강한 클래스(흡수·지배 클래스):** 정방향(→c)도 쉽지만, 기저가 넓은 만큼 역방향(c→)도 어렵다면 비대칭입니다. 그렇다면 비대칭만으로는 백도어와 구별되지 않습니다.
  - 그래도 그 비대칭은 끈 상태(F)와 켠 상태에 함께 있으므로, 켬/끔 차분에서 지워질 것입니다.
- **백도어 표적:** 켜면 정방향 비용만 줄고 역방향은 그대로라서, 비대칭이 켤 때만 커질 것입니다.

## 가정 수준

- **유도 + 라벨 있는 소량 데이터:** 클래스마다 방어자의 라벨 이미지 10장을 출발점으로 씁니다.
- 트리거 모양, 표적, 공격 형식은 가정하지 않습니다.
- 참 트리거는 ASR(어느 상태가 켜는가)과 표적 확인에만 씁니다.

## 설계 (`exp.py`)

- **코호트와 상태:** ST12와 같습니다(331개; F, Bfp, C1, N).
- **비용:** 순서 쌍 (s, c)마다 공통 섭동 δ를 둡니다.
  - 그 쌍의 출발 이미지 10장에 같이 더하고, 평균 마진 z_c − max_{k≠c} z_k를 L2 정규화 기울기 상승(한 걸음 .1, 최대 100걸음)으로 키웁니다.
  - 90 %가 c로 분류되는 첫 걸음의 ‖δ‖₂가 비용입니다. 넘지 못하면 마지막 노름 × 1.1로 두고 "검열"로 표시합니다.
  - 5, 10, 20, 40, 100걸음의 뒤집힘 비율도 남깁니다.
- **쌍:** CIFAR-10은 모든 순서 쌍(90)입니다. GTSRB와 CIFAR-100은 클래스마다 무작위 짝 8개를 양방향으로 씁니다.

## 점수 (먼저 정함, `analyze.py`)

- 클래스 c마다 정방향 F_c = 중앙값_s log cost(s→c), 역방향 R_c = 중앙값_s log cost(c→s)이고, **A_c = R_c − F_c**입니다(클수록 "닿기 쉽고 떠나기 어려움").
- **Z_A (주 점수):** 켠 상태마다 ΔA_c = A_c(S) − A_c(F)의 클래스 간 강건 z 최댓값을 내고, 세 상태 중 최댓값을 씁니다. c*는 그 클래스입니다.
- **보조 점수**
  - Z_E: 정방향 쉬움의 켬/끔 차분
  - zA1_S: 한 상태의 비대칭(K-Arm식 단일 상태)
- **강한 클래스:** ST12의 F 상태 MM-BD 1위 클래스(정상)를 씁니다.

## 예측

| | 예측 |
|---|---|
| **P0 구현** | 정상의 F에서 검열된 쌍의 비율 중앙값 ≤ .1. 상태가 ST12처럼 켬(N에서 QuEST W4A4 ASR > .5 ≥ 2/3) |
| **P1 강한 클래스는 대칭 (K-Arm 전제)** | 정상의 F에서 MM-BD 1위 클래스의 A가 다른 클래스 A의 중앙값 + 1 MAD 이하인 비율 ≥ 2/3 |
| **P2 백도어는 켤 때 비대칭** | 켜진 QCB(ASR > .5)에서 ΔA(표적) > 0 ≥ 3/4. c* = 표적 ≥ 1/2(전체), QuEST W4A4 ≥ 1/3 |
| **P3 탐지** | Z_A AUROC(전체 QCB 대 정상+대조군) ≥ .80. QuEST W4A4 대 아는 정상 ≥ .75. Z_A > 3.5 경보 정상+대조군 ≤ 15 % |
| **P4 MM-BD보다 나음** | 같은 모델에서 QuEST W4A4 대 아는 정상 AUROC가 ST12 Z보다 .10 이상 높음 |

제 사전 기대는 다음과 같습니다.
- **P1:** 반반입니다. 흡수 클래스는 기저가 넓어 비대칭일 수 있습니다.
- **P2 QuEST:** 3할입니다. 패치 트리거의 L2(약 5)가 자연 보편 섭동보다 작지 않아서, 정방향 비용이 크게 줄지 않을 수 있습니다(E18).
- **P3:** 3할입니다.

## 틀렸다고 볼 기준과 판정

1. **구현:** P0이 틀리면(검열이 많음) 결과를 읽지 않고, 걸음 수를 늘려 다시 할지 보고합니다.
2. **데이터셋 의존:** 정상의 Z_A 중앙값이 데이터셋 사이에서 3배 넘게 다르면 데이터셋별로만 씁니다.
3. **오경보:** 정상+대조군 Z_A > 3.5가 20 %를 넘으면 "오경보 통제 실패"로 적습니다.
