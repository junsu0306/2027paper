## 설계 (`exp.py`)

- **표본(SAMPLE 규칙, seed 14):** 층(계열 또는 정상 하위 종류) × 데이터셋마다 정해진 수를 무작위로 뽑습니다.
  - QCB: QuEST W4A4는 8/6/6, 나머지 계열은 칸마다 최대 4개입니다.
  - 정상: 대조군은 모두, QAT-W4A4-IAO 3, 다른 QAT 2, 가벼운 3, 표준 3, 어려운(기타) 4입니다.
  - 합계 156개(QCB 82, 정상+대조군 74; CIFAR-10 52, CIFAR-100 51, GTSRB 53)입니다.
- **상태**
  - N: 잡음 아래 BN, 깨끗한 추론(ST11 S2c)
  - Bfp: FP32 BN 재추정
  - 짝지은 무작위 영 상태: N_sign1, N_sign2, N_perm, Bfp_sign1
  - D: 형식을 아는 참고. QCB는 표적 배포, 정상은 iao4와 fbgemm8
- **탐색:** A′ 틀(선별 100걸음 → 후보 3개 → 클래스마다 300걸음, 배치 128)입니다. 목적함수는 CE(S(x+δ), k) + CE(F(x+δ), ŷ)입니다.
  - L2: 공통 δ, ‖δ‖₂ ≤ β√(3·32·32), 정규화 기울기 걸음 후 투영
  - L1: ‖δ‖₁ ≤ β²·3·32·32
  - patch: A′식 마스크 + 무늬, 면적 평균 ≤ 5 %
- **측정:** G = max_k [fwd(δ*_k, k) − fwd(0, k)]입니다. fwd = 측정용 500장에서 "S는 k, F는 원래 답"인 비율입니다. 패치의 출발점은 얇은 회색 막입니다.
- **탐색 계획(모델마다):**
  - N: L2 .10, L2 .25, L1 .25, patch
  - N_sign1: L2 .10, L2 .25
  - N_sign2: L2 .25
  - N_perm: L2 .25
  - Bfp: L2 .10, L2 .25
  - Bfp_sign1: L2 .10, L2 .25
  - D 배포마다: L2 .25, patch

## 점수 (먼저 정함, `analyze.py`)

- **Γ (주 점수):** max( G(N, L2 .25) − G(N_sign1, L2 .25),  G(Bfp, L2 .25) − G(Bfp_sign1, L2 .25) )
- **대안 정보(보조, 미리 정한 읽기)**
  - Γ_sign2, Γ_perm(다른 영 상태)
  - G(N, L2 .25)와 깨끗한 불일치의 관계(σ 정규화 재료)
  - L1, patch, L2 .10
  - D의 L2·patch
  - 찾은 δ*의 에너지 중 트리거 자리 몫(진단)
  - 데이터셋별 AUROC
